# Agent Note：V2 采用唯一的 FDE 八阶段生命周期

状态：已实现

[English](2026-09-01-fde-v2-eight-stage-lifecycle.md) | 中文

## 问题

工作台此前存在两套互相竞争的生命周期模型。V2 产品语言描述的是八个现场交付阶段，但持久化阶段状态、项目汇总和部分页头仍在投影旧版六阶段课程流程。后续阶段也缺少统一、可测试的基础合同，无法稳定表达固定产物、人工评审、返回路径和可复制测试提示词。这会让界面看起来已经完成，却无法让使用者可靠理解和测试完整交付链路。

## 决策

V2 只采用一套权威八阶段状态：发现高价值问题，定义结果、范围与责任，调查数据、系统、接口、安全与组织，设计方案并完成端到端纵向切片，运行 PoC 与 Eval，完成企业集成、可靠性改造与受控 Pilot，进入生产、推动采用并验收交接，以及持续改进并沉淀可复用能力。持久化记录保存这套 V2 状态及其返回与重新确认历史。旧六阶段值只作为现有专用页面和旧项目记录的显式兼容投影，不再定义当前生命周期。

阶段二至阶段八共用一套轻量交付基线。阶段二提供九项可查看的方法，阶段三至阶段六各提供七项，阶段七提供八项，阶段八提供七项。每个目录都区分必做工作与按需处理，使用用户能理解的业务名称，并对应运行时真实注册的 Skill。侧栏按分组展示方法但不虚构执行状态，Agent 只加载当前任务需要的最少方法。每项方法都明确业务目标、固定产物路径、状态文件合同、真实性约束，以及只有 FDE 才能改变阶段的规则。Host 读取阶段 JSON 记录和必需文件，并暴露当前工作、阻塞项、评审就绪状态与产物可用性。项目工作台使用与第一阶段一致的四步引导形态，支持预览已有产物、准备可编辑的 Agent 任务，并把评审和返回决定留在当前项目内。完成阶段必须满足评审就绪并经过人工二次确认；文件存在不等于事实已确认，也不等于评估、Pilot、生产或交接已经通过。

项目中心、项目侧栏和阶段页头统一读取同一份八阶段状态和名称。返回前一阶段会记录原因，并把后续阶段标记为需要重新确认。阶段八记录持续发生的改进轮次，而不是把项目伪装成已经没有后续工作。每个阶段都配有中文手动测试包和简短提示词，方便使用者生成基础产物并在次日手动走通完整流程。

项目侧栏同时支持在不改变持久化生命周期状态的前提下，只读查看全部八个阶段。真实当前阶段与正在查看的阶段分别标记。已完成阶段只展示当前项目中真实存在的输入、产物、阻塞和人工阶段结论；缺少的历史事实明确标为未登记，不用模板补齐。后续阶段采用明确的“尚未开始”状态，只说明项目当前阶段、开始条件和预计形成的记录，不把计划方法或工作写成仿佛已经开始执行。用户可通过专用入口清除预览选择，重新跟随权威当前阶段。

当前项目工作台右侧采用折叠的“项目记录轴”，替代只能打开当前产物的单一按钮。记录轴只列当前阶段和已经由 FDE 推进的阶段，不显示尚未开始阶段；节点显示阶段序号、当前或已完成状态，以及必需记录完成数。展开后可以查看所选阶段当时使用的输入、留下的产物和人工决定，也可以汇总全部已有记录。选择历史节点只是只读浏览，不调用阶段迁移接口；记录轴高度按已有阶段数量自适应，避免用贯穿整页的空白轨道占位。

项目中心采用面向人工行动的高保真管理首页：顶部保留项目身份、新建入口与静态账号区，概览区展示真实项目、待人工决定、运行中会话和已登记周期，当前优先事项使用独立深色卡片承载。项目集合默认使用双列卡片，同时保留列表、筛选和排序；项目卡片继续显示八阶段路径、最近进展、待决定事项和进入项目入口。优先事项中的层叠图形只是本地静态视觉资产，不引入登录、消息或权限行为，也不改变隔离区事实来源。

本次实现刻意定位为基础闭环，不宣称每一种现场专用操作都已完成。价值证据分析、权限与治理矩阵、真实纵向切片执行、评估运行器、Pilot 授权与遥测、生产采用证据和受控发布自动化，仍保留在各 Feature 的任务清单中继续实现。通用基线让八阶段可以导航、持久化和测试，同时不会虚构这些操作的真实结果。

## 考虑过的替代方案

**继续保存六阶段状态，只在新工作台显示八个名称。** 否决，因为项目汇总、页头、阶段迁移和持久化状态会彼此矛盾。

**必需文件一存在就自动完成阶段。** 否决，因为文件只是候选载体，不能证明事实已确认或真实操作已经成功。

**先完成所有阶段专用工作面，再开放完整生命周期。** 否决，因为这会延迟可测试的端到端产品链路，也容易引入未经验证的复杂集成。基础闭环保留清晰扩展点，同时如实标记尚未完成的工作。

## 影响

使用者现在可以看到并手动测试一条一致的八阶段交付路径。Agent 工作、产物持久化、当前项目内评审、人工阶段决定、返回和持续改进轮次拥有共享合同。现有 V1 记录和六阶段专用页面通过显式兼容投影继续可用。阶段专用高级执行能力仍明确标记为进行中，不会再从文件存在或静态界面推断其已经完成。
