# Agent Note: 第一阶段只读 Skill 库

Status: implemented

[English](2026-09-17-stage-one-skill-library.md) | 中文

## 问题

平台技能入口需要可阅读、可下载的方法，同时不能改变项目执行，也不能把外部参考资料表示为包内文件。

## 决定

技能库从现有固定阶段目录派生七个包。阅读器与 ZIP 编码器共用每个文件字符串，保留固定来源声明和许可证，并明确内容为工作台适配版。查看与下载不枚举用户目录，也不调用 agent（智能体）。既有阶段方法对话框与自动选择保持不变。

## 考虑过的替代方案

**另外编写一套 Skill 目录**会让下载内容偏离 Host 实际注册的方法，因此当前从同一只读目录派生文件。

**打包上游参考资料**会暗示链接中的模板和脚本已经审阅并包含在内，因此阅读器保留外链，只列出实际包内文件。

## 影响

导出正文保留工作台路径与协作能力依赖，不承诺在其他环境中的安装或执行兼容性。定向测试覆盖七个真实方法、ZIP 与文件一致性、搜索、恢复、阅读和返回状态。浏览器视觉验收遵循产品仓库的人工优先规则。
