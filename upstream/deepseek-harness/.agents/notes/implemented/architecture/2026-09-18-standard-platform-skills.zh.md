# Agent Note: 标准平台 Skill 文件

Status: implemented

[English](2026-09-18-standard-platform-skills.md) | 中文

## 问题

简短运行适配正文遗漏了有用方法；独立完整原版浏览器快照虽然补齐下载，却让 Agent 使用另一套指令。用户要求完整中文平台 Skill、直接文件加载和只呈现名称与内容的阅读器。

## 决定

fde/stage/skills 下七个维护中的 SKILL.md 包负责平台名称、描述、完整流程与必要资料。原生 FileSystemSkillProvider 只读取这一固定目录，返回当前正文与资源基目录；固定优先级 250 保留原项目/运行时/用户的顺序。七个硬编码正文和独立浏览器快照退役，其他阶段和课程原版保留原机制。

可信阶段目录接口从同一包提供展示和下载，包括共享规则依赖及字节哈希。共享持久化规则只在一份被引用文件中维护。阅读器呈现名称和正文，允许打开配套引用并返回，不展示目录树或上游详情。下载保留必要许可，不重复嵌套 Skill 外层目录；历史 Session 工具结果不改写。

## 考虑过的替代方案

**保留简短内联指令。** 名称和来源链接不能代替完整操作方法。

**在适配版旁保留完整原版快照。** 虽然保留原字节，却形成两份维护源，无法规范实际执行。原始研究副本继续用于维护和许可，不用于运行加载。

**直接运行未翻译的上游包。** 它们的产物路径、安装命令和权限假设与平台不同。中文平台维护保留实质方法，并采用现有证据、产物和人工决定规则。

## 影响

平台 Skill 编辑会进入后续原生加载和目录读取，无须重建指令快照。加载不新增执行权限，课程不会自动注册。运行时、目录和压缩包检查比较实际文件内容，卸载移除七项 provider 贡献。skill-creator 校验和独立模拟采购案例检查结构与判断指引，但不冒充真实模型业务验收；浏览器观感仍由人工检查。
