# Agent Note: FDE 项目独立性与证据完整性

[English](2026-09-07-fde-generality-and-evidence-integrity.md) | 中文

Status: implemented

## Problem

项目交付记录可能在证据不足时呈现完成；普通图谱消费可能改变编制验证状态；旧版阶段操作可能绕过 V2 现场调查阶段。

## Decision

阶段记录从已注册项目读取。空白或越界产物不计有效记录，空调查项需要带证据的不适用理由，未明确边界阻止评审。验证结果证据摘要独立于输入指纹固定，明确的模拟来源不能证明真实交付就绪。这些检查证明完整性，不独立认证执行或客户验收。

普通语义查询通过 Harness 工具结果返回上下文，不写编制状态；只有显式验证查询替换编制上下文。适配器实际执行项目身份、字段、关系与有效时间检查，验证回执携带检查版本，旧类型检查不能直接沿用。文字规则仍是说明，不是授权引擎。

旧记录不在读取时迁移。完成与返回执行器只接受各自生命周期版本，提示词按同一版本分流。

阶段文案使用具体交付任务和可观察状态：实现方案选择、业务问题查询、图谱接入、受测版本和阶段评审。技术标识与既有生命周期名称保持稳定。方案选择记录不写成人工批准，历史只读查看不宣称文件不可变；客户填写的内容保持原文。

## Alternatives considered

案例名称特判、虚构默认事实或独立演示进度会隐藏证据缺口，损害新项目适用性。删除旧入口会破坏合法旧项目；自动改写旧回执会制造验证历史。

## Consequences

既有文件与生命周期历史保持不变。未绑定摘要的旧结果和旧图谱验证需要核对或重跑。文件哈希不提供回执真实性、机器执行认证或外部签署。规则分数是启发式数值，有界能力问题查询不认证业务答案正确。

## Testing

定向项目和阶段测试覆盖文件完整性、来源性质与生命周期隔离。真实 Python 查询证明编制文件字节不变；适配器测试用出版领域 Schema 覆盖身份冲突、字段类型、关系基数和排除路径。SDK 构建另由显式启用的集成测试验证。

CLI 所属的免密 FDE 快照从已构建包经 Loader 加载实际 Base 与 Web Bundle，对隔离项目调用真实 HTTP 路由，并固定评审输出与模型可见查询参数。测试覆盖层禁用纯浏览器界面和遥测；生产默认配置不变。

同一组合快照固定阶段与方法说明。客户端测试在核对可读标签的同时保留文件查看、图谱构建、运行控制和显式阶段确认的验证。
