# Agent Note: 按调用时间统计项目用量

Status: implemented

[English](2026-09-08-project-usage-time-ranges.md) | 中文

## 问题

用量页面默认选择今天，并把会话累计计数全部分配到最近更新时间。历史项目隔天打开就像没有数据，跨天会话也会把全部用量挪到某一天。

## 决策

页面默认项目累计。在累计统计旁注册独立数值投影 `sessionActivity`，复用统计 reducer，同一步的重复用量回执采用替换而非相加。每次调用归属开始时段，仅在开始事件缺失时采用回执时间。既有累计投影和聊天底部统计不变。

受信 Workspace 用量路由读取已连接快照，或通过公开投影缓存冷回放历史会话。它不打开 Agent、不复制消息内容、不改写日志。客户端控制器取消过时读取，区分加载、失败、部分数据与真实无活动。日期筛选后的卡片、趋势和会话表共用活动数据；长期历史合并自然日，而非丢弃旧数据。

## 替代方案与验证

只改默认选项会留下错误的日期筛选。公开投影缓存能够回放历史日志，无需让浏览器解析私有持久化文件或扩宽 Session API。定向测试覆盖跨午夜归属、回执替换、取消、检查点恢复、Loader 组合、范围切换及客户端过时请求。真实项目累计、日志哈希和在线 Bundle 在 F002 任务记录核对。不需要模型调用、外部导出或自动浏览器验收。
