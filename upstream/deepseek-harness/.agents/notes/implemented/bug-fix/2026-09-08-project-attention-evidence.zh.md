# Agent Note: 项目中心待处理提示必须有具体事实

Status: implemented

[English](2026-09-08-project-attention-evidence.md) | 中文

## Problem

按读取状态、会话运行和项目是否完成挑选“优先关注”，会把后台加载和正常工作误称为人工待办；评审条件列表又包含尚未形成的材料，不能整体当成业务风险。

## Decision

项目中心从当前阶段的显式未解决问题、当前版本实际执行失败的测试或交付记录、Host 可评审状态、有效已登记计划日期及读取错误派生待处理原因。卡片显示原因标签和具体问题，列表、顶部提示、计数、筛选和优先排序复用同一判定。已完成项目、历史阶段、已解决问题、普通未完成状态和加载过程不自动产生待办。默认集合排序仍按最近操作，只有手动优先排序使用原因级别。

## Alternatives considered

**所有未完成项目都需优先关注。** 该规则不能说明为什么此刻需要介入，因此不作为待办依据。

**直接使用全部评审缺口。** 缺少尚未生成的文件只是普通工作进度，不等于已发生的业务阻塞；只读取显式问题和已执行结果。

## Consequences

没有事实时允许没有优先项目；“暂无已登记待处理事项”不宣称所有项目已经确认无风险。登记日期属于计划，不当成合同承诺。旧生命周期保留相应人工确认动作；本轮不新增存储、模型调用或阶段推进，不根据项目名称作任何特判。
