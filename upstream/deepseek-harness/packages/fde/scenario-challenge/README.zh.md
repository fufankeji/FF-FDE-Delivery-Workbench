# @deepseek-ai/dsh-fde-scenario-challenge

[English](README.md) | 中文

中文 FDE 场景挑战的独立 Host 插件。固定十道单选题、五方向各两题、连续限时 300 秒，交卷后显示逐题解释。题库由平台自行编写，不复制外部考试题。

## 数据与访问

必须显式设置 `DSH_HOME`；记录保存在其 `fde-scenario-challenge/state.json`。同一运行区共享一个进行中轮次和最近 20 次结果，不提供账号隔离。轮次保存题目快照、答案、开始/截止时间和修订号，历史按当时题目评分；不读写 Workspace、项目阶段、Session 或业务访谈数据库。

`/api/fde-scenario-challenge` 的 GET 读取状态，POST 执行开始、保存答案或交卷；两者都要求 Connection owner 身份和同源信任校验。读取及写入前按服务端截止时间结算过期轮次，进行中响应不含标准答案。文件锁与原子替换保护提交；旧修订拒绝覆盖，重复开始/交卷复用已有结果。损坏或未知格式返回明确错误，不用空状态覆盖原文件。重新加载插件会撤销其路由。

## Model Experience

不注册提示词、工具或 Agent，不读取模型凭据，不调用模型或外部题库。所有题目、选项和解释都是固定中文资料；结果只描述本次表现，不是认证或项目验收。

#### KV Cache effect

没有模型请求，因此不改变上下文、Token 或缓存。

## Known Limitations and Deferred Work

- 这是本机共享的练习，不是防作弊考试；不能防止有权修改本地文件或系统时间的使用者篡改结果。
- 固定十题与每方向两题不能推断完整职业能力；复测可能有记忆效应。
- 最多保留最近 20 次完成记录；没有云同步、多人账号或题库管理后台。
- 原子替换不等于断电持久性保证；文件写入失败必须先重新读取确认状态。
