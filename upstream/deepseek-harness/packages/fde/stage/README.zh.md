# @deepseek-ai/dsh-fde-stage

[English](README.md) | 中文

FDE 项目当前阶段的 Host 端状态。该包打开一张以 Harness WorkspaceId 为键的 `storage-domain` 表，并提供仅限可信同源访问的 POST 路由：记录存在时直接读取，不存在时持久初始化为 `requirements`。同一 Workspace 的并发首次读取共享一次写入。当前切片不接受目标阶段、完成声明或阶段变更操作。

产品六阶段依次为需求调研、方案设计、项目开发、验证评估、部署试运行和验收移交。每阶段的详细输入、产物、确认与完成规则属于后续阶段交付门切片。

## 模型体验

无。读取或初始化项目进度不会创建 Session 事件、提示词、工具、消息或模型请求。

#### KV Cache 影响

无；系统不会组装或改变任何提供方请求。

## 已知限制与暂缓事项

- 路由只允许本机同源访问，并要求 WorkspaceId 已存在。
- 当前记录只有当前阶段、revision 和时间；阶段变更历史、受影响状态、交付门证据和浏览器推送更新延期到 F005。
- 在后续 `fde-context` Consumer 把可重建项目快照写入对应 Session 前，当前阶段不会进入模型上下文。
