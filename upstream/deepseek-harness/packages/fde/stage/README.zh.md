# @deepseek-ai/dsh-fde-stage

[English](README.md) | 中文

HTTP 接口要求 Connection 认证后的 owner 身份并遵守同源检查。默认仅本机监听；显式局域网访问使用具体 `--host` IP 和启动授权链接，退役的 `--lan` 不能关闭认证。

FDE 项目当前阶段的 Host 端状态。该包打开一张以 Harness WorkspaceId 为键的 `storage-domain` 表，并提供仅限可信同源访问的 POST 路由：读取或初始化记录，以及执行六个固定转换——`requirements` 到 `solution`、`solution` 到 `development`、`development` 到 `validation`、`validation` 到 `pilot`、`pilot` 到 `handoff`，最后由 `handoff` 进入终态 `completed`。同一 Workspace 的并发首次读取共享一次写入；阶段转换按项目串行并要求页面提交精确 revision。六个交付门依次重新检查三份需求调研文件、包括项目 PRD 在内的五份方案设计文档与已确认架构、三份项目开发收口文件、当前已由 FDE 确认的验证方案/合同/证据/阻塞项和三份验证产物、部署试运行合同/环境授权/五类证据/问题和四份产物，以及最终验收移交合同/交付物/条件项/责任移交/证据和四份产物。另一条仅限 FDE 的路由每次只返回一个阶段，也可把 `completed` 重新打开到 `handoff`；它必须填写原因，保留全部文件和证据，记录有界审计，并把返回范围标记为待重新确认。所有路由都不接受任意目标阶段。

第一阶段七个方法以 skills/ 下的完整中文 SKILL.md 文件包维护，包含必要参考与模板。原生 FileSystemSkillProvider 只读取这一固定目录，按需加载当前正文。平台优先级保留为 250，维持项目覆盖和此前用户级优先级；七个硬编码正文不再注册。其他阶段、证据检查、记录和人工决定不变，Skill 不能推进项目阶段。

可信只读 GET /api/fde-stage/skills 路由从同一目录重新读取平台元信息、正文和可下载 UTF-8 文件，包括路径和 SHA-256；必要许可继续随包保留。它不枚举用户/全局 Skill 目录或客户项目，不执行 Skill 或修改项目数据。

核心方法保留业务还原、原因诊断、指标口径、非 AI 对照和三份既有记录。持久化字段只在 qualify-ai-workflow/references/stage-records.md 维护一份，其他平台方法链接到它。创建遵循 skill-creator：明确触发、完整任务流程和按需参考。指令不能证明生成诊断的质量。

## V2 交付记录

V2 阶段六至八的方法正文包含 delivery 记录、文件摘要、证据范围和可选语义依赖写入指引；旧六阶段与前五阶段方法不变。阶段门读取 Host 核验结果，文件数量或 Agent 建议不能直接推进。


## 生命周期版本隔离

读取既有记录不执行迁移。旧完成／返回操作只接受旧记录；V2 操作要求 `lifecycleVersion=2` 和权威 `v2Stage`。版本交叉操作失败且不修改修订号。提示词按同一版本分流，不把旧项目统一放入发现阶段。

## 模型体验

当 Agent 属于已登记项目的任一活动交付阶段时，模型会看到一段短提示：当前阶段、固定产物目录、可选工作方法，以及不得确认客户结论或推进项目。只有当前任务选中的 Skill 正文才会在既有 skill 工具被调用后加载；终态 `completed` 不再贡献阶段提示。本包不注册阶段推进工具。

#### KV Cache 影响

短提示在每个活动阶段内保持稳定，只在已提交项目状态变化时改变，并在最终完成后变为空。较长的 Skill 正文只在明确加载后影响普通对话后缀。

## 已知限制与暂缓事项

- 路由只允许本机同源访问，并要求 WorkspaceId 已存在。
- 当前记录保留有界的返回审计和待重新确认边界；完整的前进转换历史与浏览器推送仍延期实现。
- 部署与验收合同仍是项目文件；本包不执行部署、不保管凭据、不认证客户，也不完成签章。
- 固定文件只校验存在和可读取；业务质量仍由 FDE 负责判断。
