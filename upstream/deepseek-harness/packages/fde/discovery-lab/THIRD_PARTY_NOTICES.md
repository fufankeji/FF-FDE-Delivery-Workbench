# 第三方来源与许可

本文件由 development/scripts/package.mjs 按当前构建依赖生成。许可清单不替代业务验收记录。

## 本项目素材

五种办公室地图、家具与人物像素几何由本项目原创，源码在 development/client/SceneArt.tsx、PixelPeople.tsx 和 PixelOffice.tsx；没有分发 AI Town 或 LimeZu 图像资产。选中的 UI 效果图仅作为设计参考。五个案例材料来自本课程原创教学素材；源码归档保留教师和未来事件层，运行包按 case.assets 白名单发布。

## 宿主与字体

- DeepSeek Harness：deepseek-ai/deepseek-harness，官方 npm 0.1.5-rc.2，MIT。由用户独立安装，插件不分发宿主副本。https://github.com/deepseek-ai/deepseek-harness
- React：官方入口共享 React 18.3.1（MIT）；局域网独立入口本地打包 React 和 ReactDOM。https://github.com/facebook/react
- Noto Sans CJK SC Regular：Noto CJK 项目，SIL Open Font License 1.1。字体未经修改，随 PDF 导出能力分发；完整许可随 development/fonts/LICENSE 提供。https://github.com/notofonts/noto-cjk
- PDFKit 0.17.2：MIT，运行时由 npm 安装，其依赖保留各自 npm 包许可。https://github.com/foliojs/pdfkit
