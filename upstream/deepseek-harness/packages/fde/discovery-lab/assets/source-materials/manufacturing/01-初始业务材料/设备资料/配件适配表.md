# PART-MAP 1.1｜配件适配及替代规则

生效2026-08-20。A/B皮带的结构与安装配合不同，PT-BELT-A不替代PT-BELT-B；整套胶带头TH48A/TH48B也不得临时互换。胶带卷MAT-T48为试验物料，其合格不代表客户任意胶带均合格。配件单位见库存表，双侧皮带更换工单按2条预留，不能把1条当1套。

技术确认料号 → 仓库查询实物、有效预留与隔离 → 项目经理确认费用承担 → 调度确认收货窗口 → 仓库出库并写物流单 → 现场验收数量和型号 → 完成更换与旧件处理 → 客户确认。任何环节未完成，在工单保留负责人和下一次更新时间。

可承诺数量=实物-有效预留-隔离待检。在途不是现货。预留释放需要原任务负责人同意并记录；不由新求助的先后顺序直接覆盖。照片只能帮助识别标签，型号不清必须核对。
