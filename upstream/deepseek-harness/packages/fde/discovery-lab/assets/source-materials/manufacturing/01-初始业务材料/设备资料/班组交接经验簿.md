# 班组交接经验簿｜2026-09-01整理

记录人唐序安，审核裴稷。经验用于帮助观察和追问，不替代有效操作卡或证明故障原因。

1. 客户说“胶带偏”，先问纸箱本身是否斜着进入、偏的是上面还是下面、整批还是偶发。H001是换型核对的历史例子，但相同文字也可能是传动或物料变化。
2. 听到“没改过”时，把时间范围说清楚：本班、本周、上次正常以后；纸箱与胶带更换也属于需要记录的变化。
3. “靠门那台”“2号机”是客户口头位置，先转成序列号；设备台账与贴签冲突时保留两方证据，不任意覆盖。
4. 对维修中断的师傅，准备设备身份、变化、照片、已确认项目和明确问题，约一个不同时指导他处的窗口；不连续发送无上下文短消息。
5. 说“库里有”时问实物还是可用、什么料号、几条还是几套、有没有其他预留。C003/C007当前预留必须由仓库确认后再改。
6. 每次更新交代当前状态、下一步负责人和预计更新时间；“在跟进”不足以让客户安排生产。
7. 10只试封通过后，仍要询问客户持续运行结果与遗留条件；不同箱型和班次不能自动继承一次确认。
