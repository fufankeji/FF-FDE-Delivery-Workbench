# DATA｜数据目录与关联约定

所有 CSV 为 UTF-8 BOM、首行为英文字段名、空串表示未发生/不适用，布尔值 0/1。时间为 ISO 8601 +08:00；`date` 是本地自然日。订单、会话和渠道都属于 BU-01。主键不可按行号重新生成。

|文件|粒度与键|业务字段|
|---|---|---|
|channels.csv|每渠道一行；channel_id|channel_name 中文渠道，owner_role 责任岗位|
|products.csv|每 SKU 一行；sku_id|product_name 商品，category 品类，list_price_fen 标价；非成本|
|users.csv|每可识别用户一行；user_id|first_seen_at 首次访问，acquisition_channel 首访渠道；不含客户个人信息|
|sessions.csv|每访问会话一行；session_id|user_id→users；channel_id→channels；device 设备；landing_sku_id→products；add_to_cart、checkout_started 为该会话是否发生事件；order_id 为空表示未提交订单|
|orders.csv|每提交订单一行；order_id|session_id→sessions；gross_fen 商品标价金额；discount_fen 折扣；payable_fen 应付；paid_at 为空表示未成功付款；financial_status 财务状态；order_status 业务状态；currency 固定 CNY；is_test 固定 0|
|order_items.csv|每订单商品行一行；order_item_id|order_id→orders；sku_id→products；quantity 件数；unit_price_fen 标价；line_payable_fen=单价×件数−该行折扣；本教学集每单一商品行，数量可大于一|
|payments.csv|每付款尝试一行；payment_id|order_id→orders；attempted_at 尝试时间；status success/declined/timeout/pending；amount_fen 仅成功时为收款额；error_code 错误码；provider 支付供应方|
|refunds.csv|每退款申请一行；refund_id|order_id→orders；requested_at 申请时间；processed_at 成功处理时间或空；status succeeded/pending；refund_fen 申请/处理金额；reason_code 原因；refund_type full/partial|
|channel_spend.csv|每日每渠道一行；(date,channel_id)|spend_fen 已结算费用；campaign_id 活动标识，见补充活动台账|
|daily_kpi.csv|每自然日一行；date|由上述明细生成的现有日报视图；dau、sessions、created_orders、paid_orders、paid_gmv_fen；不要再次与原明细累加|

订单状态：confirmed 表示曾确认付款；open 表示待付款；canceled 表示未付款已关闭。付款与履约不是同一状态，本资料未提供仓储履约流水，不能据此判断发货率。financial_status 为 paid/partially_refunded/refunded/pending/unpaid，退款成功后状态更新但 paid_at 保留。

关系链：渠道/用户 → 会话 → 订单 → 商品行、付款尝试、退款。费用独立为日×渠道粒度；先各自聚合，再关联，避免把一笔渠道费用乘上订单数。直接连订单和多条退款会重复成交額；本集每单至多一笔退款，但设计查询时仍应先聚合。

覆盖边界：28 天完整交易样本，非整个行业。每天数量有意规则化，便于人工复算；不用于训练真实商业预测、检验季节性或估计生产吞吐量。无同比前年数据、商品成本、库存流水、广告曝光和跨设备身份，相关问题需明确缺口。
