# 现行岗位协作

采购专员：维护供应商报价、采购行和订购数量；向供应商核实普通或加急供货条件，整理申请。采购负责人负责方案和资源安排，超过本次授权的事项送经营负责人或财务确认。

物流协调员：按货运批次接收消息，核对预计到仓与预计可售日期；不能仅凭服务商“已经发出”就改成海外可售。

海外仓对接员：取得两仓的库存、清点和质量状态，负责向合作仓追问。合作仓确认的实收、隔离与预留是不同字段。

店铺运营：查看履约、规格供货和推广计划；可以调整运营安排，但采购和物流不代替运营修改广告。

财务审批岗：核对费用范围、预算授权和支付条件。金额低于限额不代表自动采购，业务负责人仍需确认方案适用。

目前的处理顺序是：运营或采购发现供货疑问 → 采购看现有表格 → 向仓库和物流核实同一规格/批次 → 询价或核调拨条件 → 整理措施及费用 → 人工批准 → 通知执行 → 追踪入仓及剩余异常。一次处理可以停在“仍待仓库确认”，这和已经补好货不同。

工作日主要在09:00—18:00协作，合作仓按其值班安排回复。马来西亚与中国本案例都使用UTC+8，但运输通知可能只有日期。资料没有精确时刻时不得补出一个看似精确的到货时间。
