# @deepseek-ai/dsh-client-ui-fde-appearance

[English](README.md) | 中文

FDE 工作台界面主题的浏览器展示与本地持久化插件。插件通过设置插槽提供“界面主题”页面，包含官方原版、五套 1920×1080 WebP 内置皮肤和本地自定义图片。一个 apply 作用域控制器统一拥有背景 DOM 属性和一层可卸载的 `ThemeRuntime.overrideTokens()`，因此官方浅色、深色和跟随系统偏好保持独立。AppFrame 保留一层半透明侧栏表面，稳定的 `[data-slot='sidebar']` 地址则移除重复内层填充并增加背景模糊，使同一皮肤也能在项目与 Session 导航后方可见。

选择皮肤卡片或图片只改变设置页预览。“保存并应用”先校验完整值并序列化到版本化的 `fde.appearance.v1` localStorage 项，成功后才替换全局背景和 Token。图片处理或存储失败时，已有持久值与当前 DOM 都不改变。选择官方原版或卸载插件只移除本包写入的背景和 Token。

自定义 PNG、JPEG、WebP 原图上限为 16 MiB，浏览器会在本地解码、按 cover 裁切为 1920×1080 WebP，并采样四个主题色。原图和处理结果都不会通过 RPC，不进入 Workspace、Session 日志、Agent 请求或观测后端；清理站点数据会删除这项个人偏好。

设置页使用原生 20/28 标题与 13/20 说明层级、轻量卡片边框和稳定的悬停反馈；图片预览及偏好保存格式不变。

## 模型体验

无。该包不注册消息、提示词、schema、工具、请求上下文或 Host 调用。

#### KV Cache 影响

无；系统不会组装或改变任何提供方请求。

## 已知限制与暂缓事项

- 主题选择只属于一个浏览器 Origin；不提供皮肤市场、跨设备同步、团队共享或项目级主题。
- localStorage 配额由浏览器决定；处理后的自定义图片超过安全序列化上限时会被拒绝，当前主题继续保持。
