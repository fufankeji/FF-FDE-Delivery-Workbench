# @deepseek-ai/dsh-client-ui-fde-scenario-challenge

[English](README.md) | 中文

通过 `fde.workbench.lab.challenge` 子插槽提供中文挑战介绍、答题、结果与历史页面，使用工作台原生控件和语义主题。题目、规则、错误、无障碍标签与解析为中文，即使外壳切换为其他语言也保留中文题目体验。

## 行为

`fde-challenge` 资源提供者统一读取独立 Host 接口；页面使用 `useResource`，不持有第二份业务事实。答案写入确认并重新读取前禁止下一次冲突操作，失败保留已保存选择。进入页面不开始计时，点击开始才创建或恢复轮次。显示计时以服务端时间样本和经过时长推导，到时请求服务端结算；刷新、切页或关闭不重新计时。

交卷前只展示题目与已选项，确认框说明未答数；交卷后可逐题查看全部选项的解释、方向答对数与练习建议。历史和“返回挑战介绍”不创建新轮次；进入业务挖掘只导航，不自动提问。资源、请求和焦点监听随插件释放。

## Model Experience

没有模型请求、提示词或凭据读取。所有业务判断和评分在独立本机 Host 完成，界面不创建项目或会话。

#### KV Cache effect

没有影响。

## Known Limitations and Deferred Work

- 结果只描述本次固定题目表现，不代表职业等级、认证或真实项目验收。
- 同一运行区共享答题记录；不是按账号隔离，也不跨不同运行区同步。
- 中文题目难度、主题可读性与桌面使用体验仍需人工验收。
