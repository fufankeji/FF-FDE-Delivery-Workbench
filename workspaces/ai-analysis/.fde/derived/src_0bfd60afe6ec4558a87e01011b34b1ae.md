## 指标口径

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 核心指标口径 |  |  |  |  |  |  |  |
| 指标名称必须携带口径。支付 GMV、净 GMV、订单退款率和退款金额率不得相互替代。 |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
| 指标 | 业务定义 | 计算逻辑 | 分析维度 | 数据来源 | 更新频率 | 责任人 | 当前问题 |
| 支付 GMV | 支付成功订单金额合计，不扣除后续退款 | SUM(paid_amount)，排除已取消 | 日/渠道/区域/品类 | OMS | 每日 | 经营分析 | 运营日报主口径 |
| 净 GMV | 支付金额扣除已完成退款金额 | 支付 GMV - 已完成退款金额 | 月/渠道 | OMS+售后 | 每日 | 财务/经营 | 退款完成时间与订单时间跨期 |
| 支付订单数 | 发生有效支付的去重订单数 | COUNT(DISTINCT order_id) | 日/渠道 | OMS | 每日 | 经营分析 | 多明细订单必须去重 |
| 客单价 | 支付 GMV / 支付订单数 | 支付 GMV ÷ 支付订单数 | 日/渠道 | OMS | 每日 | 经营分析 | 使用支付 GMV 还是净 GMV 待场景说明 |
| 订单退款率 | 发生已受理退款的订单数 / 支付订单数 | 退款订单数 ÷ 支付订单数 | 周/渠道/品类 | OMS+售后 | 每日 | 经营分析 | 与退款金额率不得混称 |
| 退款金额率 | 退款金额 / 支付 GMV | SUM(refund_amount) ÷ 支付 GMV | 周/渠道 | 售后+OMS | 每日 | 财务 | 按退款发生日还是订单日待确认 |
| 准时送达率 | 实际签收不晚于承诺送达的完成订单占比 | 准时完成订单 ÷ 有承诺日期的完成订单 | 周/仓/承运商/区域 | WMS | 每日 | 节假日和偏远地区规则缺失 |  |
| 30 天复购率 | 首购后 30 天内再次支付的客户占比 | 30 天内复购客户 ÷ 可完整观察首购客户 | 月/渠道 | OMS+CRM | 每周 | 用户增长 | 同日第二单、全额退款订单待确认 |
| 高价值客户 | 近 90 天金额、频次和最近购买综合判断 | RFM 分层，阈值按月版本化 | 月 | OMS+CRM | 每月 | 用户增长 | 当前阈值未冻结 |
| 复购模型召回率 | 实际复购客户中被模型识别为高潜的人数占比 | TP ÷ (TP + FN) | 模型版本 | 模型产物 | 按实验 | 用户增长 | 需求初稿写准确率 80%，需重新确认 |

## 权限与敏感信息

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 字段敏感等级与使用边界 |  |  |  |  |  |
| 以下为初步规则，最终以公司信息安全评审结果为准。 |  |  |  |  |  |
|  |  |  |  |  |  |
| 数据项 | 内容类型 | 敏感等级 | 允许角色 | 使用要求 | 保留建议 |
| 订单号 | 业务标识 | 内部 | 经营分析、供应链 | 可进入项目；对外模型默认不发送 | 按项目保留 |
| 脱敏会员 ID | 可关联个人 | 敏感 | 经营分析、增长 | 仅不可逆映射值；不得与手机号映射共存 | 按项目保留 |
| 手机号 | 个人联系方式 | 极敏感 | 授权客服/增长 | 首期不进入项目、不发送模型 | 不提供 |
| 详细地址 | 个人位置 | 极敏感 | 授权履约人员 | 首期删除，仅保留省市 | 不提供 |
| 支付金额 | 交易信息 | 敏感 | 经营分析、管理层 | 聚合可用于模型；明细需安全评审 | 按项目保留 |
| 商品成本参考 | 商业机密 | 敏感 | 经营分析、财务 | 不进入外部模型 | 按项目保留 |
| SQL 与查询结果 | 分析过程 | 内部 | 项目成员 | 随项目保存，导出时排除凭证 | 不少于 12 个月 |
| 模型 API Key | 系统凭证 | 极敏感 | 系统管理员 | 仅保存在本机受限配置，不进入源码/导出包 | 随配置生命周期 |
