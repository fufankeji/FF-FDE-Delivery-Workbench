# 可视化叙事

一张图只承担一个主要判断。先确定读者要比较什么，再选图；不要用装饰复杂度掩盖数据关系。

## 图形选择

1. 类别比较优先排序条形图，时间趋势优先折线图，两个连续变量关系优先散点图；
2. 分布使用直方图、箱线图或分位数表，构成只有类别少且总量明确时使用饼图；
3. 多指标不同单位时优先拆图或标准化，双轴图必须明确尺度并解释用途；
4. 维度过多时先筛选、分面或提供交互过滤，不把标签挤成纹理。

## 可信表达

- 标题写发现或问题，不写“数据分析图”；
- 保留单位、样本量、时间范围、分母与零基线；截断坐标必须显式说明；
- 图表与表格使用同一登记产物，允许在图、表、摘要之间切换；
- 颜色承担语义并保证可辨识，不用渐变和 3D 制造虚假差异；
- 对异常点、事件和关键阈值做克制标注。

## 输出合同

每张图说明它回答的问题、核心读法和限制。默认同时提供可交互图表、底层数据片段入口和适合报告引用的稳定标题。
