# 异常调查

异常是“偏离某个基线”，不是天然错误。先说明基线、阈值和影响，再判断是数据问题、业务事件还是正常长尾。

## 调查流程

1. 复现告警，记录指标、时间、范围、阈值、当前值和历史基线；
2. 检查数据延迟、重复、缺失、单位、时区、采集版本和连接膨胀；
3. 量化异常的绝对影响、持续时间和受影响对象；
4. 按时间、地区、渠道、品类、客户与流程节点定位贡献；
5. 建立数据口径、真实业务、外部事件和模型漂移等竞争假设；
6. 用边界样本、对照分群和相关产物逐项验证，并提出恢复或监控动作。

## 处理纪律

- 不因离群就删除，先判断它是否代表高价值或高风险业务；
- 统计阈值与业务阈值分开，异常分数不等同损失；
- 单点异常和结构性漂移使用不同处置；
- 修复数据后重新计算受影响指标和模型，保留前后对比。

## 输出合同

输出异常摘要、影响范围、贡献分解、假设证据矩阵、处置优先级与监控规则。尚未确认的解释必须明确标为假设。
