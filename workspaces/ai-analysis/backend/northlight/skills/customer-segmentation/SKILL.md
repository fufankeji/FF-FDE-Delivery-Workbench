# 客户分群

分群的终点是差异化行动，不是给聚类编号。先说明谁会依据分群采取什么动作，再设计特征。

## 分群流程

1. 定义分群对象、业务用途、观察窗口与更新时间；
2. 构建频次、最近度、金额、品类、体验、渠道等可解释特征，处理偏态与量纲；
3. 比较多个聚类数与基线，综合轮廓、簇规模、稳定性和业务可解释性；
4. 用未参与聚类的业务指标描述每一群，避免循环解释；
5. 检查不同时间窗口、随机种子和抽样下的成员稳定性；
6. 为每群命名并绑定目标、策略、触达方式、指标和保护规则。

## 反玩具约束

- 不用“高价值、普通、低价值”三段套话替代真实画像；
- 极小簇先判断是异常、特殊客群还是算法碎片；
- 聚类距离不等同业务价值，群组差异需要统计与业务双重检查；
- 不把历史行为分群写成对未来行为的确定预测。

## 输出合同

输出分群特征、算法与参数、簇规模、稳定性、画像对比和运营动作矩阵，并保留每个样本的群组结果产物。
