## 6. 原型 / API 契约 / 数据映射 / POC 适用性

| 项 | 适用性 | 结论 / 证据位置 |
|---|---|---|
| 交互原型 | **适用** | 需在 M1 前产出可演示的数据接入与分析链路原型；证据：`fde-deliverables/02-solution-design/development-plan.md` WP2/WP3（原型证据文件待建立，候选阶段未落盘演示素材） |
| API 契约 | **适用（候选）** | 前后端（工作台 ↔ FastAPI/SSE 网关、能力服务）需契约；**本阶段未落正式契约文件**，属于待补工件（标记为【未落盘】） |
| 数据映射 | **适用** | 数据源/字段与指标口径映射（CSV/Excel/SQLite/只读副本字段 → 指标），来源见字段清单；**正式映射清单待补** |
| POC | **部分适用** | 单机文件优先已可支撑 POC；是否需面向“仅脱敏字段+本地模型”做专项 POC 需 IT 评审（涉及模型可用性、外发白名单）。当前未见 POC 证据，属待确认 |

> 上述“证据位置”大多为**候选阶段未落盘的工件**，已明确标注【未落盘/待补】，未虚称已完成。
