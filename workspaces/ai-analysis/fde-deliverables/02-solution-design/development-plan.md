## 3. 工作包（候选）

### WP1 需求与数据基线（M0）
- 冻结已确认决策（范围/口径方向/模型/节点）。
- 确认单机部署落地方式：**每分析师独立实例，还是共享本机多项目**（需 IT 决策，见风险 R-5）。
- 整理字段敏感等级、脱敏样例、来源指纹规范。
- 建立验收问题集与对账 SQL（依赖客户提供 10 个问题）。

### WP2 数据接入与画像（M1）
- CSV/Excel/SQLite 导入器；数据源登记为资产（来源指纹、画像、版本）。
- 只读查询引擎（SQL AST、仅 SELECT、限时限行、结果哈希）。
- 样例数据质量检查（覆盖 05 CSV：重复行、缺失、枚举不一致、异常评分）。

### WP3 分析与可视化（M1~M2）
- 数据片段、质量画像、清洗、特征工程（生成新产物，不被覆盖）。
- 表格/柱/折线/散点；图表引用数据片段并记录维度/指标。

### WP4 建模（M2）
- 异步训练进程；登记数据/特征/随机种子/划分/参数/指标/模型/逐行预测。
- 复购预测基线；输出人工复核名单，不自动触达。
- 验收指标：AUC/召回率/F1（替换准确率 80%）。

### WP5 自然语言与可追溯（M2）
- 自然语言入口：引用已选数据与已登记产物；执行前说明计划、执行后给证据。
- 血缘：数据/SQL/图表/模型/报告关系保留；来源变化提示重新运行。

### WP6 报告版本（M2~M3）
- Markdown 底稿 + 引用产物 + 版本化；自包含 HTML 报告。

### WP7 安全与运维（贯穿）
- 敏感字段脱敏/排除；模型/DB 凭证不入源码与导出包；导出排除密码/API Key/日志敏感值。
- 脚本型 Skill 无网络沙箱、受限目录。
- 备份/恢复（项目、数据源配置、报告、模型产物）。

### WP8 试运行与验收（M4~M5）
- 3 名分析师各完成一次独立分析并导出项目。
- 归档文档、部署说明、使用手册、验收记录。

## 4. 实施顺序（候选）

```
WP1 基线/数据就绪(9/1-9/10)
  → WP2 数据接入+只读查询(9/11 前后)
  → WP3 分析/可视化 + WP4 建模(并行推进至9/26)
  → WP5 自然语言/追溯 + WP6 报告(9/26 前闭环)
  → WP7 安全/运维(贯穿, 关键断点评审)
  → M3 国庆演示(10/1)
  → WP8 试运行与验收(10/16-10/30)
```

关键路径：**WP2（数据可用性）→ WP4（模型基线）→ WP6（报告）→ M3 演示**。模型部分受前置数据（复购训练窗口/历史触达记录）供给影响最大。

## 5. 数据与环境准备

| 准备项 | 责任方 | 说明 |
|---|---|---|
| 脱敏样例文件（CSV/Excel） | 业务/IT | 首期验证用；已提供 05 CSV |
| 只读副本 / 每日脱敏文件 | IT | 若提供则接入；非前置 |
| 字段敏感等级 | 业务 | 见字段清单“权限与敏感信息” |
| 10 个验收问题 + 对账 SQL/结果 | 经营分析组 | 正确性验收前置，9/8 前 |
| 历史类目映射 | 商品中心 | 影响历史分析 |
| 节假日/偏远地区规则表 | 供应链 | 影响准时送达率验收 |
| 复购训练窗口 + 历史触达记录 | 用户增长 | 影响复购模型 |

**开发环境**：单机（如 16GB MacBook 或等同）；本地运行后端组件；浏览器前端；脚本在无网络沙箱执行。

## 6. 外部依赖

- **客户/业务**：10 个验收问题与对账 SQL、类目映射、时效规则、复购训练窗口/触达记录（详见第 5 节）。
- **IT**：只读账号/只读副本或脱敏文件、字段敏感等级、部署/安全评审结论、备份策略。
- **模型**：本地/私有模型可用性；若需云模型仅发送脱敏字段 + 聚合（外发白名单待 IT 落地）。

## 7. 风险与应对

| 编号 | 风险 | 影响 | 应对 |
|---|---|---|---|
| R-1 | 正确性验收前置数据未按期提供（10 问题/对账 SQL） | 9/8 后 M1/验收受阻 | 提前催收；先以样例自建口径自测 |
| R-2 | 模型数据缺口（训练窗口/触达记录） | 复购基线无法验收 | 用脱敏/合成数据先跑通；正式指标待数据到位 |
| R-3 | 节假日/类目规则未结构化 | 准时送达率、历史分析不完整 | 先做探索，不冻结验收值 |
| R-4 | 单机部署落地方式未定 | 影响工作区隔离与备份 | M0 前 IT 决策“独立实例 vs 共享本机” |
| R-5 | 报告导出格式（PDF/Word）未确认 | 报告能力范围 | 先做 HTML 自包含；PDF/Word 列为待确认 |
| R-6 | 指标数值与责任人书面版未补 | 口径直采 | 口径方向已确认，数值待书面冻结 |
| R-7 | 模型时间窗口切分未定 | 模型复现/有效性 | 另开专题会确定训练/验证窗口 |
