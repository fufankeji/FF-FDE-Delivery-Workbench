## 1. 产品概述与业务目标

### 1.1 一句话定位
为经营分析师提供一个**本地优先、单机工作的分析工作台**，把「数据接入 → 只读查询 → 质量检查 → 特征工程 → 图表 → 模型实验 → 版本化报告」放进同一个项目，让每个经营问题都能得到**可复核、可追溯**的答案。

### 1.2 业务目标【✅已确认范围】
| 目标 | 当前基线 | 一期期望 | 说明 |
|---|---|---|---|
| 日报效率 | 2~3 小时/天 | ≤30 分钟初稿 | 保留人工确认 |
| 临时问题响应 | 0.5~2 工作日 | 常见问题 ≤30 分钟可复核 | 复杂问题不以“秒级”为目标 |
| 分析可追溯 | 依赖个人文件 | 关键结论可回到数据/SQL/图表/模型 | 至少项目级版本 |
| 模型使用 | 零散 Notebook | 一套可复现复购预测基线 | 验收用 AUC/召回率/F1【✅已确认】 |
| 报告交付 | 手工复制粘贴 | 周报由产物生成、可版本化 | 图表标注来源与版本 |

## 3. 用户 / 业务流程

### 3.1 核心业务场景与期望输出
| 场景 | 典型问题 | 期望输出 |
|---|---|---|
| 经营概览 | 昨日 GMV/订单量/客单价/退款率为何变化？ | 趋势、渠道/区域拆解、异常说明、可复核查询 |
| 履约分析 | 华南仓延迟上升来自承运商、仓库还是商品结构？ | 按仓库/地区/品类/承运商分层的延迟率 + 可回看订单明细 |
| 客户分群 | 新客/复购客/高价值客有何特征？ | 可保存的分群数据片段与画像 |
| 复购预测 | 哪些首购客户 30 天内更可能复购？ | 训练数据/特征/指标/预测 + 人工复核名单，**不自动触达**【✅已确认】 |
| 售后归因 | 某活动期退货率上升是否集中在少数 SKU？ | 异常 SKU、订单明细、活动对比、证据图表 |
| 经营报告 | 把本周确认结论整理成周报并保留版本 | 带数据来源/图表/结论的报告版本 |

### 3.2 典型闭环流程
```
业务问题 → ①说明将使用哪些数据与计划 → ②只读查询 → 结果保存为数据片段
→ ③质量画像 → 清洗/特征工程(生成新产物) → ④图表(引用片段)
→ ⑤模型实验(登记数据/特征/参数/指标/预测) → ⑥报告(引用产物, 版本化)
→ 任一步骤可回溯; 结论可溯源, 数据源变化提示重新运行
```

## 5. 业务规则

- **指标名必须带口径**：支付 GMV / 净 GMV、订单退款率 / 退款金额率分别命名，不得混称。【✅已确认】
- **主口径【✅已确认按候选基线】**：GMV 以“支付 GMV”为主（不扣退款），净 GMV 另存；复购以 30 天为主；**准时送达率因节假日/偏远地区规则缺失，暂不能冻结验收值**。
- **只读约束**：生产库只读账号，查询由 IT 控制；原始数据不得被清洗/建模覆盖。
- **敏感数据**：姓名/手机号/详细地址/身份证不进入首期样例；会员 ID 不可逆映射；订单号可显示。【✅已确认】
- **模型输出**：复购预测只作为人工复核名单，不自动触达；敏感字段不外发，只用脱敏字段+本地/私有模型。【✅已确认】
- **报告规则**：关键结论不可悄悄改写；数据源变化时提示重新运行；图表必须引用已保存产物。

## 7. AI 行为与失败回退

### 7.1 自然语言 / AI 行为
- 输入业务问题 → **先说明将使用哪些数据与执行计划** → 再执行 → 给出**证据链**（数据/SQL/图表/模型），不只是结论。【✅已确认】
- 模型仅接收**脱敏字段/样本与聚合结果**；敏感字段（会员标识/订单号/原始明细）是否发送需白名单 + 安全评审。【✅已确认】

### 7.2 失败与回退
- **无在线模型/凭证**：数据接入、只读查询、数据处理、建模、报告仍可运行（确定性能力独立于模型）。【✅已确认】
- **自然语言对话降级**：模型不可用时对话可降级，但不影响确定性能力。
- **脚本执行安全**：脚本型 Skill 在无网络沙箱、受限目录运行；禁止访问宿主机敏感目录。
- **数据源变化**：旧结果不悄悄改写，提示重新运行。

### 7.3 模型验收与边界
- 复购模型验收用 **AUC/召回率/F1**，替换“准确率 ≥80%”（类别不平衡下准确率失真）。【✅已确认】
- 模型需登记训练数据、特征、种子、算法、交叉验证、验证集指标、逐行预测、复现代码。

## 8. 约束

| 类别 | 约束 |
|---|---|
| 部署 | 数据优先保存在公司电脑/局域网；**单机试点**，不做 20 人局域网并发【✅已确认】 |
| 数据 | 生产库只读；原始数据不覆盖；账号由 IT 配置，不写入源码/交付文件 |
| 安全 | 敏感字段脱敏/排除；模型/DB 凭证不入源码与导出包；脚本沙箱 |
| 性能 | 指定设备 + 指定数据（100 万行）+ 指定 5 类查询，不用模糊“秒级”表述【方案选择，具体待确认】 |
| 浏览器 | Chrome/Edge 当前稳定版；Windows 用户可用 WSL2；是否原生运行待 IT 【未知】 |
| 节点 | 2026-10-01 按“演示核心链路”理解，不称正式上线【✅已确认】 |
