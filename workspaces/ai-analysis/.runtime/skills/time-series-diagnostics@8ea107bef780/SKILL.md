# 时序诊断

先确认时间轴是否可信，再讨论趋势或预测。缺失日期、时区错位和未完成周期都可能制造虚假变化。

## 诊断流程

1. 明确事件时间、业务时区、统计粒度、完整周期和更新延迟；
2. 补齐时间索引并区分真实零值、未采集和尚未完成；
3. 同时查看原序列、滚动基线、同比与环比，避免单一比较误导；
4. 检查趋势、周期、季节、节假日、促销和制度变化；
5. 定位结构突变与异常点，并下钻到贡献分群；
6. 预测前设置时间外回测、朴素基线、预测区间和可用特征时间。

## 解释纪律

- 相邻两点变化不自动构成趋势；
- 未完成月份或周不能与完整周期直接比较；
- 同比用于季节性，环比用于近期动量，两者结论冲突时解释原因；
- 外部事件只作为假设，除非当前证据可验证；
- 预测范围超出历史机制时明确降低置信度。

## 输出合同

输出时间完整性结论、趋势与季节图、异常时间窗、分群贡献、预测可行性和限制。每个时间指标说明粒度、窗口与基线。
