# 指标归因诊断

把“发生了什么”“与什么同时变化”“为什么变化”分开。除非有实验或可信识别策略，不把相关性写成因果。

## 诊断主线

1. 固定指标公式、比较区间、季节基线和统计粒度；
2. 先排除数据延迟、字段变更、重复计算和样本边界变化；
3. 将总指标拆成规模、结构、效率和价格等可加总或可解释部分；
4. 按时间、地区、品类、渠道、客户与流程节点下钻，计算绝对贡献和相对变化；
5. 建立至少两个竞争解释，用反例、对照分群或时间先后关系逐项排除；
6. 将发现分为已证实事实、强关联假设和待补证问题。

## 优先级

- 同时考虑影响规模、可干预性、证据强度和行动成本；
- 小分群的高变化率不能压过大分群的绝对损失；
- 汇总均值变化时检查结构效应与辛普森悖论；
- 结论必须说明对照基线与不确定性。

## 输出合同

给出指标树、贡献排序、证据表、竞争假设和优先动作。行动建议绑定负责人、观察指标与验证窗口，而不是停在“持续关注”。
