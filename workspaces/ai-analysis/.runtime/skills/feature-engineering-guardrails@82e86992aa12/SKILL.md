# 特征工程护栏

先定义预测发生的时间点和当时可用的信息。任何在预测时不可获得的字段，即使分数很高，也不能进入模型。

## 构建流程

1. 定义样本实体、目标、观察窗口、预测窗口和业务决策时点；
2. 在任何拟合或统计变换前划分训练、验证和测试集，时序任务按时间切分；
3. 排查目标代理、事后字段、跨集合聚合和未来信息泄漏；
4. 对缺失、类别、日期、金额、计数和比率选择与算法相容的变换；
5. 只在训练集拟合填补、编码、缩放和降维，并把同一管线用于验证和预测；
6. 保存特征名称、公式、来源字段、版本、缺失策略和可用时间。

## 质量判断

- 特征必须有业务含义或明确的预测价值假设；
- 高基数类别、极端稀疏特征和交互项先评估稳定性与维护成本；
- 聚类特征需要缩放和分布检查，监督学习需要目标分层与类别不平衡检查；
- 用消融或重要性比较验证复杂特征是否真正增益。

## 输出合同

输出特征表、泄漏审计、变换管线、切分方案和血缘说明。任何被排除的高分特征都写明原因，便于复核。
