# F003 · 数据质量、清洗与特征工程

## 用户结果

用户可以对当前项目的表格产物执行质量画像、清洗和特征工程，每一步生成新的可追溯产物，原始来源和上游结果保持不变。

## 行为规格

1. 画像读取明确 Artifact，输出字段类型、空值、唯一值、分布等质量摘要。
2. 清洗支持显式缺失值、重复值、类型/文本等规则；规则和实际影响写入元数据。
3. 特征工程基于明确字段和转换配置生成新列，保留输入字段和转换说明。
4. 所有处理结果写入项目 Derived Artifact，包含父 ArtifactId、参数、行列、路径、哈希和 lineage。
5. 处理服务只能读取当前项目 Artifact，不能通过路径直接读取其他项目或任意文件。

## 边界与失败

- 不原地修改 Source 或输入 Artifact。
- 缺少字段、参数不合法、数据不可转换时拒绝发布新 Artifact。
- 画像/清洗/特征结果是技术证据，不自动成为业务指标口径或模型有效性结论。

## 验收

同一输入依次画像、清洗和特征后，可看到三个新产物及完整父子关系；输入文件哈希不变；错误配置不产生 ready 产物。
