# F004 · 机器学习训练与预测

## 用户结果

用户可以选择当前项目数据产物训练分类、回归或聚类模型，观察异步状态、取消任务，并使用已登记模型对兼容数据生成预测产物。

## 行为规格

1. 训练请求明确 ArtifactId、任务、目标列、特征、算法、随机种子、名称和是否调参。
2. 分类/回归对数值与类别特征建立统一预处理 Pipeline；聚类保留所需转换和簇标签。
3. 训练保存模型 Artifact，元数据包含数据来源、特征、目标、参数、指标、随机种子、版本和复现代码。
4. 模型 Job 使用 `queued/running/succeeded/failed/cancelled` 可观察语义，用户可查询和请求取消。
5. 预测只接受当前项目 compatible 模型与数据 Artifact，输出 Predictions Artifact 和 lineage。
6. 分类支持指标与软投票证据；回归记录误差/拟合指标；聚类记录簇和轮廓等适用指标。

## 边界与失败

- 未选择目标、目标泄漏进特征、特征不存在、数据不足或任务/算法不兼容时拒绝。
- 训练超时/取消不发布 ready 模型；后台任务失败保留诊断。
- 模型指标不自动代表业务可上线；预测不执行自动触达。

## 验收

分类、回归、聚类各可生成带配置/指标/lineage 的模型；兼容原始特征的数据可预测；取消的 Job 不伪装成功。
