# F001 · 报修到本地草稿实施计划

## 现有上下文与复用

复用35份资源、原始SourceId与已存在的56节点图谱。原件保持只读，遵守PSC-001、PSC-002。

## 影响范围

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |
|---|---|---|---|
| backend/ | 尚无应用代码 | 资料读取、规则与图谱、API、持久化 | AC-F001-001, AC-F001-002 |
| frontend/ | 原始品牌资产 | 中文交互工作台 | AC-F001-001, AC-F001-002 |
| docs/ | 本轮系统规范 | 运行和测试交接 | AC-F001-002 |

## 实现方案

遵循Architecture：Node内置HTTP、浏览器ES Module与SVG，无第三方运行依赖。显式拣选样例输入字段，图谱按实体和两跳关系检索，业务规则返回候选。所有写入只进入独立运行目录。

## 实施顺序

1. 资料和业务规则。
2. 本地API和草稿闭环。
3. 交互页面与图谱。
4. 定向验证、启动与交接。

## 依赖与风险

无模型密钥可运行；自由文本规则识别能力有限，明确显示模式；缺失权威合同保持未知。

## 回退策略

停止当前Node服务即可；保留运行记录，原始材料和工作台代码不受影响。
