# F001 · 报修到本地草稿规格

## 目标与可观察结果

在一个有视觉表现力的工作台中完成维修案例操作，真实保留建议、证据和草稿。

## 来源与范围

- 来源需求：REQ-001, REQ-002, REQ-003, REQ-004, NFR-001, NFR-002
- 来源总规格：PSC-001, PSC-002
- 包含已批准的报修、分析、知识、资料与本地草稿；不包含生产或模型调用。

## 用户旅程与状态

打开报修队列，选择案例或新录入；运行后进入待确认；确认记录后保存并读回草稿。失败保留原文并可重试。

## 功能行为

默认优先展示南京案例；提供案例快速切换。分析展示规则、重复候选、相关图谱、设备和维修商候选以及来源、未知项。支持实体详情、资料预览、草稿历史和JSON导出。

## 异常与恢复

缺字段最多提三个关键问题；P0立即提示人工；未知合同不承诺有效；同一操作不重复生成草稿；图谱或资料变化后重算分析。

## 验收标准

### AC-F001-001 · 案例与证据分析

- 来源：REQ-001, REQ-002, REQ-004, NFR-001, PSC-001
- 对应 PRD 验收：AC-001
- Given 原有材料和图谱可读取
- When 选择或新建报修、运行分析并查看关系与来源
- Then 返回真实局部图谱和规则结果，P0优先、未知明确、最终答案隔离、原件保持不变。

### AC-F001-002 · 人工确认与运行

- 来源：REQ-003, NFR-001, NFR-002, PSC-002
- 对应 PRD 验收：AC-002
- Given 具备当前分析与可启动服务
- When 人工确认保存草稿并刷新、重复提交
- Then 草稿可读回且不重复，页面与实际API连接，不能越界派单。

## 开放问题

无阻塞问题；视觉偏好交由用户查看后调整。
