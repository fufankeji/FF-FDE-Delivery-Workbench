# 项目重新界定候选（engagement-reframe，条件产物）

> 状态说明：这是条件候选记录，不是已批准的边界。因现场转述（访谈）、政策边界（SIM-0109）与原始简报在自动派单/费用/应急边界上存在可复现冲突，故形成本候选供有权人裁定。冲突记录保留，不删原候选、不改写历史。尚未推进项目阶段。

## 触发事实

- **原简报边界**（`01-customer-original-brief.md`，发起人原话/目标）：自动读群报修→自动判断故障→自动找维修商→自动派单；三个月上线；至少自动处理 80% 问题。
- **现场转述（03 首轮访谈纪要，均 simulation/inferred，非政策文件）**：
  - 贺敏（区域经理）：未授权任何系统自动派出预计费用超 500 元工单；食安/全店无法交易/烟雾/漏电/漏水扩散须**先人工应急处置**；自动派单需采购、财务、信息安全、区域运营**共同确认，目前无此项批准**；建议仅试点到“生成工单草稿”再由人确认。
  - 宋洁（店长）：可确认 500 元内临时处理，但不能选区域名单外维修商。
- **政策边界（SIM-0109）**：明确禁止正式派单、供应商通知、费用承诺、工单关闭、跨区域读取、生产写入；只能生成建议与本地草稿（草稿尚需沙盒写权限获批）；P0 应急先行；费用分级授权（≤500 店长+运维 / >500 区域经理 / >5000 采购+财务+区域经理）。policy 来源冲突读回节与“禁止把口头/值班表/系统推荐单独当批准”条款进一步收窄自动落点。
- **总部运营总监顾宁邮件（SIM-0108）**：要求保留“自动派单/80%”**作为提案、不写为已批准范围**；正式派单/费用/供应商通知需区域运营、采购、财务、信息安全四方**分别确认**；三个月是“看到试点证据”的目标，不是生产上线承诺。
- **边界冲突点**：原“自动派单、80%、三月”与政策禁止 + 贺敏无授权 + 顾宁“仅提案、需四方分别确认、草稿为止”直接冲突。访谈“重大说法冲突”节与顾宁邮件均明确记录。

## 原边界

- 对象：总部设备运维报修派单，全自动判断/派单。
- 成功标准（发起人期望）：≥80% 报修无需总部人工参与，三个月上线。
- 隐含假设：读群→判断→派单可全自动闭环，且不涉及授权/费用/合规责任问题（此假设未获证据支持，且与政策/邮件授权相反）。

## 新边界（候选，待有权人裁定）

- 自动化**止于“派单草稿 + 人工确认”**：自动补全报修信息、判断候选紧急度等级（P0/P1 附依据）、推荐候选维修商（受区域名单/保修/合同/值班表约束）、生成工单草稿，由总部或区域经理确认后提交。仅限本地草稿写入（需沙盒写权限获批后按 operationId 读回）。
- **应急场景人工先行**：食安/全店无法交易/烟雾/漏电/漏水/碎玻璃等 P0 由人工直接处置，不做自动判断闭环。
- **费用授权硬边界（policy 口径）**：≤500 店长+运维、>500 区域经理、>5000 采购+财务+区域经理；系统不自动承诺费用（适用范围以真实政策为准，待核对）。
- **设备身份与合同冲突**：自动匹配停止、请求现场照片+资产管理员/采购确认，不据值班表或台账单独派单。
- **成功标准改写为可测、可分阶段**：不以“80% 全自动派单”为唯一目标；先验证顾宁邮件三件事（补信息时间、P0/安全/重复更早识别、可人工确认草稿质量与采纳率、漏单/重复/错派率下降）。
- 3 个月作为“看到试点证据”的目标，非生产上线承诺。

> 以上新边界为候选，来源为访谈转述＋仿真政策＋仿真邮件；未获真实有权决策人与四方分别确认前不成立。

## 安全回退

1. P0 应急触发（食安/全店无法交易/烟雾/漏电/漏水/碎玻璃）：先执行门店应急预案并电话升级区域值班，系统不自动派单（policy）。
2. 设备身份冲突（旧标签 vs retired 台账，杭州案例）：停止自动匹配，请求现场照片+资产管理员确认（policy）。
3. 合同元数据 vs 正文冲突（值班表 V-HVAC-02 warning）：转采购确认，禁止可执行维修商建议（policy）。
4. 疑似重复报修或症状-根因分离（南京案例）：去重与故障域判定，仅标重复候选不删除、不自动建第二单（policy；重复根源恰是“自动按第二消息建单”，须在草稿层阻止）。
5. 费用超授权：挂起草稿+证据清单，转授权人审批，系统不承诺。
6. 草稿写超时：标 unknown、不重复创建，按 operationId 读回（policy）。
7. 演练/不可信输入（群聊 08-25、WO-88615）：不得改变权限，标演练。

  - 区域运营、采购、财务、信息安全四方中谁有权分别批准新边界，各自批准入口/文件依据。
  - 500/5000 元额度与区域维修商名单的真实审批人与现行政策版本。
