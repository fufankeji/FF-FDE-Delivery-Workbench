### B. 手工估算（hand-estimated；非正式工时/成本口径）
来源 `01-baseline-and-target-discussion.md`（SIM-0201）与 `04-triage-workload-observation.xml`（SIM-0204）：
- **每月约 286 小时**（SIM-0201 表“总部人工分诊工时 每月约 286 小时”，来源=两名专员工时记录与抽样估算）。
- SIM-0204 观察周（2026-07-13~17，两名运维）10 班次分诊 4050 分钟=67.5 小时/周，×4.24 周 ≈ **286.2 小时/月**；status=`hand-estimated`；文件注明“4.24 周非财务正式工时口径”，未覆盖节假日/促销高峰/极端天气，并行与电话 ±5 分钟内记录误差。
- **三个月合计 ≈ 286 × 3 ≈ 858 小时**（由正确月口径推算，非逐月实测；逐月值未编造）。
- 本口径取代 03 JSON 的旧字段（见 A 节来源冲突注记）。

### C. 客户目标 / Pilot 候选目标（customer target；非已测基线，非生产承诺）
- “80% 免人工 / 三个月上线 / 自动派单”——SIM-0101 发起人目标，保留为提案；SIM-0108/0210 明确非已批准范围。
- 顾宁关注点：**高优先级故障更快进入人工确认**（SIM-0206）。
- **Pilot 候选指标映射（SRC-SIM-0201）**：15 分钟→P1/P2 初步分诊中位（基线 46，仅匹配样本）；2%→明显重复率（基线 7.4%）；2%→首次错误派单率（基线 5.8%）；12%→首次报修信息缺失率（基线 ~31%）。均为 Pilot 候选，非验收承诺，样本不足不得单独作通过依据（SIM-0210）。

## 三、计算规则（SIM-0205 `calculation_rules`，本情景遵守）

- 已测 / 手工估算 / 客户目标 / 项目预测**分栏**，不混算。
- 未确认成本**不合并成单一确定 ROI**。
- 基本情景与下行情景**都须含人工复核负荷**。
- P0/P1 停业与食品损失当前**不使用统一平均金额**。

## 四、风险上限与停止条件

- **风险上限**：未以货币对 P0/P1 停业与食品损失设统一平均金额（SIM-0205）。可承受上限以“P0 应急不延迟、人工复核不超过已确认容量、数据不越批准边界”为界（SIM-0210 停止条件第 1–3 项）。
- **停止条件**：同 `outcome-contract.md`（SIM-0210 五条）。出现任一即由贺敏暂停、顾宁决定收窄/停止。

## 五、结论（候选，非决定）

- 已测基线给出**中位分诊 46 分钟、首次信息缺失率 ~31%、明显重复率 ~7.4%、SLA 违约 ~12.6%**（均有明确口径限制）；**人工分诊为每月约 286 小时（三个月约 858 小时），属手工估算，非财务正式工时口径**（03 JSON 旧字段已判错误，不采用）。
- 但**任何货币化节省、任何“80%/三月”目标、任何单一 ROI 都不可据此成立**；人工 120 CNY/h、错派 260 CNY/单为低置信/未批准/样本受限，仅作候选情景。
- 是否值得继续投入，仍需真实基线 + 财务正式成本 + owner/验证人真实确认；在此之前本文件保持候选、不推进阶段。
