# 门店维修系统

- 根目录由用户指定为现有 `fde-agent`，不重命名、不嵌套另一份项目。
- `frontend/` 保存页面、样式与浏览器代码；`backend/` 保存本地服务、业务规则与测试；`docs/` 保存当前业务系统文档。
- `.fde/`、`fde-resources/`、`fde-deliverables/` 是既有阶段材料，只读复用，不修改阶段决定或知识图谱原件。
- `node backend/server.mjs` 启动同源服务，默认 `http://127.0.0.1:4177`；`node --test backend/tests/*.test.mjs` 运行定向测试。
- 启动前读取 `http://127.0.0.1:4177/api/health`，响应 `ok=true` 且名称为“FF - 门店维修工作台”则复用现有服务，不重复启动。默认停止方式为所属服务终端 Ctrl+C，只处理本项目进程。
- 当前范围为本地开发验证：规则与现有 Semantica 图谱提供候选建议，不调用付费模型，不执行正式派单、通知或费用承诺。
- 运行状态保存在 `.runtime/maintenance/`；测试使用独立临时目录。运行数据不提交 Git。
- 前端名称使用 `FF - 门店维修工作台`，保留原始 FF Logo 与 `@赋范空间 独家研发`。
- 完成标准：真实 API、图谱查询和人工确认后的本地草稿持久化通过定向测试；提供启动地址与第五阶段测试说明。
