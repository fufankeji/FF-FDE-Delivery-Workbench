# 列表页局部修订：去掉阶段导航条

确认来源：用户表示“第一个思路对”，并截图指出八阶段导航条“不需要这里，我们直接可以滑动查看就行”。

## 继承与替换

- 产品形态继承本轮 `product-shape-spec.md`，其上游形态已确认。
- 保留 [round-02 页面功能](../round-02-stage-one-skills-library/page-function-spec.md) 中的七个 Skill、卡片查看／下载、搜索、独立只读详情、真实文件与同版本下载约束。
- 本轮替换旧方案中的“八阶段分类切换条”和“第二至八阶段待接入占位”。列表不再需要阶段 Tab、步骤条、锁定阶段或阶段选择状态。
- 各已接入阶段以“阶段标题＋简介＋该阶段 Skill 卡片”的内容分区按顺序排列，主内容区纵向滚动，不做横向滑动的阶段轮播。
- 首版只接入第一阶段，页面中只呈现第一阶段分区；不为其他阶段生成资产或空白大区块。
- 第一阶段标题和简介继续帮助用户理解卡片所属阶段，不因去掉导航条而去掉阶段语义。
- 从详情返回时恢复搜索与滚动位置，不再恢复不存在的阶段选择器状态。

## 保护范围

原平台侧栏、设置和返回入口保留。候选 1 中的顶部全局导航是已记录的生成偏差，不是本轮获批的平台导航变更。阅读页尚未选视觉方向，本轮不修改或生成阅读页。

## 本轮产物与停止点

沿用户指定的 1 号作一张定向修订图，使用原图作为编辑参考；保留卡片浏览与浅色蓝调的方向，去掉阶段条并回到原侧栏结构。只做视觉，不实现前端；成图后等待用户确认，不自动把修订图登记为最终选中。
