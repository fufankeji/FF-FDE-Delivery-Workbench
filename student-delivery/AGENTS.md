# 学员部署 Agent 入口

此目录是“FF - FDE 交付工作台”的学员源码包。先阅读根 README.md、SOURCE_VERSION.json、DEPLOYMENT_AGENT.md，再进行部署。本次默认任务是部署并交付可用地址，不是重构或续开发。

- 以包内源码与锁文件为准，不另装全局 Harness、不拉取或覆盖最新版上游。
- 从根目录执行源码检查；安装、构建和 Host 启动的工程目录是 upstream/deepseek-harness。
- 无 .git 是正常源码分发。构建前从 SOURCE_VERSION.json 读取 sourceCommit，设置 DSH_CLIENT_COMMIT_HASH；不能编造版本或用 git init 掩盖缺失。
- 始终显式传入本包内的 DSH_HOME。默认导入门店示例至 .runtime/fde-agent-sample；已有目录拒绝覆盖。严禁读取全局或讲师运行区。
- 启动只绑定 127.0.0.1。端口占用则换空闲端口，不能停止其他项目服务。仅在用户明确授权后开放 LAN 或公网。
- 首次浏览需打开启动输出的授权链接。该链接和 Cookie 是临时访问凭据，不得公开或写入交付报告。
- 不读取任何既有凭证库。模型调用前说明服务商、费用与数据外发范围，等待授权；让学员在本机设置中填写自己的模型配置。
- 五案例实验室静态素材已随源码提供，缺失或损坏必须作为交付错误报告，不能按可选项跳过。Semantica 重建环境及真实模型调用仍需独立配置和授权。
- 先安装，再完整构建，之后才启动。某一步失败就停止依赖它的步骤，不改锁文件、不跳过原生模块或报错检查。
- 仅运行手册中的必要检查，不默认录屏、浏览器自动回放或全仓测试。交付访问方式、数据目录、停止/重启方法和未验证项后停止。
- 示例历史材料中的路径与结果仅供阅读，不是目标机配置。不得修改样例摘要以把旧证据伪装为本机新验证。

产品工程子目录的规则供继续开发时使用；本次部署以以上目标和安全边界为准。
