# F010/F016 人工验收问题修复记录

## 用户反馈与根因

- F010 空白阶段提示条比输入卡整体向左错开。`conversation.input.dock` 位于 Composer Stack，InputBar 自身再增加左右各一份 `--dsh-composer-side-clearance`，原阶段条直接使用外层宽度，少算了这两份空间。
- F016 背景只在主内容明显可见。AppFrame 的 sidebar column 与 SidebarRoot 同时绘制 `--dsw-specific-sidebar-fill`，两层透明色叠加后接近不透明，遮住了 body 背景。

## 修复结果

- 阶段提示条改为“外层宽度减去两侧 clearance”，并使用 `--dsh-composer-card-max-width` 与 `margin: 0 auto`，与输入卡共享同一水平轴。
- F016 把侧栏填充调整为浅色 `rgba(235, 244, 254, 0.42)`、深色 `rgba(8, 21, 36, 0.52)`；通过官方稳定 `[data-slot='sidebar']` 地址移除 SidebarRoot 的第二层背景并增加 `blur(14px) saturate(1.08)`，AppFrame 继续保留单层半透明表面和右边界。
- 未修改 Conversation、AppFrame、SidebarRoot 的组件结构、项目状态或主题持久化。
