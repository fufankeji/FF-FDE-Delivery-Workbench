# 知识图谱原生三维渲染修正

## 范围与验收口径

只修改共享图谱展示链路，作用于标准快照的所有项目；不修改 Semantica Provider、项目来源、知识事实或阶段决定。目标是恢复官方三维力导向和动态探索效果，并保留搜索、证据详情、筛选、全屏与用户喜欢的粒子背景。不能以增加虚假节点或关系达到参考图密度。

## 已确认的原因与修正

1. 旧适配器把真实连通分量先做二维模拟、拼排，并写入固定展示深度；渲染器再用 `cooldownTicks(0)` 冻结模拟。现由 `3d-force-graph` 负责唯一三维模拟，输入不含预计算或固定坐标；减少动态效果模式才在后台预热后直接展示稳定结果。
2. 强制容纳所有离群节点的首屏取景把网络缩成远处的一团。现首屏使用上游按节点数量计算的镜头距离；手动重置仍可适应全图。探索视角允许外围节点超出取景边界，可旋转、缩放或适应全图查看，不是 DOM 溢出。
3. 默认展示全部真实关系；只在悬停、选中或社区筛选时展示避让名称。移除节点附加光晕模型，保留原生节点、细中性色连线及独立星空。
4. 自动环绕提供暂停／恢复；拖拽、缩放或选中实体停止自动运动。恢复模拟只发生于初始化后的用户操作，避免过早激活导致上游布局尚未创建的 `tick` 错误。
5. 旧 `.graphHost > div > div` 高度规则把空 `.graph-info-msg` 撑满并覆盖画布下半区。实际命中测试确认透明层截获鼠标。尺寸规则已限定到视口，提示层不再接收鼠标事件。
