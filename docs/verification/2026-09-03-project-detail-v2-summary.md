# 单项目详情八阶段信息优化验证记录

## 调整结果

- 单项目详情顶部按权威 V2 状态显示“第 N/8 阶段”和八阶段名称。
- 新增“当前阶段重点”，展示阶段责任、八阶段位置、项目资料与识别数量、固定记录、未决阻塞、人工阶段门和下一步工作。
- 交付证据按八阶段 Artifact 汇总；通用数据区改为当前输入、Artifact、阻塞与后续评估证据。
- 原六阶段工作区保留已有资料、固定产物、架构、验证、试点和交接能力，但改称“阶段产物档案”，不再表达权威生命周期。
- 零项目资料时使用紧凑行动空态，并复用既有“进入项目交付”动作，不再渲染无内容的大预览画布。
- V2 项目详情使用独立全视口结构；旧生命周期项目继续使用原兼容详情。所有示例位置均由真实 Stage、Source 和 ProjectSurface 数据填充。
- 模板选择只在 Host 明确返回非 V2 生命周期时进入旧兼容页；`undefined/loading/error` 不再被误判为旧项目。进入详情时会主动重读该 Workspace 的阶段，避免项目中心分批加载造成模板永久分叉。
- 长项目名与 Hero 阶段信息改为内容顺排，阶段信息和右侧动作均有无重叠断言；阶段指标压缩间距并增加包含断言，避免说明文字被卡片边界裁切。
- 阶段指标、工作项与 Artifact 使用内联 SVG 表达；主动作恢复业务蓝高亮；1825×1199 时主工作区吸收剩余视口高度，人工门横幅保持在页面底部。
- 字号按全屏响应式合同分层：1586×992 的辅助文字不再沿用 11px 密集排版；1825×1199 下项目与阶段标题为 32px、阶段正文 15px、阶段指标值 17px、下一步标题 24px，并同步放大导航、工作项、Artifact 和人工门文字。
- Hero 使用新生成的无文字分层背景：原始输出 1906×825 PNG，经无尺寸变化的 WebP 编码落盘为 36KB；图片只承担深蓝渐变、轨道、玻璃能量球和光点，项目文字、阶段信息与按钮继续由真实 DOM 渲染；旧内联轨道 SVG 已移除，等待 3081 人工验收背景裁切和文字对比度。
