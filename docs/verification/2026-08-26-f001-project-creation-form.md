## 本次实现

- “新建项目”打开 560px 结构化表单，不再直接打开文件夹选择器。
- 项目名称必填；所属企业／业务方可选。
- 交付周期默认“待确认”，可切换为预计起止日期；缺失日期或结束早于开始会阻止创建。
- 存储位置默认使用 Host 用户目录，并随项目名称实时预览项目目录；“更改”复用官方目录流程选择父目录。
- 创建按顺序执行：新建安全目录 → 注册 Workspace → 必要时设置显示名称 → 保存基础信息 → 进入首个会话。
- “导入已有项目”作为独立次级入口，直接接纳既有目录。
- 企业、周期和规范项目路径写入浏览器持久 Store，并在项目悬浮信息中呈现。
