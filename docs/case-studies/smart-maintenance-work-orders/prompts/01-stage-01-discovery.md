# 阶段 1 提示词：发现高价值问题

## 本阶段释放素材

依次导入，不要一次发送三条提示词：

1. `materials/01-discovery/01-customer-original-brief.md`
2. `materials/01-discovery/02-representative-cases.md`
3. `materials/01-discovery/03-first-interview-notes.md`

## Prompt A：从最近案例还原真实工作

```text
我刚导入了客户原始简报。请先保留客户的原始说法，不要马上设计 AI 方案。请告诉我：为了判断这个问题是否真实、是否值得继续，最少还需要哪一个近期正常案例、哪一个重要异常案例，以及需要找到哪些真正了解流程或拥有决定权的人。未知内容请明确标为待核对。
```

预期内部路由仅供学习对照：工作流资格判断；根据缺口可能追加项目定向、访谈或责任映射。

## Prompt B：比较说法、观察和权限

```text
我又导入了近期代表案例和首轮访谈纪要。请逐项区分项目发起人说法、现场人员陈述、案例中实际发生的事情、系统可能强制的行为和政策授权。重点检查“自动派单”和“80% 自动处理”是否与现场责任和费用权限冲突。保留原始简报，不要静默改写目标；如果冲突足以改变项目边界，请形成可追溯的重新界定候选，并写明安全回退和谁有权决定。
```

预期内部路由仅供学习对照：资格判断＋重大冲突重新界定；可能使用访谈、责任映射和系统勘察。

## Prompt C：形成阶段候选，不代替 FDE 决定

```text
请基于当前已明确引用的材料，形成本阶段可供 FDE 审阅的候选结果：真实工作流、角色、正常与异常路径、当前基线或未测状态、候选业务结果、范围与非目标、人工回退、主要风险、停止条件和仍缺证据。每条关键主张都要能回到具体来源。只维护本阶段固定路径，不创建平行最终稿，也不要把文件生成写成客户已经确认或阶段已经完成。
```

## 人工检查

- 是否真的识别出发起人目标与区域经理权限之间的冲突。
- 是否把案例 B 的“收银机故障”还原成可能的网络故障链。
- 是否保留尚未测量的基线，而不是编造比例。
- 是否生成逐条 evidenceRefs 和固定 Artifact Catalog。
- FDE 审阅后再决定 Go、Revise、Narrow 或 Stop，并记录 revision。
