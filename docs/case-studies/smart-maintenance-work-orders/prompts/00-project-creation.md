# 新建项目操作卡

## 目标

从工作台创建一个真实隔离的新项目，不在 `FDEDeliveryWorkbench` 源码目录中直接运行案例。

## 创建前输入

先阅读：

- `materials/00-project-creation/01-project-card.md`

## 表单填写

| 字段 | 填写值 |
|---|---|
| 项目名称 | 智修协同——连锁门店设备故障智能分诊项目 |
| 所属企业／业务方 | 华东悦邻连锁（仿真） |
| 计划交付周期 | 待确认 |
| 物理目录 | 使用工作台生成的安全 ASCII 名称 |
| 父目录 | 用户明确选择的案例运行区；不得选择 `FDEDeliveryWorkbench` 源码目录 |

## 创建后第一条可复制提示词

```text
这是一个刚创建的独立 FDE 项目。请先确认当前项目身份、阶段和可使用的项目资料入口，不要设计方案、不要创建假产物，也不要推进阶段。请告诉我现在最适合导入什么原始材料，以及第一步应该从哪一个最近发生的真实案例开始。
```

## 预期观察

- 左侧出现新项目及首个普通会话。
- 项目初始阶段为“发现高价值问题”。
- Agent 不应在没有客户素材时声称已经理解工作流。
- 实际 WorkspaceId、SessionId、目录和创建结果写入运行台账。
