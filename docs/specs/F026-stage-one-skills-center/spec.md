# F026 · 平台与课程技能阅读下载规格

## 目标与可观察结果

用户在同一技能中心区分平台内置与课程原版，按来源筛选并搜索，在原列表上打开文件阅读弹窗，再下载相同内容的对应版本。

## 来源与范围

- 来源需求：REQ-034
- 来源总规格：PSC-028
- 包含：第一阶段七个内置方法、用户提供的第 1 课 fde-business-diagnosis 原包、来源筛选和标记、课程归属、搜索、阅读弹窗、多级文件树、Markdown 包内跳转、放大阅读、整包与单文件下载、关闭恢复。
- 不包含：其余阶段、安装、运行、编辑、客户项目导出、外部 Agent 兼容承诺；不改变平台侧栏与阶段内方法。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 统一侧栏 | 打开技能中心 | 读取内置目录并展示已收录课程，内置失败可重试 | 仅目录读取状态 | 默认全部，两类真实卡片 | 分类、搜索、查看、下载 |
| 卡片列表 | 筛选或搜索 | 来源与名称、标识、用途、课程信息匹配，零结果可清除 | 分类与搜索条件 | 匹配卡片 | 查看 |
| 单个卡片 | 查看 | 在列表上叠加只读弹窗 | 当前 Skill / 文件 | 默认 SKILL.md 的 Markdown | 选文件、下载、放大 |
| 阅读弹窗 | 展开文件夹或点击包内引用 | 呈现真实子目录，引用打开文件并展开祖先目录 | 展开目录 / 当前文件 | 不跳离弹窗，不改写原文 | 阅读或下载 |
| 阅读弹窗 | 放大/还原 | 只改变弹窗尺寸 | 阅读窗口状态 | 当前文件与阅读位置保留 | 继续阅读或关闭 |
| 阅读弹窗 | 关闭 | 回到原列表 | 清除详情选择 | 搜索、滚动保留，焦点回到原查看按钮 | 继续浏览 |

## 功能行为

1. 七个内置方法保持 qualify-ai-workflow、fde-orient、knowledge-interview、ownership-map、repo-recon、stakeholder-brief、reframe-ai-engagement 的顺序；新增课程原版卡片，不替换已有卡片。默认全部，分类为全部/平台内置/课程原版，蓝色/紫色标签同时显示文字；课程卡片标明真实课次，内置卡片保留阶段信息。
2. 文件树只包含实际导出文件；不把上游外链或课程模板中的未来产物误作本地文件。阅读和下载来自同一对象。课程原版包含 SKILL.md、agents/openai.yaml、assets 下两个模板和 references 下两个方法文件，不改正文、换行或目录，也不新增平台 README/许可文件。
3. 正文保留现有工作台内容与路径；README 说明本地适配、来源、许可和依赖边界。下载不承诺在其他 Agent 中直接可用。
4. 定稿图只约束内容区；保留原侧栏、设置与其他业务入口。详情功能已确认，视觉无独立定稿。
5. 弹窗打开期间底层列表和侧栏不可操作，键盘焦点留在弹窗内。关闭按钮和遮罩关闭整个弹窗；Escape 在放大时先还原，再次按下关闭。标题与操作区固定，正文和文件目录各自滚动，不因选文件而滚动底层列表。
6. 原版独立于平台适配版维护，收录不等于加入 Agent 调用链；不扫描课程库或移动硬盘其他目录。后续只收录用户明确提供的包，不预建其他课程占位。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 目录加载中或失败 | 加载提示或错误 | 不伪造卡片 | 重试 |
| 搜索无结果 | 无匹配提示 | 保留搜索内容 | 清空 |
| 文件选择或下载失败 | 明确失败原因 | 保留当前 Skill | 重新选择/下载 |

## 验收标准

### AC-F026-001 · 真实列表与入口保护

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 工作台有第一阶段内置目录。
- When 打开、搜索和重试技能中心。
- Then 七个内置方法保留并增加实际课程原版，来源标记与筛选一致；课程归属不冒充平台阶段；无阶段条、虚构数量或执行按钮；平台及项目原入口保持可用。

### AC-F026-002 · 同版本文件阅读与下载

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 用户选中一个 Skill。
- When 在弹窗查看文件、切换放大、下载整包/单文件并关闭。
- Then 默认打开 SKILL.md，Markdown 可阅读，文件树与包一致并可逐级展开，包内相对引用在弹窗跳转且展开目录；课程原文与下载字节一致，来源及实际许可保留；原列表保持挂载且暂不可操作，正文独立滚动，放大不丢文件与阅读位置；关闭按钮/遮罩或非放大状态的 Escape 恢复原列表分类、搜索、滚动和查看按钮焦点，放大状态的 Escape 只还原窗口；不写项目或调用模型。

### AC-F026-003 · 内容区定稿复刻

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 用户确认的 1117×704 内容区裁切图。
- When 用户打开技能中心。
- Then 保留原背景、七卡纹理、图标、搜索与按钮风格，在已确认的分类和课程扩展处增加来源标签与辅助信息；新增区域不宣称原图逐像素复刻，参考字体/DPR未知项与未自动验证项保持显式，视觉由用户人工验收。

## 开放问题

- 无阻塞项；其他 Agent 可移植性与其余阶段不在当前范围。
