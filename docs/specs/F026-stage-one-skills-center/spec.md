# F026 · 平台与课程技能阅读下载规格

## 目标与可观察结果

用户在同一技能中心区分平台内置与课程原版，按来源筛选并搜索，在原列表上打开文件阅读弹窗，再下载相同内容的对应版本。

## 来源与范围

- 来源需求：REQ-034
- 来源总规格：PSC-028
- 包含：第一阶段七个内置方法、用户提供的第 1 课 fde-business-diagnosis 原包、来源筛选和标记、课程归属、搜索、阅读弹窗、多级文件树、Markdown 包内跳转、放大阅读、整包与单文件下载、关闭恢复。
- 不包含：其他阶段迁移、课程原版执行注册、客户项目导出、外部 Agent 兼容承诺；不改变平台侧栏、阶段产物合同或人工决定。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 统一侧栏 | 打开技能中心 | 读取内置目录并展示已收录课程，内置失败可重试 | 仅目录读取状态 | 默认全部，两类真实卡片 | 分类、搜索、查看、下载 |
| 卡片列表 | 筛选或搜索 | 来源与名称、标识、用途、课程信息匹配，零结果可清除 | 分类与搜索条件 | 匹配卡片 | 查看 |
| 单个卡片 | 查看 | 在列表上叠加只读弹窗 | 当前 Skill / 文件 | 默认 SKILL.md 的 Markdown | 选文件、下载、放大 |
| 阅读弹窗 | 点击正文资料引用 | 打开真实参考文件并提供返回正文动作 | 当前文件 | 不显示多层路径，不改写内容 | 阅读或下载 |
| 阅读弹窗 | 放大/还原 | 只改变弹窗尺寸 | 阅读窗口状态 | 当前文件与阅读位置保留 | 继续阅读或关闭 |
| 阅读弹窗 | 关闭 | 回到原列表 | 清除详情选择 | 搜索、滚动保留，焦点回到原查看按钮 | 继续浏览 |

## 功能行为

1. 七个平台条目保留稳定 ID、顺序和阶段职责，改为平台专属中文完整 Skill；保留实质方法与步骤，工具、路径、产物规则适配平台。Agent、阅读与下载共用实际文件包，不另存运行简版或展示快照。
2. 阶段路由、选择优先级、证据与人工决定不变，其他阶段不迁移。课程原版保留原六文件与独立身份，不翻译或注册；分类、搜索、课程信息和其他模块入口继续可用。
3. 阅读弹窗只显示名称、正文和必要动作，不列出文件树、LICENSE、来源仓库、父级路径或元数据代码块。正文引用可继续打开真实配套文件，以单一返回正文动作恢复；不存在的模板输出路径不伪装为文件。
4. 下载保留完整入口、必要参考、模板、共享规则及许可，逐文件与维护源一致；平台包不重复嵌套同名根目录，课程结构不变。
5. 保留焦点、底层锁定、正文独立滚动、放大与 Escape、关闭恢复；失败保持当前上下文并可重试。
6. 浏览和下载不调用模型、不写客户数据、不改变项目阶段；实际执行仍由已授权 Agent 工具完成，不因为标准化而取得额外权限。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 目录加载中或失败 | 加载提示或错误 | 不伪造卡片 | 重试 |
| 搜索无结果 | 无匹配提示 | 保留搜索内容 | 清空 |
| 文件选择或下载失败 | 明确失败原因 | 保留当前 Skill | 重新选择/下载 |

## 验收标准

### AC-F026-001 · 真实列表与入口保护

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 工作台有第一阶段内置目录。
- When 打开、搜索和重试技能中心。
- Then 七个内置方法保留并增加实际课程原版，来源标记与筛选一致；课程归属不冒充平台阶段；无阶段条、虚构数量或执行按钮；平台及项目原入口保持可用。

### AC-F026-002 · 同版本文件阅读与下载

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 用户选中一个 Skill。
- When 在弹窗查看文件、切换放大、下载整包/单文件并关闭。
- Then 默认打开完整中文 SKILL.md 正文，不列出树、上游来源、许可、原始路径或元数据块；引用可在窗内打开并返回，下载含全部必要文件且字节与维护源一致；原列表、焦点、独立滚动、放大和关闭恢复不变，不写客户数据或调用模型。

### AC-F026-003 · 内容区定稿复刻

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 用户确认的 1117×704 内容区裁切图。
- When 用户打开技能中心。
- Then 保留原背景、七卡纹理、图标、搜索与按钮风格，在已确认的分类和课程扩展处增加来源标签与辅助信息；新增区域不宣称原图逐像素复刻，参考字体/DPR未知项与未自动验证项保持显式，视觉由用户人工验收。

## 开放问题

AC-F026-002 在本次标准化中额外要求：文件加载器实际向 Agent 返回的中文正文与页面同源；七个旧内存正文不再注册；单包下载含完整正文、模板、直接依赖与必要许可。仅 UI 简化不算通过。原有阶段、产物、证据和人工决定规则不变。

- 无阻塞项；其他 Agent 可移植性与其余阶段不在当前范围。

2026-09-18：用户纠正完整展示与下载要求，AC-F026-002 的字节一致和原目录保留同时适用于全部七个平台内置条目，替代原四文件适配包方案；保留现有课程和 Agent 运行行为。
