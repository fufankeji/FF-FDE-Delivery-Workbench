# F026 · 第一阶段技能阅读与下载规格

## 目标与可观察结果

用户先浏览第一阶段七个 Skill 卡片，查看用途，进入文件阅读页，再下载相同内容的工作台适配包。

## 来源与范围

- 来源需求：REQ-034
- 来源总规格：PSC-028
- 包含：第一阶段七卡、搜索、独立详情、真实文件树、Markdown、整包与单文件下载、返回恢复。
- 不包含：其余阶段、安装、运行、编辑、客户项目导出、外部 Agent 兼容承诺；不改变平台侧栏与阶段内方法。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 统一侧栏 | 打开技能中心 | 读取内置目录，失败可重试 | 仅目录读取状态 | 七个真实卡片 | 搜索、查看、下载 |
| 卡片列表 | 搜索 | 名称、标识、用途匹配，零结果可清除 | 搜索条件 | 匹配卡片 | 查看 |
| 单个卡片 | 查看 | 独立只读文件页 | 当前 Skill / 文件 | 默认 SKILL.md 的 Markdown | 选文件、下载、返回 |
| 详情 | 返回 | 恢复列表 | 清除详情选择 | 搜索与滚动不丢失 | 继续浏览 |

## 功能行为

1. 仅第一阶段按固定顺序呈现 qualify-ai-workflow、fde-orient、knowledge-interview、ownership-map、repo-recon、stakeholder-brief、reframe-ai-engagement；取消阶段条，4+3 卡片基准，自然纵向滚动。
2. 文件树只包含实际导出文件；不把上游外链误作本地文件。阅读和下载来自同一对象。
3. 正文保留现有工作台内容与路径；README 说明本地适配、来源、许可和依赖边界。下载不承诺在其他 Agent 中直接可用。
4. 定稿图只约束内容区；保留原侧栏、设置与其他业务入口。详情功能已确认，视觉无独立定稿。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 目录加载中或失败 | 加载提示或错误 | 不伪造卡片 | 重试 |
| 搜索无结果 | 无匹配提示 | 保留搜索内容 | 清空 |
| 文件选择或下载失败 | 明确失败原因 | 保留当前 Skill | 重新选择/下载 |

## 验收标准

### AC-F026-001 · 真实列表与入口保护

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 工作台有第一阶段内置目录。
- When 打开、搜索和重试技能中心。
- Then 只呈现真实七项，无阶段条、虚构数量或执行按钮；平台及项目原入口保持可用。

### AC-F026-002 · 同版本文件阅读与下载

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 用户选中一个 Skill。
- When 查看文件、下载整包/单文件并返回。
- Then 默认打开 SKILL.md，Markdown 可阅读，文件树与包一致，来源和许可保留；返回恢复搜索和滚动，不写项目或调用模型。

### AC-F026-003 · 内容区定稿复刻

- 来源：REQ-034, PSC-028
- 对应 PRD 验收：AC-031
- Given 用户确认的 1117×704 内容区裁切图。
- When 用户打开技能中心。
- Then 内容区呈现对应标题、背景、七卡纹理、图标、搜索与按钮；参考字体/DPR未知项与未自动验证项保持显式，视觉由用户人工验收。

## 开放问题

- 无阻塞项；其他 Agent 可移植性与其余阶段不在当前范围。
