## 实现方案

平台内置继续读取已有目录，仅筛选 index=0 / requirements 中明确的七个 ID，再构造 SKILL.md（含名称、触发描述、原正文）、README.md、来源 NOTICE 和 LICENSE。课程原版以单个 JSON 原文快照保存六个 UTF-8 文件的相对路径、完整字符串、内容哈希和课程归属，打包进入当前 Client，不新增 Host 文件扫描或执行接口。SSD 原包是课程维护源，项目内快照是本次收录版本的唯一内容源；后续明确导入时才能更新，不依赖移动硬盘在线，也不另外保存同一份原文目录副本。仅排除 AppleDouble 与 Finder 元数据。

两类共用只读 LibrarySkill 表示，身份使用来源与 Skill ID，原版不覆盖适配版；渲染、单文件下载和 ZIP 共用同一文件字符串。分类默认全部，平台目录失败时课程原版仍可阅读。详情保存当前 Skill、文件、展开目录集合、放大状态和触发按钮；列表持续挂载，关闭后分类、搜索和滚动不变。界面文案归字典，来源及课程内容归数据，颜色归主题。

阅读弹窗复用现有 Modal 外壳，在 SkillsCenter 内处理焦点循环、底层 inert 与滚动锁定，并在关闭或卸载时恢复原状态；不修改共享 Modal 或引入学习平台的 Radix/Tailwind 依赖。参考学习平台的窗内阅读、固定操作区和放大交互，保留现有文件目录/Markdown 与两类下载。Escape 的放大还原在弹窗内拦截，普通关闭交给原 Modal。下载失败提示留在当前弹窗内。

新增课程包已包含真实嵌套目录，因此文件树由实际相对路径构造并递归呈现：保留文件夹箭头、图标、子项缩进及当前选择。打开 Skill 时根目录展开，子目录按需展开；收起只隐藏子项，不更换正文、阅读位置或下载目标。文内引用使用当前文件所在目录解析相对路径，只允许本包实际文件，跳转时展开祖先目录。不存在的输出模板路径保持非链接；外部 URL 不转成本地文件，也不允许越过包根目录。

MarkdownText 增加可选 fileLinks 解析入口，复用既有安全解析与文件按钮样式，不改课程原文或下载内容；普通调用者、外链和流式输出保持原规则。共享组件属于 Web 静态种子，除对应 Client 包 bundle 外，还需重建 Web 外壳并核对在线外壳与项目资源。

## 实施顺序

1. 同步最小规格并通过视觉预检。
2. 实现目录及包生成、列表和阅读返回。
3. 接入授权装饰裁切与 CSS，更新总览同义状态。
4. 定向组件与 ZIP 内容检查、必要构建、主工作树 3080 在线资源核验，交由用户人工确认。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
