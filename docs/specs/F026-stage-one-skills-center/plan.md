## 实现方案

fde/stage/skills 是七个中文 Skill 的唯一维护目录，每个 ID 一个 SKILL.md，必要内容位于浅层 references 与 assets。共享持久化规则位于 qualify-ai-workflow/references/stage-records.md，其他包相对引用；许可位于 _licenses，不注册为 Skill。

Host 复用原生 FileSystemSkillProvider，只扫描固定平台目录并按需读取正文，保留 rank 250 与项目/用户优先级。移除七个旧内存正文注册，其他阶段维持原机制。既有目录接口每次从相同文件读取名称、描述、正文、入口和实际下载文件及哈希，不读取客户或额外用户目录。

前端移除树、路径栏、来源段落和元数据块，只呈现名称与正文；引用可打开已收录资料，辅助阅读提供返回正文按钮。整包和单文件下载共用准确字节，平台包路径不重复增加同名根目录；课程六文件快照不修改或注册。

复用 MarkdownText 的包内引用，焦点、inert、滚动锁定、放大、Escape、关闭恢复保持。旧原版展示快照和导入器在原生加载检查通过后退役，不创建重复备份；固定研究原件仍用于维护和许可溯源。

使用 skill-creator 检查七个入口，并以教学模拟材料做一次独立前测；以真实 registry/provider、目录文件与 ZIP 核验同源、引用和释放，进行定向组件检查、受影响类型与 Host/Client 构建及在线资源核验。不调用计费模型，不自动浏览器验收。

## 实施顺序

1. 同步最小规格并通过视觉预检。
2. 实现目录及包生成、列表和阅读返回。
3. 接入授权装饰裁切与 CSS，更新总览同义状态。
4. 定向组件与 ZIP 内容检查、必要构建、主工作树 3080 在线资源核验，交由用户人工确认。
