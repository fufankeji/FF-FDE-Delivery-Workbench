- 复用 F025 的 skills 页面入口、现有只读 /api/fde-stage/skills、内置正文、共享 MarkdownText/Button/Input。

## 实现方案

技能中心读取已有目录，仅筛选 index=0 / requirements 中明确的七个 ID。浏览器构造 SKILL.md（含名称、触发描述、原正文）、README.md、来源 NOTICE 和 LICENSE；渲染与 ZIP 共用这些字符串。详情只保存当前 Skill、文件和列表返回位置；无需项目身份。字典持有界面文案，主题持有颜色，组件样式不影响其他页面。

## 实施顺序

1. 同步最小规格并通过视觉预检。
2. 实现目录及包生成、列表和阅读返回。
3. 接入授权装饰裁切与 CSS，更新总览同义状态。
4. 定向组件与 ZIP 内容检查、必要构建、3084 在线资源核验，交由用户人工确认。
