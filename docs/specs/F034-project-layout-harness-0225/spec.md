# F034 · 项目操作可达与 Harness rc.5 兼容

## 目标与可观察结果

修复项目详情裁切、阶段/资料入口缺失和输入框遮挡，在已发布的最新 Harness 基座上保留既有 FDE 工作流程。当前用户明确授权三项修复及完成后推送 GitHub，不包括重新打包桌面源码包。

## 来源与范围

- 来源需求：REQ-001, REQ-009, REQ-015, REQ-033, REQ-037, NFR-005, NFR-007。
- 来源总规格：PSC-001, PSC-008, PSC-013, PSC-027, PSC-031。
- 包含：详情页滚动与窄窗口重排、明确的阶段工作台与项目资料上传入口、底部独立输入区域、指定官方版本的三方兼容、定向测试及发布。
- 不包含：修改阶段门、代替人工决定、付费模型调用、自动开启新增实验性插件、覆盖个人偏好、迁移真实用户数据或全量浏览器回放。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 小窗口或浏览器放大 | 打开项目详情 | 纵向滚动、按可用宽度重排 | 无业务写入 | 八阶段、证据和底部操作可达 | 选择阶段 |
| 详情里程碑 | 打开所查看的阶段 | 复用项目工作台导航 | 只改变浏览位置 | 相同项目、所选阶段；历史/未来保持只读 | 浏览或继续当前阶段 |
| 新建项目、零会话 | 上传项目资料 | 复用本地上传与识别能力 | 只新增项目资料 | 成功/失败明确，资料汇总刷新 | 继续整理 |
| 项目阶段工作台 | 输入多行内容、滚动正文 | 输入区域在底部占位 | 草稿保持 | 输入框不覆盖卡片、按钮或页尾 | 显式发送 |
| 旧版本源码 | 更新基座并启动隔离验收 | 保留定制与固定插件 | 不写旧运行区 | 新版能构建、加载既有功能 | 用户体验 |

## 功能行为

1. 详情页不固定裁掉超出视口的内容；窄窗口不将四个统计字段压成竖排。必要的表格/局部横向内容可滚动，不要求所有页面人为产生横向滚动。
2. 里程碑提供明确的打开阶段动作，项目资料提供始终可达的上传控件，不依赖后台隐藏侧栏或已有会话。上传沿现有鉴权、文件落盘、识别和刷新路径，不自动向模型发送。
3. 输入框保留官方单一 Composer 与草稿状态。阶段工作台正文与输入框分配独立空间；历史/未来阶段继续隐藏输入框。普通对话与运行轨迹的既有布局不受影响。
4. 兼容官方已发布版本而非未发布主分支，保留品牌、默认官方皮肤、上下文洞察、实验室素材、Skills、项目状态和权限边界。

## 异常与恢复

| 情况 | 反馈 | 系统行为 | 恢复 |
|---|---|---|---|
| 项目或阶段加载失败 | 原错误和重试 | 不伪造空数据 | 重试或返回项目中心 |
| 上传失败 | 保留明确失败提示 | 不创建会话、不自动发送 | 重新选择文件 |
| 阶段打开失败 | 可见错误 | 不推进项目阶段 | 重试或返回 |
| 升级兼容失败 | 构建/加载错误 | 不覆盖旧运行数据 | 按 Git 检查点恢复代码后重建 |

## 验收标准

### AC-F034-001 · 详情内容与操作可达

- 来源：REQ-015, REQ-033, REQ-037, NFR-007, PSC-013, PSC-027, PSC-031。
- 对应 PRD 验收：AC-013, AC-029, AC-034。
- Given 项目为零会话或存在历史记录，且页面内容超过可用区域。
- When 滚动、选择阶段、打开阶段或上传资料。
- Then 内容不被外层裁切，所选阶段打开准确；上传有真实结果且刷新本项目资料，不生成模型请求。

### AC-F034-002 · 输入框不覆盖正文

- 来源：REQ-037, NFR-005, PSC-031。
- 对应 PRD 验收：AC-034。
- Given 当前阶段可以输入，或正在只读浏览其他阶段。
- When 改变窗口、草稿高度或滚动内容。
- Then 当前阶段输入区在底部独立占位，正文可完整滚动；只读阶段不出现输入框，草稿和其他对话视图行为保留。

### AC-F034-003 · 新版基座保持项目兼容

- 来源：REQ-001, REQ-009, NFR-005, NFR-007, PSC-001, PSC-008。
- 对应 PRD 验收：AC-001, AC-007。
- Given 现有项目、固定插件和前一官方基线。
- When 按锁定的新版构建并隔离启动。
- Then 版本可追溯、插件真实加载，原运行区不被写入；既有源码定制保留，完成后正常推送不覆盖远端历史。

## 开放问题

- 无阻塞产品决定；目标版本及准确提交写入 Plan 与 lock。页面视觉由用户人工确认，不把静态布局断言说成全量视觉验收。
