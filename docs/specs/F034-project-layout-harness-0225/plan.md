# F034 · 实施计划

## 现有上下文与复用

项目详情的 projectV2Detail/projectV2Main 固定高度和隐藏溢出叠加，固定三列压缩中栏。StageWorkbench 通过 data-conversation-composer-overlay 启用 absolute Composer，阶段分别减高度/加底部留白，不能稳定覆盖多行输入。上传已由 ui-fde-sources 持有，新增页面入口复用同一能力，不从隐藏控件广播寻找文件选择器。保持 PSC-001、PSC-008、PSC-013、PSC-027、PSC-031。

官方目标为 2026-11-18 发布的 `dsh-v0.2.2-rc.5` / `9c2670d3bce5275e0d1610272958121af87787bb`。旧基线 `ddac96760b6edf8fa0fe17cbdcf0b512f4c12b2c`，本地检查点 `2e9abf4b547ac735a7ab286b12d4db2ddd567b01`。官方差异共 580 文件，主要包含版本更新、会话导入可选插件、搜索路由与错误处理；Session 格式目录没有代码代际变更。

## 实现方案

先整合上游再修复下游页面，避免在旧契约上修补。只在现有 main 工作树操作；用 Git 对象和带子目录映射的三方合并保存定制，实际冲突逐项处理。外部插件版本不随意升级；仅更新已验证的精确兼容声明和依赖锁。

详情页采用有界外层滚动和自适应网格；标题、统计与记录高度由内容决定，不再由固定三列强行挤压。阶段打开复用 stageView 的 Workspace 隔离浏览选择；不能改变阶段状态。资料上传通过 ui-fde-sources 的共享 Factory 直接挂载到页面，复用原存储、识别和项目刷新通知。

阶段输入区仍由官方 ConversationContent 持有，不重挂载或复制 Composer；仅在 FDE 阶段布局标记下将覆盖布局改为正常占位，并让剩余正文区域滚动。原聊天、运行轨迹和历史阶段隐藏规则不变。

`.runtime/harness-0225-upgrade` 仅保存本轮合并清单和日志，可由 Git 与命令重建，验收后可清理。隔离启动使用一次性目录和公开门店示例，不复制凭据或改写原 home；退出后清理临时验证数据。复用当前依赖树，不新建 worktree 或重复运行时。

## 实施顺序

1. 规格确认、锁定官方标签、记录检查点。
2. 三方整合、兼容依赖与版本声明。
3. 详情滚动和操作入口；阶段 Composer 占位。
4. 定向测试、完整构建、隔离启动和静态资源核验。
5. 同步证据并普通推送 GitHub；不自动重打桌面 ZIP。

## 回退策略

回退按上述 Git 检查点恢复本轮准确文件并重建，禁止 reset --hard 或删除用户运行区。合并输出和 source lock 说明实际升级差异。
