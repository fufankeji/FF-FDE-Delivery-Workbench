# F004 · Skill 路由、Artifact 与证据规格

## 目标与可观察结果

FDE 只需描述业务工作，平台即先选择 AI-FDE 方法 Skill，再按需组合工程 Skill 与 DeepSeek Harness 工具；重要结论持久化为带类型、来源版本、结构成熟度和证据状态的 Artifact，并成为后续 Skill、阶段和六项生产责任的输入。

## 来源与范围

- 来源需求：REQ-007, REQ-018, REQ-019, REQ-026, REQ-028, REQ-029, NFR-011, NFR-012, NFR-014
- 来源总规格：PSC-006, PSC-015, PSC-022, PSC-023
- 本 Feature 包含：方法／工程／工具三层路由、按需加载、业务化推荐、Artifact Catalog、starter／complete 结构成熟度、证据状态、组合引用和生产责任投影。
- 本 Feature 不包含：批量安装全部外部 Skills、替代客户确认、替代 FDE 决定和具体阶段页面内容。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 当前阶段有工作缺口 | 自然语言描述任务或点推荐工作 | 先路由方法，再选择工程能力与工具 | 建立 Skill route | 显示业务名称、原因和预计产物 | 执行或补前置 |
| Skill 形成重要结果 | 审阅候选结果 | 写入版本化 Artifact、结构状态和证据状态 | Artifact 新增版本 | 可预览、校验、引用和追溯 | 继续 Skill 或阶段评审 |
| 六项责任查看 | 查看责任状态 | 聚合相关 Artifact、缺口和批准 | 不改变阶段 | 可见责任证据与未知项 | 补证据或由 FDE 决定 |

## 功能行为

### 主流程

1. 路由器读取项目、阶段、任务、已有 Artifact、权限和工具可用性。
2. 先选择负责业务方法、Artifact 和决策门的方法 Skill，再选择必要的工程 Skill 与真实工具。
3. 只加载本次工作必要的正文与直接参考，向用户显示业务名称、理由和预计 Artifact。
4. Skill 生成候选 Artifact，不能声明客户确认、工具授权、生产证据或阶段推进。
5. Artifact Catalog 保存类型、项目、阶段、版本、上游来源版本、结构状态、证据状态和前序输入引用。
6. 支持的 Artifact 在同一对象上从 starter 演进到 complete；不支持渐进校验的类型不得显示 starter 通过。
7. 六项生产责任从 Artifact 与有权批准中聚合，文档摄取和 Schema 通过本身都不提升就绪状态。

### 业务规则与边界

- `fde-guide` 方法 Skill、43 个工程 Skill、Schema 和模板必须分别逐项审查、固定来源版本并确认许可证后才接入，不因目录存在而可用。
- “已确认”只能来自有权责任人；Agent 结论只能为推断或待验证，直到人工确认。
- 同一 Artifact 新版本不覆写旧版本，后续引用固定版本。
- starter／complete 描述结构成熟度；已确认／推断／待验证描述证据可信度，两者不得互相推断。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 没有合适 Skill | 显示能力缺口和原因 | 不盲目调用相似能力 | 选择普通对话、安装受审能力或调整任务 |
| Artifact 写入或 Schema 校验失败 | 显示未持久化或结构无效 | 不把会话文本或无效对象当交付事实 | 修复后对同一 Artifact 重试 |
| 上游 Artifact 更新 | 显示依赖版本过期 | 保留旧结果并标记需重评 | 选择新版本重新运行 |

## 验收标准

### AC-F004-001 · 无需记 Skill 名称的按需路由

- 来源：REQ-007, REQ-026, REQ-029, NFR-014, PSC-006, PSC-022
- 对应 PRD 验收：AC-005, AC-023
- Given 当前项目、阶段和任务具有确定输入与权限
- When 用户用业务语言发起工作
- Then 平台先选择适用方法，再按需选择工程 Skill 与工具，说明选用原因和预计产物，无合适能力时如实显示缺口且任何 Skill 都不能推进阶段

### AC-F004-002 · 可组合 Artifact 与真实生产责任

- 来源：REQ-018, REQ-019, REQ-028, NFR-011, NFR-012, PSC-015, PSC-023
- 对应 PRD 验收：AC-016, AC-017, AC-025
- Given Skill 生成重要结论或用户上传文档
- When 结果被保存并用于后续工作或生产责任判断
- Then Artifact 具有项目、类型、版本、来源、结构状态和证据状态，后续引用固定版本，Schema 通过或文档摄取不会代替范围、集成、审查、测试或人工批准

## 开放问题

- 两个外部 Skill 来源、Schema 和模板的逐项许可证与内容审查在对应阶段 Feature 实施前完成，不在本共享 Feature 中一次性导入。
