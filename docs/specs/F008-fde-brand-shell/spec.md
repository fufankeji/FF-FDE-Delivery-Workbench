# F008 · FDE 品牌壳规格

## 目标与可观察结果

FDE 从业者打开锁定的官方 DeepSeek Harness Web 空白页时，首先看到赋范 FF 品牌和 FDE 产品身份，而不是官方开发构建品牌；新会话、工作区、Preset 和输入行为保持不变。

## 来源与范围

- 来源需求：NFR-009
- 来源总规格：PSC-013
- 对应 PRD 验收：AC-011
- 本 Feature 包含：两处 FF Logo 的统一小圆角呈现；左上 `FF-FDE工作台`、移除提交短 SHA；中央 `见所未见，成所未成`、移除旧 Hero 文案与 `预览版`；相关可访问文本和聚焦验证。
- 本 Feature 不包含：浏览器标签标题、Sidebar 信息架构、新建项目、工作区语义、普通文件、模型配置、Agent Preset 能力、Composer、颜色主题或其他视觉重构。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 官方 Web 已启动且首次提示已处理 | 用户进入没有会话内容的空白页 | 页面加载官方三栏壳与空白 Hero | 无业务对象变化 | 左上显示小圆角 FF Logo＋`FF-FDE工作台`；中央显示小圆角 FF Logo＋`见所未见，成所未成` | 用户继续选择工作区或后续阶段开发 |

## 功能行为

### 主流程

1. Web 构建复制并使用项目唯一 FF Logo 原始字节。
2. Sidebar 品牌标记使用 FF Logo，名称精确显示为 `FF-FDE工作台`。
3. Sidebar 不显示官方 `DSH Local Build` 或提交短 SHA。
4. 两处品牌标记使用同一 FF Logo，并以相同比例的小圆角呈现。
5. 空白 Hero 标题精确显示为 `见所未见，成所未成`，不增加副标题。
6. 空白 Hero 不渲染 `预览版` 徽标。
7. 新会话、选择工作区、Preset、Composer 和发送控件继续按官方行为工作。

### 业务规则与边界

- Logo 文件必须与 `frontend/public/brand/ff-logo.png` SHA-256 `522944bbaee48d98190c8c5a0a0ac80f05b71b1975838807742a782e2aeceedc` 完全一致，不修改源文件；两处界面实例使用同一小圆角比例，不变为圆形。
- 两处文案逐字使用 `FF-FDE工作台` 和 `见所未见，成所未成`，不自动增加副标题、空格、Preview 或版本号。
- 本 Feature 是品牌表面替换，不把“新会话”重命名为“新建项目”，也不提前实现 FDE 项目语义。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| Logo 静态资源缺失 | 浏览器出现损坏图片或品牌缺失，验收失败 | 不使用官方鲸鱼 Logo 作为静默回退 | 恢复原始 FF Logo、重新构建并验证 HTTP 资源 |
| 品牌插件未加载 | 官方 DSH 品牌可能重新出现，验收失败 | 不宣称 FDE 品牌完成 | 检查构建产物和 Web 插件组合后重启 |
| Hero 文案为空但徽标残留 | 出现空白徽标，验收失败 | 不以 CSS 隐藏文本冒充删除语义 | 修复 Hero 条件渲染并重建 |

## 验收标准

### AC-F008-001 · 左上 FDE 品牌

- 来源：NFR-009, PSC-013
- 对应 PRD 验收：AC-011
- Given 官方 Web 已进入空白页
- When 用户查看 Sidebar 顶部品牌区
- Then 页面按顺序显示小圆角 FF Logo 和精确文字 `FF-FDE工作台`，且不显示 `DSH Local Build` 或提交短 SHA

### AC-F008-002 · 中央 FDE Hero

- 来源：NFR-009, PSC-013
- 对应 PRD 验收：AC-011
- Given 官方 Web 已进入空白页
- When 用户查看中央 Hero
- Then 页面按顺序显示同样的小圆角 FF Logo 和精确文字 `见所未见，成所未成`，不显示副标题、`探索未至之境`、`FDE 一站式交付` 或 `预览版`

### AC-F008-003 · 官方空白页行为保持

- 来源：NFR-009, PSC-013
- 对应 PRD 验收：AC-011
- Given 品牌替换已经生效
- When 用户查看空白页的工作区选择、Preset、Composer 和发送控件
- Then 这些官方控件仍然存在并可达，品牌替换没有新增业务状态或改变其行为

## 开放问题

- 无；浏览器标签标题、Sidebar 语义和空白项目行为不属于本 Feature。
