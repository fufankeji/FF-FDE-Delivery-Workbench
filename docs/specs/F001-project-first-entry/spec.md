# F001 · 项目优先入口与连续工作规格

## 目标与可观察结果

FDE 以项目作为最高层工作单元：新需求先创建使用独立目录的项目并自动进入首个会话；已有多个项目时，可以在左侧按“项目 → 会话”切换工作，并在明确项目下新建会话，不感知 Harness 的 Workspace 术语。

## 来源与范围

- 来源需求：REQ-007, REQ-013, REQ-014, NFR-005, NFR-007, NFR-008
- 来源总规格：PSC-001, PSC-004, PSC-011, PSC-012, PSC-014, PSC-015
- 对应 PRD 验收：AC-007, AC-012, AC-013
- 本 Feature 包含：新建项目主入口与结构化表单；项目名称、可选企业、待确认/预计周期和存储位置；独立导入已有项目；创建目录并进入首个会话；项目分组与会话列表；项目切换恢复最近会话；项目内显式新建会话；移除项目的真实语义。
- 本 Feature 不包含：客户管理、多项目经营看板、项目组合统计、FDE 来源/基线/阶段领域实现、跨项目资产复用或项目模板。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 尚无项目 | 点击“新建项目”，填写名称、可选企业、周期和位置后提交 | 显示表单校验、创建进度与失败反馈 | 创建独立目录、注册 Workspace、保存基础信息并建立首个 Session | 左侧出现使用表单名称的项目及首个“新会话”，中央输入区可用 | 输入客户需求 |
| 已有项目目录 | 在创建表单点击“导入已有项目”并选择目录 | 显示目录选择/注册反馈 | 注册 Workspace 并进入其空白会话 | 左侧出现导入项目 | 继续已有工程 |
| 已有多个项目 | 点击另一个项目名称 | 展开目标项目并寻找最近可恢复会话 | 当前 Session 切换；项目与会话集合不变 | 目标项目及恢复会话高亮 | 继续工作或选择其他会话 |
| 某项目已存在 | 点击该项目行的新增会话动作 | 在显式 WorkspaceId 下建立或复用空白 Session | 该项目会话集合增加或复用空白会话 | 新会话显示在目标项目内并成为当前会话 | 开始新的工作主题 |
| 项目目录或注册失败 | 重试或取消 | 显示真实错误，保留原当前项目 | 不发布半项目或游离会话 | 用户仍停留在原状态 | 重新选择有效目录 |

## 功能行为

### 主流程

1. 左侧全局主动作显示“新建项目”，不再提供脱离项目上下文的全局“新会话”；品牌标识不承担隐式新会话动作。
2. “新建项目”打开结构化表单：项目名称必填；所属企业／业务方可选；计划交付周期默认待确认，也可设置完整且有序的起止日期。
3. 用户可见项目名称与物理目录名分离。表单默认生成 `fde-YYYYMMDD-xxxx` ASCII 目录名并允许编辑；没有已记住根目录时存储位置显示未选择，用户必须主动选择父目录。
4. 用户可勾选“记住为默认项目存储位置”；勾选后后续表单带出该根目录，未勾选时仅当前项目使用所选位置。
5. 表单提交后，系统使用安全目录名在根目录下创建独立目录、注册 Workspace、设置业务显示名称、保存项目基础信息与位置偏好，再建立或复用首个空白会话并进入。
6. “导入已有项目”是表单中的独立次级动作，直接选择既有完整目录并注册，不把目录选择冒充新建项目表单。
7. 左侧导航使用“项目”作为分组名称，每个项目下显示其非归档会话。
8. 点击项目名称时，展开项目并打开该项目最近更新的非归档普通会话；若不存在可恢复会话，才建立首个空白会话。
9. 展开箭头只改变导航展开状态，不打开会话或创建对象。
10. 项目行新增会话动作始终携带该项目的明确身份，不使用当前/最近项目隐式回退。
11. 中央空白态使用“选择项目”；项目注册移除动作明确说明本地目录与会话日志保留。

### 业务规则与边界

- 一个项目对应一个 Harness Workspace；一个项目可以拥有多条 Session，一条 Session 只能归属一个项目。
- 项目切换不创建新会话；只有目标项目没有可恢复会话时才允许创建首个空白会话。
- 新建会话必须显式指定目标项目；没有项目时只允许新建或选择项目。
- 项目目录与 Workspace 注册均成功后才能显示创建成功；当前 Feature 复用官方目录流程和 Workspace/Session 持久化，不伪造项目领域状态。
- “从工作台移除”不删除本地文件或会话日志，移除后的会话遵循官方未分组恢复能力。
- 企业为空和周期待确认都是合法值；设置预计周期时起止日期必须同时存在，且结束日期不得早于开始日期。
- 创建表单中的企业与预计周期是项目初始元数据，不创建客户实体，也不自动进入已确认项目基线。
- 没有默认根目录时不使用 `~` 静默兜底；目录名只允许 ASCII 字母、数字、点、下划线和连字符，必须以字母或数字开头且不能以点结尾。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 目录选择取消 | 保持原项目和会话 | 不创建 Workspace 或 Session | 再次点击“新建项目” |
| 项目注册失败 | 显示无法打开/注册目录错误 | 不进入首个会话 | 重新选择目录 |
| 项目切换时目标会话无法打开 | 保持原当前会话并记录诊断 | 不创建替代会话冒充恢复 | 重试或打开目标项目的其他会话 |
| 项目无可恢复会话 | 显示创建中的空白会话 | 只在该项目下建立首个 Session | 创建失败则保持原项目 |
| 项目被移除 | 明确目录和日志仍保留 | 仅移除 Workspace 注册 | 以后可重新导入目录 |
| 表单校验失败 | 对应字段显示错误且创建按钮不可提交 | 不创建目录、Workspace 或 Session | 修正名称、日期或位置 |
| 目录已存在 | 显示目录冲突并保留表单输入 | 不覆盖目录，不自动改为导入 | 更改名称/位置或选择“导入已有项目” |

## 验收标准

### AC-F001-001 · 新需求创建独立项目

- 来源：REQ-007, PSC-001, PSC-011, PSC-012, PSC-014
- 对应 PRD 验收：AC-007, AC-012
- Given 用户尚无适合承载新需求的项目
- When 用户点击“新建项目”并成功新建或选择独立目录
- Then 左侧出现使用该目录的项目，系统自动进入其首个空白会话，输入区可继续工作；失败或取消不留下半项目

### AC-F001-002 · 多项目切换不制造会话

- 来源：REQ-013, NFR-007, NFR-008, PSC-001, PSC-004, PSC-014
- 对应 PRD 验收：AC-012
- Given 工作台已有至少两个项目且目标项目拥有可恢复会话
- When 用户点击目标项目名称
- Then 目标项目展开并打开其最近更新的非归档普通会话，会话总数不因切换增加

### AC-F001-003 · 项目内新建会话归属明确

- 来源：REQ-013, PSC-004, PSC-014
- 对应 PRD 验收：AC-012
- Given 用户查看任一已注册项目
- When 用户点击该项目行的新增会话动作
- Then 新建或复用的空白会话只出现在该项目下并成为当前会话，不会落入当前或最近的其他项目

### AC-F001-004 · 项目语言与真实移除语义

- 来源：REQ-013, NFR-005, PSC-012, PSC-014
- 对应 PRD 验收：AC-012
- Given 用户查看项目入口、选择器、分组和项目操作
- When 页面呈现这些控件
- Then 用户看到“项目”“新建项目”“选择项目”和“从工作台移除”，不把“工作区”作为产品概念；移除说明明确目录与会话记录保留

### AC-F001-005 · 无项目时不存在游离会话入口

- 来源：REQ-007, REQ-013, PSC-001, PSC-014
- 对应 PRD 验收：AC-007, AC-012
- Given 工作台没有已注册项目
- When 用户进入空白页
- Then 主要入口引导新建或选择项目，输入区保持不可发送，页面没有可创建游离会话的全局动作

### AC-F001-006 · 结构化创建信息可恢复

- 来源：REQ-014, NFR-005, NFR-007, NFR-008, PSC-001, PSC-015
- 对应 PRD 验收：AC-013
- Given 用户打开“新建项目”表单
- When 用户填写必填名称，选择周期待确认或有效日期范围，按需填写企业并使用默认或自选位置创建项目
- Then 首次必须选择项目根目录，业务名称可以使用中文，物理目录使用独立且可编辑的 ASCII 安全名称；项目以填写业务名称显示，企业、周期状态/预计日期、根目录和物理目录信息在重新进入后仍可读取；勾选记住位置后下一次创建自动带出该根目录，未填企业或日期不阻止创建，非法名称、日期、目录名或空位置不创建任何项目对象

## 开放问题

- 项目基础信息当前只用于创建与识别；其后续编辑入口将在项目概览阶段讨论，不属于本次创建表单。
