# F001 · 项目身份与 V2 生命周期任务

## 任务规则

- 每项任务交付一个可独立验证的生命周期结果。
- 只改当前项目解析与直接相关阶段路径，不迁移 V1 数据。
- 只有证据真实存在后才勾选。
