# F001 · 项目身份与 V2 生命周期规格

## 目标与可观察结果

FDE 打开任一项目时，只能看到该项目的资料、会话、阶段、Artifact、代码和证据；V2 项目采用八阶段与人工决定，既有 V1 项目保持原生命周期，任何返回或重评都不删除既有事实。

## 来源与范围

- 来源需求：REQ-001, REQ-003, REQ-004, REQ-005, REQ-009, NFR-001, NFR-002, NFR-003, NFR-005, NFR-006
- 来源总规格：PSC-001, PSC-003, PSC-004, PSC-008, PSC-009, PSC-010, PSC-024
- 本 Feature 包含：项目身份解析、V1/V2 生命周期区分、八阶段状态、Go／Revise／Narrow／Stop 决定、合法返回与历史保留。
- 本 Feature 不包含：阶段页面呈现、Agent 执行、Skill 路由和具体阶段业务产物。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 新建 V2 项目 | 进入项目 | 建立隔离项目身份与阶段 1 | 项目为 active，阶段为 1 | 只出现当前项目事实 | 进入阶段工作台 |
| V2 阶段评审 | FDE 记录决定 | 校验决定、理由和影响范围 | 追加决定并合法迁移或保持 | 可见决定人、时间、理由 | 继续、返回、缩窄或停止 |
| 既有 V1 项目 | 打开项目 | 识别生命周期版本 | 不做隐式迁移 | 原入口和原状态可用 | 按 V1 继续或显式启动迁移讨论 |

## 功能行为

### 主流程

1. 从隔离工作区解析项目身份和生命周期版本。
2. V2 项目加载八阶段当前状态、历史决定和需重评范围。
3. 只有 FDE 明确提交决定后才写入阶段历史并执行合法迁移。
4. 返回阶段时保留资料、会话、Artifact、代码、证据和后续阶段历史，并标记需重评范围。
5. V1 项目继续走既有六阶段路径，V2 文档和代码只维护中文事实源。
6. V2 项目以八阶段 ID、修订号和返回边界作为权威状态；兼容旧入口时，由权威状态确定性投影为旧六阶段名称，不维护可独立变化的第二套进度。
7. 既有六阶段记录只有在项目明确采用 V2 时才按固定规则升级：需求调研→阶段 1、方案设计→阶段 2、项目开发→阶段 4、验证评估→阶段 5、部署试运行→阶段 6、验收移交→阶段 7、项目完成→阶段 8；升级记录保留原状态和时间。

### 业务规则与边界

- 文件生成、构建成功、Agent 建议和工具返回都不能自动推进阶段。
- 项目身份不能从电脑其他目录、最近项目或全局缓存回退推断。
- Stop 是可审计终态，不等于删除项目。
- V2 阶段 3 必须拥有独立状态，不得继续被旧“方案设计”或“项目开发”吸收。
- 返回后的后续阶段只标为需重评，不删除文件，也不把旧结论继续显示为当前有效。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 项目身份缺失或冲突 | 明确显示无法确定当前项目 | 拒绝加载其他项目事实 | 修复项目元数据后重试 |
| 决定保存失败 | 阶段保持原状并显示失败原因 | 不写入部分历史 | 保留输入并重新提交 |
| 返回后的 Artifact 不再适用 | 标记“需重评”而非删除 | 保存原版本与影响范围 | 在目标阶段更新或重新确认 |

## 验收标准

### AC-F001-001 · 项目隔离、V1 兼容与中文事实源

- 来源：REQ-001, REQ-009, NFR-001, NFR-005, NFR-006, PSC-001, PSC-008, PSC-010
- 对应 PRD 验收：AC-001, AC-007
- Given 隔离区中存在 V1、V2 项目及工作区外目录
- When 用户分别打开项目并读取生命周期
- Then 系统只加载当前项目事实，V1 不被静默迁移，V2 规格只维护中文版本

### AC-F001-002 · 八阶段人工决定与可恢复返回

- 来源：REQ-003, REQ-004, REQ-005, NFR-002, NFR-003, PSC-003, PSC-004, PSC-009
- 对应 PRD 验收：AC-003, AC-004, AC-005
- Given V2 项目已有阶段资料、Artifact 和历史决定
- When 文件生成、Agent 建议或 FDE 提交 Go／Revise／Narrow／Stop
- Then 只有 FDE 提交会改变阶段，决定完整留痕，返回不删除已有事实并标记需重评范围

### AC-F001-003 · V2 权威状态与旧入口兼容投影

- 来源：REQ-003, REQ-009, NFR-002, NFR-003, PSC-003, PSC-008, PSC-024
- 对应 PRD 验收：AC-003, AC-004, AC-007
- Given 一个 V2 项目位于任意阶段，或一个既有六阶段项目被 FDE 明确升级为 V2
- When 项目中心、阶段工作台和旧兼容入口同时读取项目进度
- Then 三个入口显示同一权威 V2 阶段的确定性投影，阶段 3 可独立存在，任何入口都不能单独改写另一套阶段状态

## 开放问题

- V1 到 V2 的迁移合同不在本 Feature；若后续需要迁移，先新增独立需求和 Feature。

## 2026-09-07 通用性校正

- 承接：REQ-003, REQ-009；PSC-008, PSC-024；AC-F001-001, AC-F001-003。
- 打开旧项目不迁移记录；旧六阶段完成／返回只接受旧项目，八阶段写入口只接受明确 V2 项目。冲突时保留修订号和历史。
- 确认依据：用户在通用性审计后授权修复；不新增案例专用分支，不改写现有项目数据。
