# F012 · API 文档与受控接口使用任务

## 任务规则

- 当前实现直接复用锁定 `dsh-openapi` 的解析和请求模块；不挂载其进程级静态 API 清单。
- 直接集成 `dsh-openapi` 不等于直接暴露全局 API 目录，项目隔离和安全默认必须经过运行证明。
- 不实现通用网页浏览器、完整 API 管理平台或自动放开写方法。
