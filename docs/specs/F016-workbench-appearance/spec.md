# F016 · 工作台界面主题规格

## 目标与可观察结果

FDE 可以在设置中预览并保存六套内置皮肤，也可以选择一张只在本地处理的自定义背景；保存后工作台全局外观立即切换并在刷新后恢复，浅色、深色和跟随系统继续独立生效。

## 来源与范围

- 来源需求：REQ-021, NFR-005, NFR-011
- 来源总规格：PSC-012, PSC-013, PSC-023
- 对应 PRD 验收：AC-020
- 当前切片包含：“界面主题”设置页；官方原版、大肥鱼拟人、云端猫咪、九天·深空算力穹顶、九天·量子玻璃实验室、九天·晨曦算力网络；皮肤预览；自定义 PNG/JPG/WebP；浏览器内 1920×1080 WebP 裁切和配色；主体焦点；玻璃层；明确保存；刷新恢复；恢复默认；明暗模式适配；真实失败提示。
- 当前切片不包含：皮肤市场、在线下载、跨设备同步、团队共享、项目级主题、把背景传给 Host/Agent，以及 Electron 更新或视觉增强能力。

## 业务对象

| 对象 | 必需字段 | 权威位置 | 边界 |
|---|---|---|---|
| 内置皮肤 | 稳定 id、背景 URL 或空值、四值配色、默认焦点、玻璃层 | F016 固定定义和 Web 静态资源 | 资源版本随产品发布，不复制到用户存储 |
| 自定义背景 | 处理后 WebP Data URL、四值配色、焦点、玻璃层 | 当前浏览器固定 Origin 的本地存储 | 原图不保存、不上传、不进入项目 |
| 已应用主题 | 内置 id 或自定义值、状态、可选错误 | F016 外观控制器不可变快照 | 不拥有浅色/深色偏好，不改变项目状态 |
| 预览草稿 | 待选皮肤/图片、焦点、玻璃层、提示 | 设置组件本地状态 | 未保存前不修改全局主题 |

## 用户旅程与状态

| 前置状态 | 用户动作 | 过程与反馈 | 可观察结果 | 恢复 |
|---|---|---|---|---|
| 首次打开或无有效偏好 | 打开工作台 | 使用大肥鱼拟人默认皮肤 | 全局背景和语义配色已应用 | 可选择官方原版或其他主题 |
| 已有主题 | 打开“设置 → 界面主题” | 读取当前选择并展示六张主题卡 | 当前已保存皮肤明确标记 | 关闭设置不改变主题 |
| 选择内置皮肤 | 点击主题卡 | 只更新预览和待保存说明 | 卡片与预览显示新主题 | 不保存即可离开并保留旧主题 |
| 选择本地图片 | 选择合法图片并调整焦点/玻璃层 | 浏览器创建临时预览，不上传 | 文件名、大小和预览可见 | 取消或换图释放临时 URL |
| 明确保存 | 点击“保存并应用” | 处理完整值、持久写入，成功后一次性应用 | 全局立即切换，刷新后恢复 | 失败保留旧主题并可重试 |
| 恢复默认 | 点击“恢复默认” | 保存大肥鱼拟人稳定 id | 默认皮肤立即恢复 | 不删除内置资源或项目数据 |

## 功能行为

1. “界面主题”作为独立设置区出现，原有“外观”浅色、深色、跟随系统选项继续保留；两个选择互不覆盖。
2. 六套内置皮肤使用稳定 id。`official` 不加载背景和皮肤 Token；其余五套使用随 Web 发布的 1920×1080 WebP 资源。
3. 点击主题卡或选择本地图片只进入预览。只有“保存并应用”成功后才修改全局 DOM、ThemeRuntime Token 和持久值。
4. 自定义图片只接受 PNG、JPEG、WebP，原图不超过 16 MiB；浏览器按 cover 裁切到 1920×1080，编码为 WebP 并提取四值配色。
5. 已应用皮肤通过 ThemeRuntime 可卸载 Token 层适配浅色与深色；系统模式变化只切换对应 Token，不清除皮肤选择。背景必须覆盖工作台全部列，左侧项目/会话栏使用可读的半透明层而不是遮住背景的不透明色块。设置弹窗必须作为文档级全局层覆盖完整视口，不得被侧栏的半透明、模糊或宽度约束压缩。
6. 保存先生成完整可序列化值，再原子写入固定本地键，最后发布并应用。编码、存储或配额错误不清除旧值，不改变已应用主题。
7. 插件卸载或切换到官方原版时，撤销自身背景属性、DOM 标记和全部 Token 覆盖；不删除其他插件写入的样式。
8. 皮肤操作不创建项目文件、Session Event、消息、工具调用、模型请求或观测记录。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复方式 |
|---|---|---|---|
| 文件类型不支持 | 说明只支持 PNG/JPG/WebP | 不解码、不改变预览选择 | 重新选择 |
| 原图超过 16 MiB | 显示大小限制 | 不创建处理任务 | 选择较小图片 |
| Canvas/编码失败 | 显示本机处理失败 | 保留旧主题和旧持久值 | 换图或重试 |
| 处理结果超过本地存储容量 | 显示图片过于复杂或存储不足 | 不清除旧主题 | 换图或使用内置皮肤 |
| 持久值损坏/未知 id | 显示默认皮肤并忽略无效值 | 不部分应用无效内容 | 重新保存任一主题 |
| 静态资源加载失败 | 卡片仍可识别，应用后背景不可用提示 | 不声明加载成功 | 选官方原版或修复发行资源 |

## 验收标准

### AC-F016-001 · 六套内置皮肤可预览、保存和恢复

- 来源：REQ-021, NFR-005, PSC-012, PSC-023
- 对应 PRD 验收：AC-020
- Given 工作台已加载且用户打开“界面主题”
- When 用户依次选择任一内置皮肤并点击“保存并应用”，再刷新网页
- Then 设置页显示六套稳定选项，保存的皮肤全局生效并在刷新后恢复；`official` 完整撤销背景和皮肤 Token，恢复默认回到大肥鱼拟人

### AC-F016-002 · 自定义图片只在本地处理

- 来源：REQ-021, NFR-011, PSC-023
- 对应 PRD 验收：AC-020
- Given 用户选择一张合法 PNG、JPG 或 WebP 图片
- When 用户调整焦点和玻璃层并保存
- Then 图片只在浏览器内裁切为 1920×1080 WebP、提取配色和持久保存，不产生网络、Host、项目、Session 或 Agent 输入，刷新后恢复处理后的背景

### AC-F016-003 · 明暗模式与皮肤相互独立

- 来源：REQ-021, NFR-005, NFR-011, PSC-013, PSC-023
- 对应 PRD 验收：AC-020
- Given 任一图片皮肤已经应用
- When 用户在浅色、深色和跟随系统之间切换
- Then 皮肤身份和背景保持不变，工作台主内容与左侧项目/会话栏共同呈现该背景，左侧以可读半透明层适配；设置弹窗仍覆盖完整视口且内容保持正常双栏宽度；工作台选择该模式对应的表面、文字、边界和强调色，FF 品牌与核心操作持续可辨识

### AC-F016-004 · 失败保留已应用主题

- 来源：REQ-021, NFR-005, NFR-011, PSC-012, PSC-023
- 对应 PRD 验收：AC-020
- Given 工作台已有一个完整保存并应用的主题
- When 新图片校验、解码、编码或本地持久化失败
- Then 页面显示具体失败和可恢复动作，已应用主题、DOM、ThemeRuntime Token 与持久值保持一致且未被新草稿部分覆盖

## 开放问题

- 浏览器清理站点数据会清除个人主题，这是当前 Web 本地偏好的明确边界；跨设备同步不在本 Feature。
- 主题资源随当前 Web 发行版本更新；若未来开放在线主题，必须另行确认来源信任、资源大小、缓存和安全策略。
