# F011 · 阶段 7：生产、采用与验收交接规格

## 目标与可观察结果

FDE 在受控 Pilot 证据基础上完成生产扩展、业务采用、客户验收和责任移交：系统持续产生已定义业务结果，接收团队能够独立操作、监控、接管、恢复和支持，交付物可取得且责任边界明确；培训材料存在或服务在线均不能单独证明交接完成。

## 来源与范围

- 来源需求：REQ-003, REQ-006, REQ-007, REQ-023, REQ-025, REQ-026, REQ-028, NFR-002, NFR-004, NFR-011, NFR-012, NFR-013, NFR-014
- 来源总规格：PSC-003, PSC-005, PSC-006, PSC-019, PSC-021, PSC-022, PSC-023
- 本 Feature 包含：生产就绪复审、范围扩展、采用、SLO／支持、客户验收、交付清单、培训实操、权限和运维责任移交。
- 本 Feature 不包含：Agent 代替客户签署验收、没有接收团队实操的纸面移交、无证据宣称生产价值或自动关闭项目。

## 功能行为

### 主流程

1. 固定读取 Pilot 版本、范围、结果、例外、接管和回滚证据。
2. 复审生产范围、发布门、SLO、支持模式、变更控制、数据责任和业务结果测量。
3. 受批准后扩展生产范围，持续记录业务结果、技术健康、成本、采用、事故和人工接管。
4. 形成交付清单、运维指南、已知问题、培训与实操计划、权限和责任移交记录。
5. 接收团队完成真实启动、监控、故障处理、回滚或恢复练习；客户有权责任人记录接受、有条件接受、退回或终止。
6. 由 FDE 根据生产、采用、验收和交接证据决定进入持续改进、继续本阶段或返回整改。

### 业务规则与边界

- 客户验收结论、签署身份和日期必须由有权人员记录，Agent 不得代填。
- 交付物 `available` 必须以接收方可取得并校验为依据，文件名存在不等于可交付。
- 培训完成必须包含接收团队实操证据；仅参加会议、阅读文档或观看演示不等于能够独立运行。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 生产结果达标但采用不足 | 采用阻塞 | 不以技术指标替代采用 | 补培训、流程或收窄人群 |
| 客户有条件接受 | 条件待关闭 | 保存条件、责任人和时限 | 关闭条件后重新评审 |
| 接收团队实操失败 | 移交未完成 | 运维责任保持原归属 | 补能力并重新演练 |

## 验收标准

### AC-F011-001 · 生产、采用和交接工作按真实责任推进

- 来源：REQ-006, REQ-007, REQ-023, REQ-025, REQ-026, NFR-004, NFR-013, NFR-014, PSC-005, PSC-006, PSC-019, PSC-021, PSC-022
- 对应 PRD 验收：AC-020, AC-022, AC-023
- Given 受控 Pilot 已形成可审阅业务和运行证据
- When 用户准备生产扩展、采用、验收与责任移交
- Then 平台按需路由生产和交接能力，持续展示发布、业务结果、采用、SLO、交付物、实操和下一项责任人动作

### AC-F011-002 · 验收与责任转移拥有人工和实操证据

- 来源：REQ-003, REQ-028, NFR-002, NFR-011, NFR-012, PSC-003, PSC-019, PSC-023
- 对应 PRD 验收：AC-003, AC-020, AC-025
- Given 生产观察期、交付物和接收团队练习已形成记录
- When 客户责任人提交验收结论且 FDE 提交阶段决定
- Then 交付物可取得性、客户接受、培训实操、权限和运维责任分别有证据，缺任一项不伪装完成，只有 FDE 改变阶段

## 开放问题

- 电子签署与企业身份系统不在首轮内置；首轮只记录外部决定的引用、责任人和时间，不伪造签名能力。
