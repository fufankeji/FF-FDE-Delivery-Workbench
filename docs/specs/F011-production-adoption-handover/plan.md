# F011 · 阶段 7：生产、采用与验收交接实施计划

## 现有上下文与复用

- 当前实现与入口：已有部署试运行、验收移交 Artifact、项目进度和运行控制可作为迁移基础。
- 直接复用点：F010 PilotRun、运行证据、Runbook 和采用计划；F004 Artifact 关系。
- 必须保持的现有行为：V1 验收移交文件可读取，但不自动转成 V2 已验收状态。
- 必须保持的 Product Spec 合同：PSC-003, PSC-005, PSC-006, PSC-019, PSC-021, PSC-022, PSC-023。

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |
|---|---|---|---|
| `packages/fde/runtime` | 运行与观测 | 增加生产范围、SLO、采用、支持和观察期事实 | AC-F011-001 |

| `packages/fde/stage` | 阶段决定 | 保存验收结论、条件、FDE 决定和返回影响 | AC-F011-002 |

## 实现方案

以 ProductionServiceReview 聚合生产范围、业务结果、SLO、成本、采用和风险；CustomerHandoff 组合交付清单、运维指南、培训实操、权限和责任转移。阶段工作台沿用统一骨架，中心区域专门投影生产结果趋势、采用、交付物可取得性、验收决定、实操和责任转移。外部客户决定作为引用事件保存，页面只从真实证据计算缺口，不以文件齐备推断验收。

## 实施顺序

1. 固定阶段 7 方法、模板、Schema 和工程 Skills。
2. 适配生产服务、采用、交付、实操和验收 Artifact。
3. 实现生产扩展、观察、采用和交接路由。
4. 构建生产与验收交接工作面。
5. 接入客户决定、责任转移、FDE 决定和条件关闭。
6. 用接受、有条件接受、退回和实操失败场景验证。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| Agent 代录客户接受 | 虚假验收 | 要求责任人、外部引用和人工事件 | 决定测试 |
| 交付包存在但接收方不可取 | 虚假交付 | 独立可取得与校验状态 | Artifact 测试 |
| 培训无实操 | 责任无法转移 | 强制关键操作练习 | Handoff 测试 |

## 回退策略

AC-F011-004 导航收口：ProjectContextSidebar 与 StageWorkbench 复用相同的浏览阶段解析函数；联动测试同时挂载侧栏和正文，并订阅真实浏览控制器，验证自动进入、从两个入口切换和退出重入，不以手动改测试 props 替代联动。

AC-F011-004：移除 deliveryDemo 读取、类型、前端分支与开关，只消费 v2Stages 和项目生命周期。当前验证项目通过现有 complete 接口逐次提交；不直接写 Storage，不改全局门槛。侧栏与正文以当前阶段及 improvementCycles/lastReviewedAt 展示状态；定向验证无演示入口、历史回看及已完成轮数。


验收或交接失败时生产服务按已批准范围继续、收窄或回滚；责任保持在原团队，保留客户条件和实操失败证据，不覆盖 Pilot 与旧交付版本。

## 2026-09-07 授权实施切片

本轮只实施 AC-F011-003，并保持已有评审与返回。共享读取器放在 `upstream/deepseek-harness/packages/fde/project/src/delivery-workbench.ts`，接入已有 `v2-stage-surface.ts`；浏览器沿现有 props 和快照控制器接入 `DeliveryStagePanel.tsx`，不新增全局服务或另一套运行状态。固定类别呈现 生产、采用、客户验收、交付物、接收团队实操，页签为 生产与采用、验收条件、交付清单、责任与实操。

状态文件新增可选 `delivery` 记录，版本 1；旧记录仍能看到原产物但显示专用证据未登记，不自动满足新评审条件。文件摘要变动撤销有效通过；范围、版本、来源与 Owner 必须下钻可见。Stage Skill 同步最小写入格式，不把缺失信息填为成功。读取客户项目真实前序产物，仅创建有来源的阶段准备记录，不运行客户项目的写操作。

顺序：更新合同 → 文件读取与定向测试 → 页签与证据详情 → 接入真实准备数据 → 构建主端口预览。验证仅采用读取器测试、组件交互测试、客户端构建与在线快照；人工视觉验收留给用户。回退时保留 delivery 和全部证据，恢复旧只读展示，不删除项目数据。

生产执行器、实时监控、客户签收工作流、独立 Semantica 生产查询属于未完成项，不因本轮页面交付勾选原 T001–T006。
