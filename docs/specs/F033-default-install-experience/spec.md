# F033 · 默认官方外观与上下文洞察

## 目标与可观察结果

源码新安装直接采用官方原版外观，并能使用已启用的上下文洞察，无需手动复制本机配置或再次安装插件。

## 来源与范围

- 来源需求：REQ-033, REQ-037, NFR-007。
- 来源总规格：PSC-027, PSC-031。
- 包含：新安装默认组合、恢复默认外观、插件版本锁定、既有配置保留。
- 不包含：更改插件内部能力、升级其他依赖、强制迁移用户偏好、调用模型、推送或重打源码包。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 新安装、无皮肤偏好 | 打开平台 | 应用官方原版 | 不新增项目或会话 | 无背景图片，洞察入口可用 | 浏览或配置 |
| 已保存其他皮肤 | 重启 | 恢复合法偏好 | 偏好不变 | 原皮肤保留 | 按需切换 |
| 已选图片皮肤 | 恢复默认 | 保存官方原版 | 仅外观变化 | 图片和皮肤配色撤销 | 继续工作 |
| 已有插件组合 | 启动 | 使用原组合与禁用选择 | 不重写自定义组合 | 不重复加载洞察 | 按需启用/停用 |

## 功能行为

### 主流程

1. 默认皮肤、无效存储回退、恢复默认和设置页默认标记统一为“官方原版”；原皮肤资源和手动选择保留。
2. 新建 Web 与桌面配置共用默认组合，含启用的上下文洞察，随标准依赖安装提供，不从开发者运行目录复制。
3. 已有组合不被默认值强行覆盖，已安装洞察不重复注册；用户仍可停用。

### 业务规则与边界

- 不改变模型、API Key、明暗模式、项目、阶段、历史会话或实验室数据。
- 默认启用不自动提交模型请求或上下文修改操作；上游插件自身的显式操作继续由用户决定。
- 第三方插件保留名称和许可，不伪称官方开发；模型价格、版本查询沿插件既有公开元数据机制，断网不应阻止界面启动。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 皮肤持久值无效 | 现有提示 | 回退官方原版 | 重新保存 |
| 主题保存失败 | 现有保存错误 | 保留旧主题 | 重试 |
| 插件依赖缺失或不兼容 | 安装/加载错误 | 不伪造洞察数据 | 按锁文件安装或修复依赖 |

## 验收标准

### AC-F033-001 · 官方原版为默认

- 来源：REQ-037, NFR-007, PSC-031。
- 对应 PRD 验收：AC-034。
- Given 无有效皮肤偏好或用户已选择图片皮肤。
- When 首次启动或主动恢复默认。
- Then 默认标记、正文、重置提示与实际应用均为官方原版；启动不覆盖合法历史选择，明暗模式不变。

### AC-F033-002 · 新安装直接使用洞察

- 来源：REQ-033, NFR-007, PSC-027。
- 对应 PRD 验收：AC-029。
- Given 从源码按锁文件安装且使用全新默认配置。
- When 启动 Web 或桌面。
- Then 洞察插件可解析并启用且只注册一次；已有用户配置仍可禁用，不要求本机开发者文件或模型凭据。

## 开放问题

- 无阻塞决定。实际洞察统计质量与既有模型会话不属于本次默认配置验收，不调用付费模型。
