# F014 · 用量分析规格

## 目标与可观察结果

项目进入项目开发后，FDE 可以在“用量分析”中跨会话查看 Agent 的真实运行、模型与工具步骤、Token、可选成本、耗时和错误，并清楚知道外部观测是否启用、数据仍在本地、等待发送、发送失败还是已经可在后端查看。外部观测失败不能影响 Agent 工作。

## 来源与范围

- 来源需求：REQ-019, NFR-001, NFR-002, NFR-003, NFR-004, NFR-005, NFR-007, NFR-008
- 来源总规格：PSC-004, PSC-008, PSC-009, PSC-011, PSC-012, PSC-014, PSC-021
- 对应 PRD 验收：AC-018
- 当前切片包含：项目交付中的“用量分析”View；当前 Workspace 全部普通 Session 的运行列表；运行/成功/失败、更新时间、Turn/Step/工具、Token、耗时和可得成本摘要；运行详情入口；观测插件启停与后端状态；内存队列/持久缓冲/失败；可选 Langfuse/OTLP 外部详情；项目切换、刷新和重启恢复；脱敏、截断与失败隔离。
- 当前切片不包含：通用日志检索、完整 APM、基础设施 CPU/内存监控、无限历史留存、默认发送完整 Prompt/工具结果、自动部署 Langfuse、`dsh-maze` 的完整多会话迷宫对比。

## 用户旅程与状态

| 前置状态 | 用户动作 | 过程与反馈 | 可观察结果 | 恢复 |
|---|---|---|---|---|
| 项目处于项目开发或更晚阶段且已有多条会话 | 打开“用量分析” | 按 Workspace membership 聚合本地事件和统计 | 运行列表、状态、Token/耗时/错误与最新活动 | 选择一条运行进入详情 |
| 当前有 Agent 运行 | 保持页面打开 | 本地状态随权威事件刷新 | 当前运行与已结束运行明确区分 | 无需手动刷新 |
| 外部导出未配置 | 查看观测状态 | 不创建网络请求 | 显示“未配置观测服务”，本地摘要仍可用 | 后续配置后启用 |
| 外部导出已启用 | 查看状态或外部详情 | 数据先脱敏，再排队发送 | healthy/degraded、队列/缓冲与外部打开 | 失败自动有限重试 |
| 后端不可用 | Agent 继续运行 | 失败被隔离并进入有界缓冲 | 页面显示错误、最近失败和缓冲数量 | 后端恢复后重试 |
| 切换项目 | 打开另一项目会话 | 取消旧项目请求并重新聚合 | 不显示上一项目运行或指标 | 无需清理 |

## 功能行为

1. “用量分析”作为项目交付中的独立 View，从项目开发阶段开始出现并在后续阶段保留；轨迹解释当前 Session 的事件，用量分析汇总当前 Workspace 的多 Session 运行与资源使用。项目仍处于需求调研或方案设计时不显示该入口。
2. 本地摘要以 Harness 持久 Session Event 为权威来源，至少呈现 Session、状态、最近活动、Turn/Step、工具错误、Token 和可计算耗时；缺少成本配置时显示“未配置”，不推算金额。
3. 运行列表只包含当前 Workspace 的普通会话；子 Agent 作为所属根运行关系呈现，不作为其他项目。
4. 外部导出默认关闭；启用时显示目标类型、当前健康、最近成功/失败、队列和缓冲，不在页面暴露凭据。
5. Prompt、Completion、工具参数/结果和路径在进入队列/缓冲前完成结构化脱敏与长度限制；关闭内容采集时只发送指标和结构。
6. 外部后端失败、超时或配置错误不得抛入 Agent Loop、阻塞 Session 保存或把运行标成失败。
7. 配置 Langfuse 时可以打开项目/Session 对应详情；没有可信映射时只打开后端首页并说明，不猜测 Trace URL。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复方式 |
|---|---|---|---|
| 当前会话不属于项目 | 不显示项目用量分析或提示选择项目 | 不使用最近项目 | 进入真实项目会话 |
| Session 统计仍加载 | 骨架/加载 | 不显示旧项目统计 | 完成后原位替换 |
| 单条 Session 损坏/不可读 | 该行显示不可读 | 其他运行继续显示 | 修复日志或保留诊断 |
| 导出未启用 | “本地观测可用，外部导出未启用” | 不连接后端 | 显式配置并启用 |
| 后端失败 | degraded/unavailable＋错误摘要 | 有界重试/缓冲，Agent 不受影响 | 自动或用户重试 |
| 缓冲达到上限 | 显示淘汰数量 | 按既定策略淘汰最旧记录 | 恢复后端或调整有界配置 |

## 验收标准

### AC-F014-001 · 项目级本地运行汇总

- 来源：REQ-019, NFR-001, NFR-005, NFR-007, NFR-008, PSC-004, PSC-011, PSC-014, PSC-021
- 对应 PRD 验收：AC-018
- Given 当前项目处于项目开发或更晚阶段，并有多条成功、运行中和失败会话，另有一个独立项目
- When FDE 打开“用量分析”并切换项目
- Then 观测入口可用，页面只汇总当前项目真实 Session/Turn/工具/Token/耗时和错误，同项目跨会话可见，另一项目数据不串入；需求调研和方案设计阶段不提前显示该入口

### AC-F014-002 · 外部观测显式启用且先脱敏

- 来源：REQ-019, NFR-001, NFR-002, NFR-003, PSC-008, PSC-011, PSC-021
- 对应 PRD 验收：AC-018
- Given 项目 Session 含 Prompt、工具参数、路径和类似凭据内容
- When 用户明确启用 Langfuse/OTLP 导出
- Then 只有配置允许的内容在脱敏和截断后进入队列，凭据不进入页面、缓冲或外部请求，关闭导出时不产生新外发

### AC-F014-003 · 失败、缓冲与 Agent 主路径隔离

- 来源：REQ-019, NFR-003, NFR-004, NFR-005, NFR-007, PSC-009, PSC-012, PSC-021
- 对应 PRD 验收：AC-018
- Given 外部后端持续超时或返回失败
- When Agent 继续完成多轮模型和工具工作
- Then Session 正常运行和持久化，观测状态变为 degraded/unavailable，失败记录进入有界缓冲或明确淘汰，恢复后按策略重试且不伪造已发送

### AC-F014-004 · 轨迹、用量分析与外部详情边界清楚

- 来源：REQ-019, NFR-005, NFR-008, PSC-004, PSC-012, PSC-021
- 对应 PRD 验收：AC-018
- Given 当前项目存在一条 Session 轨迹和可选外部 Trace
- When 用户在“轨迹”“用量分析”和外部详情之间切换
- Then 轨迹保持当前 Session 事件解释，用量分析保持项目级汇总，外部页面只在可信地址存在时打开；任一页面状态不会替代其他页面的事实

## 开放问题

- Langfuse/OTLP 的实际地址和凭据由用户或部署环境后续配置；本轮实现不得读取其他项目的受保护凭据。
- `dsh-maze` 的多会话对比可作为后续深度调试能力，不进入当前必装范围。
