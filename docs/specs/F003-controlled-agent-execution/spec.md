# F003 · 受控 Agent 执行规格

## 目标与可观察结果

FDE 通过自然语言发起工作时，Agent 在当前项目、最小上下文和获准工具内执行“分析—动作—观察—判断—验证”，用户可查看、停止和审计过程，执行最终以完成、失败、受阻或等待授权结束。

## 来源与范围

- 来源需求：REQ-011, REQ-012, REQ-013, REQ-014, REQ-015, REQ-016, REQ-017, NFR-007, NFR-008, NFR-009, NFR-010
- 来源总规格：PSC-011, PSC-012, PSC-013, PSC-014
- 本 Feature 包含：请求编排、最小能力边界、工具控制、上下文清单、闭环执行、停止与终态。
- 本 Feature 不包含：阶段特有 Skill 正文、客户侧权限系统和阶段推进决定。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 当前阶段工作台 | 输入自然语言请求 | 解释意图、上下文、工具与预期结果 | 建立 operation | 可见执行边界 | 确认高风险动作或开始 |
| operation 运行中 | 查看或停止 | 动作后观察真实结果并验证 | 追加审计事件 | 可见业务步骤与工具证据 | 继续、修订或停止 |
| 需要信息或授权 | 提供或拒绝 | 保持等待态，不无限重试 | operation 进入 waiting 或 blocked | 可见所缺内容 | 补充后续跑或结束 |

## 功能行为

### 主流程

1. 分析请求，只选择当前任务必要的上下文、工具和数据。
2. 向用户展示执行上限；高风险或越权动作先请求确认。
3. 每个工具动作保存请求、输入范围、结果、错误和验证证据。
4. 根据真实观察继续、修订、验证或转人工。
5. 执行在明确终态结束；其结果不能直接改变阶段。

### 业务规则与边界

- 项目归档资料和会话激活上下文是两个独立状态。
- 禁用工具只影响后续调用，不删除历史。
- 未知副作用、权限不足、超时和重复失败必须停止或等待 FDE。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 工具权限不足 | 显示被拒动作与所需权限 | 不尝试替代工具绕过 | 用户授权或调整任务 |
| 上下文引用跨项目 | 显示拒绝原因 | 不加入模型上下文 | 选择当前项目资料 |
| 用户停止 | 显示已停止及已完成动作 | 终止后续调度并保留轨迹 | 可基于现有证据新建 operation |

## 验收标准

### AC-F003-001 · 最小权限下的可审计平台操作

- 来源：REQ-011, REQ-012, REQ-013, NFR-007, NFR-008, PSC-011, PSC-012
- 对应 PRD 验收：AC-009, AC-010, AC-011
- Given 用户提交自然语言请求且工具、数据权限有限
- When Agent 选择并执行平台操作
- Then 只调用获准能力，展示执行上限，所有工具动作和结果可追溯且越权调用被拒绝

### AC-F003-002 · 最小且显式扩展的上下文

- 来源：REQ-014, REQ-015, NFR-009, PSC-013
- 对应 PRD 验收：AC-012, AC-013
- Given 新会话已有项目归档资料但尚未激活全部上下文
- When 用户显式添加或移除资料
- Then 模型只获得当前项目获准内容，归档状态与会话激活状态分别保存

### AC-F003-003 · 可停止的闭环执行与明确终态

- 来源：REQ-016, REQ-017, NFR-010, PSC-014
- 对应 PRD 验收：AC-014, AC-015
- Given operation 正在执行且工具返回成功、失败、需授权或不确定结果
- When Agent 观察、判断、验证或用户停止
- Then 过程按真实反馈推进并以完成、失败、受阻或等待结束，不无限重试且不自动改变阶段

## 开放问题

- 高风险动作的分类表在具体工具接入时补充，但不能弱化最小授权和人工确认合同。
