# F032 · 官方导航接入计划

## 现有上下文与复用

原 `ui-sidebar` 已维护真实面板列表、固定状态和更多菜单；FDE 一级页使用独立固定导航与覆盖面，未复用该列表。复用官方数据与注册，不复制插件/调度器业务。保持 PSC-027、PSC-032。

## 影响范围

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |
|---|---|---|---|
| ui-sidebar | 原生面板及固定状态 | 将现有面板导航提取为共享 Factory，原侧栏与 FDE 共用同一实例数据 | AC-F032-001 |
| ui-entry-customization | 官方更多菜单 | 仅在真正离开菜单进入页面/创建草稿前通知外壳；固定与关闭不切页 | AC-F032-003 |
| ui-fde-project、ui-layout 壳标记 | 一级页面与训练宿主、原生网格 | 保留统一导航，仅释放右侧覆盖面；原生内容对齐导航宽度，隐藏项目专属区域，保留返回来源 | AC-F032-002, AC-F032-003 |
| 规格、架构和包说明 | 合同与使用说明 | 同步导航能力与验证边界 | 全部 |

## 实现方案

共享 Factory 拥有 `sidebar.panellist.actions` 插槽，统一使用 ui-sidebar 现有面板可观察源和固定状态；面板图标继续由原 `sidebar.panel.icon` 提供。原生侧栏只改调用位置，不重写布局或控制器。Factory 支持外壳在明确导航前的回调；缺省保持原行为。

FDE 导航使用原生 Factory，不硬编码三份按钮和菜单项。切入原生页前在 ProjectPageController 保存来源快照并关闭业务内容覆盖面，统一侧栏仍保持可见。通过官方 activePanelId 判断全局页面，因此从项目侧栏进入也采用同一外壳。原生页面模式以限定样式将 AppFrame 网格对齐统一侧栏宽度，隐藏原项目侧栏、右侧工具与拖柄，不改写已保存布局。返回恢复来源快照或原项目会话。显式业务导航清除原生面板选择；实验室单独保留返回面板，iframe 仍常驻。创建插件交给官方草稿视图，不用全局页面覆盖草稿。标准菜单负责 portal、Escape、外部关闭及焦点。

## 实施顺序

本轮视觉反馈只调整 WorkbenchNavigation、其 CSS Module 与 locale：原生列表外增加中文组标题；底部改为上下文返回、设置和轻量产品介绍/署名，保留所有回调。借助既有语义颜色区分当前项与悬停，不改共享 Sidebar Factory 的行为或其他侧栏样式。窄栏沿用 640 px 断点和官方紧凑设置入口，标题仅视觉隐藏。组件测试验证分组、入口顺序、返回和产品介绍；实际外观继续由用户确认。

1. 文档合同与必要追踪。
2. 共享导航 Factory 与官方更多动作通知。
3. FDE 来源恢复、返回入口、分组与窄屏滚动。
4. 定向组件/状态/装配测试，必要构建与在线资源核对。
5. 优先使用现有桌面客户端更新；如需重启 Host，先确认没有执行任务，保留运行数据，交用户人工体验。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| 插槽重复声明 | 客户端激活失败 | 原声明迁到单一 Factory，测试真实装配 | 定向测试 |
| 更多动作绕过外壳 | 原页面遮挡或错误切页 | 仅导航动作触发回调，固定/关闭不触发 | 菜单测试 |
| 来源快照覆盖 | 返回错误项目或丢训练位置 | 独立暂存，不改 labReturn，普通导航清理过期返回 | 控制器测试 |
| 原生样式依赖父容器 | 窄屏裁切或不可达 | 提供同一几何变量、紧凑模式及滚动；最终用户手验 | 样式与人工 |

## 回退策略

只撤回本轮明确变更并重建 Client；没有运行数据迁移。保留原项目、会话、训练和挑战，不使用破坏性 Git 回滚。本轮不推送或替换已交付 ZIP。
