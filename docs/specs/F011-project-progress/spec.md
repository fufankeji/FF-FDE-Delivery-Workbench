# F011 · 项目进度规格

## 目标与可观察结果

FDE 从左侧一级入口进入真正独立的“项目进度”页面，在不进入具体会话的情况下先比较全部项目的阶段、周期和当前工作，再进入单项目始终可见的六阶段交付全景。需求、方案和研发阶段按各自工作对象展开；研发阶段以 Feature、任务证据、真实排期/待确认、里程碑、阻塞和收口产物形成可视化管理视图，文件作为证据按需预览，而不是把所有内容摊平成文档列表。页面不得以透明弹层悬浮在对话上；中央和右侧只显示项目进度内容。候选系统架构必须先引导到该项目“系统架构”页完整审阅，不能在项目进度页直接确认。

## 来源与范围

- 来源需求：REQ-003, REQ-011, REQ-012, REQ-016, REQ-018, REQ-023, REQ-024, NFR-001, NFR-003, NFR-004, NFR-005, NFR-007, NFR-008
- 来源总规格：PSC-001, PSC-002, PSC-003, PSC-004, PSC-005, PSC-006, PSC-007, PSC-011, PSC-012, PSC-014, PSC-015, PSC-018, PSC-020, PSC-024, PSC-026, PSC-027, PSC-028
- 对应 PRD 验收：AC-010, AC-015, AC-017, AC-022, AC-023
- 当前切片包含：左侧一级入口；不透出底层会话的完整页面；可比较的全部项目概览；“全部项目”区域默认卡片并可切换为列表；标准六阶段交付流程、项目阶段分布、交付健康和项目动态等组合图表；真实项目不足以呈现组合效果时使用的、显式标记且不可进入详情的前端演示项目；真实预计周期时间轴；始终保留六阶段方位的项目详情；需求调研三份固定产出与人工门；方案设计项目 PRD 等五份固定文档、系统架构状态与人工门；项目开发核心文档、Feature、任务证据、真实日期/里程碑/阻塞和三份收口产物；Markdown 只读预览与下载；项目资料；进入项目交付；空、加载和失败状态；现有主题与窄窗口适配。
- 当前切片不包含：任务创建/编辑、自动排期、拖拽甘特、自动文档质量判断、风险推断、项目完成百分比、后续阶段的新业务数据或推进门、人员/资源/成本、客户管理、资料编辑、删除、版本管理和跨项目自动执行。

| 层级 | 主要内容 | 可执行动作 | 不承担 |

| 项目概览 | 真实/演示项目构成、标准六阶段流程、阶段分布、交付健康、项目动态、项目身份、当前阶段和周期 | 筛选阶段、切换卡片/列表、切换概览/时间轴、查看真实项目 | 会话、代码、任务编辑、推算完成率、从演示项目进入详情 |
| 交付时间轴 | 有效预计日期项目、今天位置、待确认项目 | 选择项目、返回概览 | 伪造日期、阶段甘特 |
| 单项目交付全景 | 项目身份、真实周期、完整六阶段地图、当前阶段、待重新确认范围、最近返回和当前工作 | 查看阶段说明、进入阶段工作区、进入项目交付；填写原因并二次确认返回上一阶段或重新打开已完成项目 | 任意跳转、自动判断阶段完成、删除后续产物 |
| 阶段工作区 | 该阶段目标、输入、工作对象、产出、缺口和人工门；研发阶段展示 Feature 与任务证据 | 审阅资料、架构与研发证据、预览下载产物、执行既有人工门 | 第二套任务状态、自动排期、后续阶段新逻辑 |
| 产物预览层 | 选中文件的名称、路径、状态、只读正文和下载 | 选择其他产物、下载、关闭预览 | 编辑、移动、删除、脱离当前项目读取 |
| 项目交付 | 现有对话、资料、文件、代码和 Diff | 真实研发交付 | 跨项目汇总 |

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 可观察结果 | 下一步 |
|---|---|---|---|---|
| 位于任意会话/空白状态 | 点击“项目进度” | 左侧栏保留，中央/右侧切到独立页面 | 看不到底层对话、输入框、标题或右侧开发 Dock | 查看项目或时间轴 |
| 已登记多个项目 | 浏览概览/时间轴 | 按 WorkspaceId 读取基础信息与阶段 | 每个项目显示自己的真实阶段、周期和会话数 | 打开项目详情 |
| 用户需要密集比较多个项目 | 在“全部项目”区域切换卡片/列表 | 只改变当前页面的集合呈现方式，不改变阶段筛选、项目数据或页面模式 | 卡片适合看六阶段全貌；列表在同一行比较项目、阶段、周期、会话、状态和近期节点 | 查看真实项目或切回卡片 |
| 只有少量真实项目 | 浏览项目组合预览 | 页面在真实项目之外补充显式标记的前端演示项目，并在统计、图表和卡片中说明真实/演示构成 | 六阶段流程、阶段分布、交付健康和多项目卡片具备可审阅的完整视觉效果；演示项目不写入 Workspace，也不能点击进入 | 继续比较，或打开唯一可交互的真实项目 |
| 用户选择项目 | 点击项目卡或“查看项目” | 页面切换为该项目只读详情 | 显示项目资料清单和真实处理状态 | 选择资料或进入项目交付 |
| 用户进入项目详情 | 查看项目头部与六阶段地图 | 页面突出当前阶段并保留过去/未来阶段方位 | 无论当前阶段内容多长，都能判断“当前第几阶段、之前经过什么、之后去哪里” | 查看当前阶段或选择其他阶段说明 |
| 用户选择非当前阶段 | 点击六阶段地图中的阶段 | 只改变本页查看内容，不提交阶段状态 | 过去阶段可复核已有证据；未来阶段显示高层目标和真实空态，不冒充已开始 | 返回当前阶段或继续审阅 |
| 当前阶段发现仍需补充上游工作 | 点击“返回上一阶段”或“重新打开项目” | 页面要求填写非空原因并进行二次确认；Host 校验 revision 并计算唯一上一阶段 | 成功后显示新当前阶段、最新返回记录和待重新确认范围；全部项目产物保持原位 | 进入返回阶段继续工作，再逐门重新确认 |
| 项目有资料 | 选择资料 | 按 WorkspaceId/SourceId 加载共享预览 | 受支持格式只读显示；失败/不支持有明确说明 | 换资料、重试识别或进入交付 |
| 项目处于需求调研 | 查看“阶段输入/阶段产出” | 分别读取 Source 清单与三份固定文件状态 | 输入与产出不混放；缺失产物逐项显示待生成 | 在项目交付中继续对话或生成产物 |
| 项目已有阶段产出 | 选择一份已有文件 | Host 只按 WorkspaceId 和固定产物标识返回对应 Markdown 原件 | 当前页面显示文件名、路径和只读正文；缺失、读取失败或越界请求不打开预览 | 换一份产物、下载原件或继续核对 |
| 三份产物齐备 | 点击完成需求调研 | 页面显示 FDE 二次确认，Host 重新校验文件、阶段和 revision | 确认后只推进到方案设计；项目进度和项目交付阶段提示读取同一已提交 revision；冲突/缺失保持原阶段 | 进入方案设计并查看系统架构 |
| 项目处于方案设计 | 查看“阶段产出” | 强制刷新项目 PRD 等五份固定文档和当前项目系统架构快照 | 文档可选择预览；候选架构显示“去确认架构”，已确认架构显示不可点击的“已确认 Rn” | 补齐文档或进入系统架构审阅确认 |
| 当前架构为候选 | 点击“去确认架构” | 打开目标项目按 `updatedAt` 最新的可见普通 Session，并选中“系统架构”页；项目进度页不提交确认 | FDE 可阅读完整架构并在架构页点击“确认当前架构” | 返回项目进度继续核对阶段门 |
| 五份文档存在且架构已确认 | 点击完成方案设计 | 页面显示 FDE 二次确认，Host 重新校验文档、架构、阶段和 revision | 确认后只推进到项目开发；项目进度和项目交付提示同步，API 文档入口出现 | 开始项目开发 |
| 项目处于项目开发 | 查看当前阶段工作区 | 页面从现有 Host 快照组织研发核心文档、Feature、任务证据、已声明日期/里程碑/阻塞和收口产物 | 用户先理解模块与研发节奏，再按需打开对应文档；日期缺失继续显示“待确认” | 预览证据、回项目交付继续研发或核对人工门 |
| 用户选择阶段产物 | 点击可预览的真实文件 | 预览层在当前项目和阶段上下文中展开 | 六阶段方位与原工作位置不丢失，可查看正文和下载原件 | 关闭预览或选择其他证据 |
| 用户开始真实工作 | 点击“进入项目交付” | 在目标项目的非归档普通会话中按 `updatedAt` 选择最新一条；没有可恢复会话时才建立或复用首个空白会话 | 独立页面关闭，显示目标项目最近工作的真实对话和开发能力；子 Agent、归档和其他项目会话不参与默认选择 | 继续交付 |
| 尚无项目 | 打开项目进度 | 显示真实空状态 | 不显示示例项目或假统计 | 返回新建项目 |

## 功能行为

1. “项目进度”属于应用一级导航，不属于项目行、会话 View 或右侧 Dock。
2. 页面打开时保留左侧项目/会话导航，但中央和右侧工作内容完全替换；底层对话标题、消息、输入框和 Better Sidebar 不可见、不可点击、不可透出。
3. 页面不使用带透明遮罩的模态框视觉；内容占满可用工作区，背景、滚动和键盘焦点均属于当前页面。
4. 项目概览按 WorkspaceId 汇总名称、可选企业、当前六阶段、周期状态、预计日期和会话数量；缺失值明确显示“未填写/待确认”。
5. 六段状态条只表达阶段位置，不表达完成百分比；时间轴只使用已存在且有效的预计起止日期。
6. 选择项目先进入只读项目详情，不自动切换当前会话。详情按 F002 SourceId 列出资料、格式、大小、保存/预览/识别状态。
7. 项目详情把当前阶段的原始资料列为“阶段输入”；需求调研把 F004 三份固定文件列为“阶段产出”，方案设计把 F018 项目 PRD 等五份固定文档和 F013 系统架构列为“阶段产出”。每次进入项目详情都强制刷新 Host 产物快照，不能用此前缓存掩盖 Agent 新生成的文件或最新架构 revision。已有 Markdown 可在同一页面选择并只读预览；架构显示真实标题、revision 和确认状态。缺失或读取失败不可伪装为可预览，文件存在或架构候选不等于阶段完成。
8. 当前架构存在且未确认时，阶段产出行提供“去确认架构”动作：打开同一项目最新可见普通 Session 并选中“系统架构”页。项目进度页只负责引导，不调用架构确认接口；真正确认只发生在系统架构页的“确认当前架构”。确认后再次进入项目详情时，该行读取 Host 最新快照并显示不可点击的“已确认 Rn”。
9. 当前允许 FDE 通过二次确认完成需求调研或方案设计；F005 Host 分别复核三份需求文档，或五份方案文档加已确认架构，并只推进一个固定阶段。Agent 无同等动作。Host 成功返回后，页面更新自己的项目阶段读模型，并通知项目交付阶段提示重新读取同一 Workspace 的已提交值。
10. 项目详情可以只读预览资料和重试本地识别，不提供文件编辑、删除、移动或自动 Agent 动作。
11. 只有“进入项目交付”或“去确认架构”才切换到明确目标 Workspace/Session；默认目标是该 Workspace 中按 `updatedAt` 最新的非归档普通 Session。子 Agent Session 不参与；没有可恢复 Session 时才调用官方 Workspace 连接动作建立或复用首个空白会话。“去确认架构”在打开 Session 后额外选择系统架构 View；失败时留在当前详情并显示原因。
12. 关闭或再次点击“项目进度”返回此前项目交付；除明确的人工阶段确认外，不改变阶段、资料或会话内容。
13. 项目概览必须把“项目身份、当前阶段编号与名称、六阶段相对位置、真实周期/待确认”组织为可横向比较的主信息；项目总数和会话数可以作为辅助摘要，但不能抢占主层级或代替交付状态。
14. 单项目详情顶部始终提供带六个完整阶段名称的交付地图，明确区分已经经过、当前和尚未开始/未知；内容滚动、切换阶段工作区或打开产物后仍保留可恢复的阶段方位。
15. 点击阶段地图只改变当前页面的查看阶段，不修改 Host 当前阶段、revision、项目文件或 Session。当前阶段必须持续具有最强视觉标识；查看过去或未来阶段时同时保留“项目当前处于……”提示，避免把查看位置误认为项目状态。
16. 阶段工作区按阶段对象组织：需求调研以项目资料和三份固定产物为核心；方案设计以五份方案文档和系统架构为核心；项目开发以核心文档、Feature/任务证据和收口产物为核心。后续阶段只显示现有数据能够证明的内容或真实空态，不复用研发文档冒充阶段专属产物。
17. 项目开发的 Feature 可视化只使用 F020 快照：状态直接显示已声明值，未知为“状态待确认”；任务显示真实勾选数并明确称为“任务证据”，没有任务时不显示进度条；日期、里程碑和阻塞只在事实存在时展示，日期缺失显示“待确认”。任务比例不得命名为项目或 Feature 完成百分比。
18. 固定产物和 Feature 文档仍通过原受控文件地址读取。预览以覆盖层、抽屉或其他渐进展开方式出现，必须保留项目身份、六阶段方位和原工作位置；关闭预览后回到原上下文，下载继续使用原同源地址。
19. 页面完全复用现有工作台主题变量、字体、圆角、边界和交互状态，不引入独立主题。宽窗口优先呈现项目/阶段关系，窄窗口按“方位 → 当前工作 → 证据”顺序纵向重排；不得因主题背景或窄窗口隐藏当前阶段、核心状态、返回路径和主要动作。
20. 项目详情在需求调研之外提供“返回上一阶段”；`completed` 使用“重新打开项目”。首次点击只展开原因和影响说明，只有非空原因与第二次确认才提交。页面不发送目标阶段，成功后刷新同项目阶段和项目快照。
21. 人工返回后的六阶段地图把当前阶段之后至返回前原阶段显示为“待重新确认”，并显示最新 from/to/原因/时间。返回不删除、移动或重命名会话、文档、源码、报告和交付物；重新前进仍复用原阶段人工门。
22. 当系统至少已有一个、但不足以形成多项目组合效果的真实项目时，概览可以补充前端内置演示项目，用于展示六阶段分布、交付健康、近六周动态和项目比较。演示项目必须持续显示“演示项目/演示数据”，只存在于当前页面的展示视图，不创建 Workspace、Session、文件或阶段状态，不进入项目详情，也不参与任何写操作。真实项目仍从现有数据源读取并保持唯一可交互身份；系统没有真实项目时继续显示真实空状态。
23. “全部项目”区域提供独立于“项目概览/交付时间轴”的卡片/列表视图切换，首次打开默认卡片且不持久化偏好。两种视图复用同一阶段筛选、真实/演示项目集合和查看项目动作；列表不得形成第二套数据或导航逻辑，演示项目在列表中继续明确标记并禁用进入。

## 产品语言

- 页面与入口使用“项目进度”；单项目工作入口使用“进入项目交付/返回项目交付”。
- 只读资料区域使用“项目资料”。
- 不使用 Dashboard、驾驶舱、控制面、执行面等包装性命名。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复 |
|---|---|---|---|
| 项目列表整体失败 | 整页失败说明 | 保留左侧导航和原交付状态 | 重试或返回 |
| 单项目阶段失败 | 仅该项目失败 | 其他项目继续显示 | 单项目重试 |
| 资料列表失败 | 项目详情保留，资料区域报错 | 不伪造空清单 | 原位重试 |
| 资料预览失败/不支持 | 预览区说明原因 | 不改变识别和原件 | 下载或进入交付 |
| 阶段产出预览失败 | 当前产出预览区说明原因 | 不改变文件状态、确认状态和项目阶段 | 重新选择、刷新项目详情或进入项目交付检查原件 |
| 去确认架构失败 | 留在当前项目详情并显示原因 | 不提交架构确认、不切换其他项目 | 重试或通过“进入项目交付”手动打开系统架构 |
| 日期无效/缺失 | 待确认或不可用 | 不画时间轴项目条 | 修正项目基础信息 |
| 查看未来阶段但没有阶段专属数据 | 显示阶段目标与“尚未开始/暂无可核对产物” | 不复用当前阶段产物、不生成示例内容 | 返回当前阶段或进入项目交付 |
| Feature 没有任务或日期 | 显示“暂无任务证据”或“待确认” | 不画空进度条、不把文档存在算作完成 | 回项目交付补充真实 docs 后刷新 |
| 产物预览打开/关闭 | 预览层显示加载、失败或正文 | 保留当前项目、查看阶段和原工作位置 | 关闭后回到原上下文或下载原件 |
| 进入项目失败 | 留在详情并显示原因 | 不回退最近项目 | 重试目标项目 |

## 验收标准

### AC-F011-001 · 左侧一级完整独立页面

- 来源：REQ-016, NFR-005, NFR-007, PSC-018
- 对应 PRD 验收：AC-015
- Given 用户位于任意项目会话或空白状态
- When 点击左侧“项目进度”
- Then 左侧导航保留，中央和右侧完全替换为项目进度；底层对话、输入框和开发 Dock 不可见/不可操作，页面不是透明悬浮框，也不出现在“对话/轨迹”页签中

### AC-F011-002 · 汇总全部真实项目状态

- 来源：REQ-016, NFR-007, NFR-008, PSC-001, PSC-002, PSC-015, PSC-018
- 对应 PRD 验收：AC-015
- Given 登记了多个信息和阶段不同的项目
- When 项目进度加载完成
- Then 每个项目按 WorkspaceId 显示自己的真实信息、六阶段位置和会话数，同名或当前会话不会造成串用

### AC-F011-003 · 时间轴不补造数据

- 来源：REQ-016, NFR-005, NFR-008, PSC-015, PSC-018
- 对应 PRD 验收：AC-015
- Given 一部分项目有有效预计日期，另一部分待确认
- When 用户查看交付时间轴
- Then 只有有效日期项目显示时间条，待确认项目不获得默认日期、假阶段分段或假完成率

### AC-F011-004 · 明确进入目标项目交付

- 来源：REQ-016, NFR-007, NFR-008, PSC-004, PSC-014, PSC-018
- 对应 PRD 验收：AC-015
- Given 用户正在一个明确项目的详情中
- When 点击“进入项目交付”
- Then 独立页面关闭并进入该项目按更新时间最新的可见普通会话；归档、子 Agent 和其他项目会话不参与默认选择；只有没有可恢复会话时才建立或复用首个空白会话；失败时留在当前详情且不切换其他项目

### AC-F011-005 · 项目详情审阅同一来源

- 来源：REQ-016, NFR-005, NFR-007, NFR-008, PSC-003, PSC-018, PSC-024
- 对应 PRD 验收：AC-015
- Given 目标项目已有多种项目资料
- When 用户打开项目详情并选择资料
- Then 资料按同一 WorkspaceId/SourceId 显示名称、格式、大小、处理状态和只读预览；详情不创建第二套文件身份、不提供工程编辑，也不触发 Agent

### AC-F011-006 · 需求调研输入、产出与人工门清晰分层

- 来源：REQ-003, REQ-011, REQ-012, REQ-016, NFR-001, NFR-004, NFR-005, NFR-008, PSC-005, PSC-006, PSC-007, PSC-018, PSC-026
- 对应 PRD 验收：AC-010, AC-015
- Given 当前项目处于需求调研且拥有任意数量原始资料与标准产物
- When FDE 查看项目详情并按需确认完成需求调研
- Then 阶段输入与三份阶段产出清晰分开，已有产出可在同页选择并只读预览真实文件；缺失项不补造，文件存在不冒充确认；只有 FDE 二次确认且 Host 校验通过后进入方案设计，并让项目交付中的同项目阶段提示重新读取并显示新 revision

### AC-F011-007 · 方案设计产出与人工门清晰分层

- 来源：REQ-003, REQ-012, REQ-016, REQ-018, REQ-023, NFR-001, NFR-004, NFR-005, NFR-008, PSC-005, PSC-006, PSC-007, PSC-018, PSC-020, PSC-027
- 对应 PRD 验收：AC-017, AC-022
- Given 当前项目处于方案设计，并有任意数量固定文档和零到一个当前系统架构
- When FDE 查看项目详情并按需确认完成方案设计
- Then 项目 PRD 等五份固定文档和系统架构清晰列为阶段产出，已有文档可预览；进入详情会刷新真实产物快照；候选架构提供“去确认架构”并进入同项目最新普通 Session 的系统架构页，项目进度不直接确认；架构页确认后返回显示不可点击的“已确认 Rn”；缺失和候选不冒充完成；只有五份文档存在、架构已确认、FDE 二次确认且 Host 校验通过后进入项目开发，并让同项目阶段提示刷新

### AC-F011-008 · 多项目首先表达交付方位

- 来源：REQ-016, NFR-005, NFR-007, NFR-008, PSC-001, PSC-002, PSC-015, PSC-018
- 对应 PRD 验收：AC-015
- Given 已登记多个名称、阶段和周期状态不同的项目
- When FDE 打开项目进度概览
- Then 每个项目以一致层级显示项目身份、当前阶段编号与名称、六阶段相对位置和真实周期/待确认，用户无需进入会话即可横向比较；会话统计只作辅助，不代替交付状态，也不生成项目完成百分比

### AC-F011-009 · 单项目始终保持六阶段全局方位

- 来源：REQ-016, NFR-005, NFR-007, PSC-002, PSC-018
- 对应 PRD 验收：AC-015
- Given 一个项目存在已提交的当前阶段
- When FDE 进入项目详情、查看任一阶段工作区或打开/关闭产物预览
- Then 六个完整阶段名称、已经经过/当前/尚未开始状态和真实当前阶段始终可辨识；选择其他阶段只改变查看内容，不修改阶段、revision、文件或 Session，也不会把查看位置冒充当前状态

### AC-F011-010 · 不同阶段按工作对象呈现

- 来源：REQ-003, REQ-011, REQ-012, REQ-016, REQ-018, REQ-023, REQ-024, NFR-005, NFR-008, PSC-005, PSC-018, PSC-020, PSC-024, PSC-026, PSC-027, PSC-028
- 对应 PRD 验收：AC-010, AC-015, AC-022, AC-023
- Given 项目分别处于需求调研、方案设计或项目开发
- When FDE 打开该阶段工作区
- Then 需求阶段围绕项目资料和需求产物组织，方案阶段围绕五份方案文档和系统架构组织，研发阶段围绕核心文档、Feature/任务证据和收口产物组织；页面不再只替换同样式文档列表，后续阶段没有专属数据时显示真实空态

### AC-F011-011 · 研发进度只可视化真实证据

- 来源：REQ-003, REQ-016, REQ-024, NFR-001, NFR-005, NFR-008, PSC-005, PSC-018, PSC-028
- 对应 PRD 验收：AC-015, AC-023
- Given 项目开发快照中包含任意数量 Feature、任务、日期、里程碑、阻塞和固定产物
- When FDE 查看项目开发阶段
- Then 页面能先看出 Feature/模块及其状态、任务证据、节奏和阻塞，再按需查看文档；任务只显示真实勾选数，零任务不显示进度条，未知状态/日期/里程碑明确待确认，任务比例不被命名为项目或 Feature 完成百分比

### AC-F011-012 · 产物预览保持进度上下文

### AC-F011-013 · 返回上一阶段需要原因且保留全部产物

### AC-F011-014 · 单项目环境可预览多项目组合效果
