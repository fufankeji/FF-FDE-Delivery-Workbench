# F006 · 阶段 2：定义结果、范围与责任规格

## 目标与可观察结果

FDE 将已观察的工作流转成可承担责任的结果合同：明确合格工作、基线、被接受结果、独立验证者、目标、归因、完整成本、风险上限、非目标、责任人、Pilot 时限和停止条件，并判断是否值得继续投入。

## 来源与范围

- 来源需求：REQ-003, REQ-006, REQ-007, REQ-018, REQ-019, REQ-025, REQ-026, REQ-028, NFR-002, NFR-004, NFR-011, NFR-013, NFR-014
- 来源总规格：PSC-003, PSC-005, PSC-006, PSC-015, PSC-021, PSC-022, PSC-023, PSC-024
- 本 Feature 包含：结果与范围合同、价值工程、需求可验证化、可行性、估算、交付计划和 FDE 决定。
- 本 Feature 不包含：系统详细调查、机制选择、实现和发布批准。

|---|---|---|---|
| 方法核心 | `engineer-ai-value` | 工作流边界已具备最低可信度 | Value Case、Scorecard、成本上限和 Pilot 门 |

| 工程条件 | `stakeholder-brief`、`escalation-and-renegotiation` | 需要管理者决定或约束无法同时成立 | 决策简报或重谈记录 |

## 阶段主视图与数据投影

| 页面问题 | 核心视图 | 读取数据 | 人工介入信号 |
|---|---|---|---|
| 做到什么算成功 | 结果合同、基线到目标及验证人、范围与非目标、价值与完整成本、责任人与签署、停止条件 | 指标、基线、目标、验证人、完整成本、风险上限、范围、非目标和决定 | 基线未知、没有验证人、范围模糊、成本高于价值、硬门或停止条件缺失 |

## 功能行为

### 主流程

1. 读取阶段 1 固定版本 Artifact，检查边界是否仍然有效。
2. 路由 `engineer-ai-value`，明确结果、验证者、基线、目标、完整成本、风险与停止条件。
3. 用工程 Skills 把确认的业务边界转成可验证需求、可行性落点、估算和按风险排序的计划。
4. 将同一 Workflow Charter 从 starter 渐进到 complete，不创建第二份简版对象。
5. 展示测量与假设差异、硬门阻塞和反转当前决定所需证据。
6. 由 FDE 记录是否进入现场环境调查。

### 业务规则与边界

- 模型指标、Token、使用量和生成数量不能替代被独立接受的业务结果。
- Forecast、Pilot demonstrated 和 production realized 三类价值证据必须分开。
- 总分不能平均掉结果、验证者、权限、安全、所有权和正向价值硬门。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 基线无法测量 | 明确标为未测和阻塞影响 | 不自动填入估值 | 建立测量计划或收窄声明 |
| 完整成本超过价值上限 | 显示下行情景和停止条件 | 保留负面结论 | Narrow、Defer 或 Stop |
| Workflow Charter 上游被替代 | 结果合同需重评 | 固定旧版本并阻止沿用 | 选择新版本重新运行 |

## 验收标准

### AC-F006-001 · 价值与范围工作可理解且按需执行

- 来源：REQ-006, REQ-007, REQ-025, REQ-026, NFR-004, NFR-013, NFR-014, PSC-005, PSC-006, PSC-021, PSC-022
- 对应 PRD 验收：AC-006, AC-022, AC-023
- Given 阶段 1 已形成可引用的工作流边界
- When 用户要求定义成功、范围、成本和交付责任
- Then 平台路由价值方法和必要工程 Skills，分开展示测量、假设、硬门、当前工作与预计 Artifact

### AC-F006-002 · 结果合同可追溯且由 FDE 决定

- 来源：REQ-003, REQ-018, REQ-019, REQ-028, NFR-002, NFR-011, PSC-003, PSC-015, PSC-023, PSC-024
- 对应 PRD 验收：AC-003, AC-016, AC-017, AC-025
- Given 价值、范围、责任、停止条件和计划已形成候选版本
- When Workflow Charter 完整校验并由 FDE 评审
- Then Artifact 回指输入和证据，结构完整不等于事实确认，方法结论不自动推进阶段
