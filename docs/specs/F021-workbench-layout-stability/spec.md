# F021 · 工作区布局稳定性规格

## 目标与可观察结果

FDE 从对话中的“已编辑文件”卡片直接打开右侧差异审查时，右侧 Dock 不再向上偏移或在底部露出被覆盖页面；Dock 自身标签栏、文件审查标题与底部边界始终完整。左侧栏收起时，“新建项目”与“搜索会话”两个 36px 操作以 12px 间距紧凑排列，中间不再保留空标题行。

## 来源与范围

- 来源需求：REQ-013, REQ-015, NFR-005, NFR-010
- 来源总规格：PSC-014, PSC-017
- 对应 PRD 验收：AC-012, AC-014
- 本 Feature 包含：对话产出文件跳转至 File Review Tab 时的 Dock 滚动边界，以及项目/会话侧栏折叠态前两个操作的纵向间距。
- 本 Feature 不包含：修改 Diff 内容、审查归因、撤销规则、Dock 宽度、左侧展开态布局、项目/会话数据或其他工作台美化。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 当前会话存在 Agent 产出文件 | 点击单个文件或“审查” | File Review Tab 展开目标差异并在内容区内定位 | 只改变 Dock 活动 Tab 和审查内容滚动位置 | Dock 外层仍贴合视口上下边界，顶部标签/标题与底部均完整 | 浏览、打开或审查文件 |
| 左侧项目/会话侧栏已展开 | 点击收起侧边栏 | 完成既有宽度过渡 | 仅切换侧栏展开状态 | 新建项目与搜索按钮相邻，间隔 12px | 新建项目或展开搜索 |

## 功能行为

### 主流程

1. 右侧面板 Host 只负责裁切收起面板的画面，不得成为可被程序滚动的容器。
2. File Review 定位指定轮次或文件时，只滚动 File Review 内部内容区；外层 Host 的 `scrollTop` 与 `scrollLeft` 保持为 `0`。
3. 右侧 Dock 打开后的上边界和下边界分别与当前视口一致；标签栏、File Review 标题不被裁掉，底部不露出下层工作台。
4. 折叠态左栏不渲染占位的空标题行；两个 36px 按钮保留 12px 纵向间隔和已有左侧对齐。
5. 展开态的新建项目、分组标题、搜索框、视图选项与会话列表布局保持不变。

### 业务规则与边界

- 滚动修复不得取消 File Review 的目标文件展开和定位行为。
- 收紧间距不改变“新建项目”的直接建项流程，也不改变“搜索会话”的展开、聚焦与外部点击收起。
- 右侧 Files、Git、Editor 和其他已启用 Tab 共用同一不可滚动的外层边界，不引入 File Review 专用定位特判。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 审查目标不存在或不可重建 | Dock 保持完整，File Review 显示既有空态/不可用说明 | 不滚动外层 Host，不伪造 Diff | 刷新或返回对话重新打开 |
| 视口窄化为覆盖式抽屉 | 抽屉仍完整占据可用视口 | 保留现有宽度和软键盘下边界适配 | 视口恢复后回到桌面 Dock |

## 验收标准

### AC-F021-001 · 直接审查不再滚动 Dock 外层

- 来源：REQ-015, NFR-005, NFR-010, PSC-017
- 对应 PRD 验收：AC-014
- Given 当前会话的已编辑文件卡片可打开文件审查
- When FDE 点击单个文件或“审查”并定位到目标轮次
- Then 目标差异在 File Review 内部展开，面板 Host 的水平/纵向滚动值仍为 `0`，Dock 上下边界与视口一致

### AC-F021-002 · 审查顶部与底部完整可见

- 来源：REQ-015, NFR-005, NFR-010, PSC-017
- 对应 PRD 验收：AC-014
- Given File Review Tab 已因对话产出文件而激活
- When 定位动画完成
- Then Dock 的 Tab 栏、`文件审查` 标题和底部表面均在视口内，不露出底层工作台背景

### AC-F021-003 · 折叠栏操作保持紧凑间距

- 来源：REQ-013, NFR-005, PSC-014
- 对应 PRD 验收：AC-012
- Given 项目/会话侧栏处于折叠态
- When 左栏渲染新建项目与搜索会话操作
- Then 两个按钮均为 36px 方形，左边对齐且垂直可见间隔为 12px，中间没有占位的空标题行

### AC-F021-004 · 直接相关原有交互不回归

- 来源：REQ-013, REQ-015, NFR-010, PSC-014, PSC-017
- 对应 PRD 验收：AC-012, AC-014
- Given 工作台处于展开侧栏或右侧 Dock 其他 Tab
- When FDE 展开/收起侧栏、打开搜索、调整 Dock 宽度或切换 Files/Git/Editor
- Then 展开态左栏布局、搜索聚焦、Dock 展开/收起和内部内容滚动保持原有行为

## 开放问题

- 无；本 Feature 是对已确认 F001/F009 布局合同的定向修复，不修订 PRD 或 Product Spec。
