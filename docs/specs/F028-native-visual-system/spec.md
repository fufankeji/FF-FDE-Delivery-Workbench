# F028 · 一致的全系统工作体验

## 目标与可观察结果

用户从已确认的公共入口进入各工作页面时，不再面对互不一致的装饰、色板和控件；仍能完成原有项目、阶段、资料、模型与训练动作。

## 来源与范围

- 来源需求：REQ-037。
- 来源总规格：PSC-031。
- 包含：项目详情、八阶段及阶段侧栏、资料和方法浮层、技能中心、架构、图谱外围、用量、评估、运行输出与预览、外观设置、介绍首页和实验室外层。
- 不包含：替换官方原生插件页面、改变图谱数据绘制、重画像素场景、修改案例、功能改造、模型调用、部署或 GitHub 推送。
- F025 已由用户确认，本轮以其为样板，不回退其公共导航或背景隔离。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 介绍首页与总览 | 打开项目 | 保留原导航和项目身份 | 仅页面选择 | 项目详情与公共入口风格连续 | 进入阶段 |
| 当前、历史或未来阶段 | 阅读、切页、预览资料或方法 | 状态、证据和操作边界清楚 | 仅原动作允许的状态变化 | 八阶段与浮层可读 | 原审批或执行动作 |
| 工程辅助页与技能中心 | 查看、编辑、下载或返回 | 保留专用布局与原有交互 | 不新增执行 | 统一控件、轻量表面 | 继续原工作 |
| 实验室 | 切换案例或主题 | 保留训练现场和像素场景 | 主题仅改变显示 | 明暗主题与外层一致 | 继续访谈或返回 |

## 功能行为

1. 工作页采用统一的小标题、说明、分组间距、轻量表面和控件；移除妨碍工作阅读的重色横幅与装饰，不隐藏业务状态或必要图表。
2. 当前阶段、正在查看、历史只读、未来未开始、失败及待批准保持原义；评审与费用确认仍由明确动作触发。
3. 背景和皮肤跟随已有偏好，不写入新的主题默认值；浮层、抽屉与工具工作区不透出错误的后层交互。
4. 介绍首页保留品牌展示和所有进入路径，实验室保留五案例、像素场景与训练数据。
5. 官方对话、设置、插件、自动化任务及第三方编辑器继续使用已集成原生样式，不另做覆盖。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 数据缺失或请求失败 | 原有空态、错误及重试入口 | 不用视觉占位伪造数据 | 沿原路径重试 |
| 皮肤不可用 | 官方基础表面与可读文本 | 不丢失用户工作 | 切回原版主题 |
| 实验室单独打开 | 使用已有独立样式 | 不要求或读取无关父窗口 | 在工作台内打开即可跟随主题 |
| 窄屏或长内容 | 控件换行、表格/画布保留滚动 | 不截断必要操作 | 滚动或展开原有详情 |

## 验收标准

### AC-F028-001 · 项目与八阶段工作面统一

- 来源：REQ-037, PSC-031。
- 对应 PRD 验收：AC-034。
- Given 已有 V1/V2 项目、当前与历史阶段记录。
- When 打开项目详情、八阶段、资料预览和方法说明。
- Then 文字、表面、页头和控件统一，原入口及状态、证据、评审、返回和滚动保留。

### AC-F028-002 · 技能与工程辅助工作连续

- 来源：REQ-037, PSC-031。
- 对应 PRD 验收：AC-034。
- Given 技能内容及项目架构、图谱、用量或评估记录可读或缺失。
- When 浏览、切换、下载、打开输出或配置外观。
- Then 同一风格贯通所有工作页，图谱、终端、预览保持专用布局；不新增模型或写入操作。

### AC-F028-003 · 首页与实验室保持特色并融入主题

- 来源：REQ-037, PSC-031。
- 对应 PRD 验收：AC-034。
- Given 原版、浅色、深色或自定义皮肤，以及已打开的实验室训练。
- When 进入首页、案例大厅、岗位工作区、资料或报告浮层，或切换主题。
- Then 展示布局与像素场景保留，外围文字和控件一致；训练实例不重建，主题同步不传递凭证或业务数据。

### AC-F028-004 · 可交付且由用户确认

- 来源：REQ-037, PSC-031。
- 对应 PRD 验收：AC-034。
- Given 本轮源码与隔离验证运行区。
- When 构建、执行直接相关检查并启动预览。
- Then 构建与检查通过，在线制品包含新样式，原运行数据未改变；最终视觉由用户确认，不将技术检查冒充视觉验收。

## 开放问题

无阻塞产品问题。用户已经确认方向并授权整个系统适配；不擅自调用模型、截图回放或推送。
