# F028 · 全系统官方风格适配计划

## 现有上下文与复用

复用已通过人工确认的 F025：公共背景隔离、官方语义色和共享控件。现有样式分布在项目 CSS Modules、阶段插件、外观插件和独立实验室应用；部分阶段与方法页面仍有固定浅色值与装饰横幅。必须保持 PSC-031 及其引用的全部业务边界。

## 实现方案

在各页面所属模块中调整样式，复用官方语义 token，不引入 UI 库或全局通配覆盖。可共用的色彩沿 ui-theme 已有别名；针对重色阶段横幅、纯装饰插图和重复嵌套层做有边界的简化。保留状态选择器与差异色，不能用统一成功色覆盖失败、待确认或过期。

实验室是同源 iframe，不能天然继承父页面的 CSS 变量。只同步一份明确白名单中的主题显示变量及明暗模式；不传递业务数据、不读取凭证、不重建 iframe。同步由 UI 适配器持有，加载/卸载与主题变化均明确清理。独立打开时继续使用自身默认样式；案例插画与像素 Canvas 色板保留。

当前已打开的隔离运行区继续使用 3082，不新增 worktree、运行副本或下载依赖。官方原生页面不修改；FDE 页面与其共享规范而不是覆盖它们的 DOM。

## 实施顺序

1. 冻结本 Feature 文档与页面覆盖。
2. 适配项目详情、八阶段和阶段侧栏。
3. 适配技能、方法浮层与工程辅助页。
4. 适配介绍首页、外观设置与实验室主题边界。
5. 一次执行直接相关回归、完整构建及在线制品核对，交用户手动体验。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |

## 人工反馈：总览分区边界过弱

2026-10-23 用户截图指出总览内容与白底融为一体。本轮仅调整工作台总览：三项统计补齐浅色表面和细边框；“继续工作”、实验室与技能中心使用完整卡片边界、统一圆角与内边距。复用官方明暗主题边框 token，不叠加阴影，不改标题、数据、导航、项目打开、实验室保活或技能阅读下载。保留跨插件的 24 列位置约定，并同步现有窄屏断点的间距，避免旧规则清空新内边距。

验收：六个区域均有完整轮廓；宽屏卡片间留有间隔，窄屏保留内边距；相关总览与实验室检查、构建及 3082 在线制品核对通过后，继续由用户手动确认视觉效果，不执行自动截图。

## 回退策略

保留已确认的 F025 改动。仅撤回 F028 的样式与实验室显示同步，不修改偏好、数据、模型配置或原运行区；不用破坏性 Git 回滚。
