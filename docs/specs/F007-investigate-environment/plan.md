# F007 · 阶段 3：调查现场环境实施计划

## 现有上下文与复用

- 当前实现与入口：项目文件树、终端、会话轨迹、资源预览和架构页可作为调查表面。
- 直接复用点：F003 最小上下文／工具权限，F004 Artifact Catalog，F006 固定结果与范围。
- 必须保持的现有行为：普通只读浏览、对话和文件预览不因治理工作台而消失。
- 必须保持的 Product Spec 合同：PSC-003, PSC-005, PSC-006, PSC-016, PSC-017, PSC-021, PSC-022, PSC-023。

## 影响范围

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |
|---|---|---|---|
| `packages/fde/stage` | 阶段快照与决定 | 增加调查对象、访问缺口、治理审查和阶段决定 | AC-F007-001, AC-F007-002 |
| `packages/fde/project` | Artifact 与来源 | 适配数据、系统、权限、政策和治理 Artifact | AC-F007-002 |
| `packages/skill/*` | 分层路由 | 接入行动边界方法与调查类工程 Skills | AC-F007-001 |
| `packages/host` | 工具执行与权限 | 在 operation 中强制调查范围和只读边界 | AC-F007-001 |
| `packages/client/ui-fde-stage` | 当前阶段工作台 | 呈现系统地图、数据就绪、权限和三类审查 | AC-F007-001, AC-F007-002 |

## 实现方案

以调查任务为单位建立限定 ContextManifest 和 ToolPolicy，通过现有 operation 执行工具；将 Data Context Manifest、系统地图、访问矩阵、Tool Contract 候选和三类治理记录作为独立 Artifact 组合。阶段工作台沿用统一骨架，中心区域专门投影系统／数据关系、权限矩阵、数据就绪、政策升级路径和三类治理审查；命令和原始日志按需展开。

## 实施顺序

1. 固定阶段 3 方法、Schema、模板和工程 Skills 来源。
2. 适配数据、系统、权限与治理 Artifact。
3. 实现调查路由、上下文范围和工具权限约束。
4. 实现现场调查与三类治理工作面。
5. 接入人工批准、FDE 决定、返回与过期影响。
6. 用权限不足、声明冲突和治理未通过场景验证。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| 调查工具越出项目范围 | 客户数据泄露 | Host 层强制项目根与 ToolPolicy | 工具权限测试 |
| 用户误解 Schema 状态 | 把结构完整当治理通过 | 双轴状态和独立审查 | Artifact／UI 测试 |
| 上游系统变化 | 现场地图过期 | 固定观察时间与输入版本 | 依赖失效测试 |

## 回退策略

调查失败时保留阶段 2 已确认版本、已完成只读证据和失败轨迹；撤销本次临时工具授权，不删除客户资料，不回退成对全盘工作区的开放访问。
