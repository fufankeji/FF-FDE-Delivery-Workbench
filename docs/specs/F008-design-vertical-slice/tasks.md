# F008 · 阶段 4：方案与纵向切片任务

## 任务规则

- 先选择机制，再选择实现能力。
- 业务复杂度不自动触发本体／知识图谱；只有机制必要性证据成立时才进入 Semantica 路线。
- 纵向切片必须真实可运行且可回滚。
- 构建成功、验证通过、纵向切片通过和 FDE 决定是不同事实。
- 只有完成证据存在后才勾选。
