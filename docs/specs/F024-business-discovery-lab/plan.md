## 实现方案

实验室保持独立业务域。原 Node 业务代码以带来源记录的 JavaScript 保留在 Host 包内，类型化入口处理当前宿主注册、请求信任和数据目录。对原生会话事件读取、选用模型和退出释放做当前版本的最小适配；不复制作者的运行库、会话或凭据。

原 React/Pixi 应用保留为 Client 包的独立应用源码，由自有构建输出到 `lib/app/`；页面由当前 Host 提供，在插件页面内用 iframe 隔离 CSS 与运行时。工作台侧仅增加导航和返回，不重写像素场景、不建立新宿主进程。

素材导入脚本核对运行包摘要并按包内白名单导入 `.assets/`，保留案例定义、授权原件、固定 Python 计算程序及字体。该目录被忽略且可重建；可变 SQLite 和工作区在显式 `DSH_HOME/fde-discovery-lab/`，不能当素材缓存删除。接口采用 `/api/fde-discovery-lab`，不拦截既有 FDE 路径。

## 实施顺序

1. 冻结独立模块合同和来源摘要。
2. 导入所需源码与授权素材，实现 Host 适配并验证无模型状态、授权和持久化。
3. 挂载原应用与独立入口，验证打开和返回不改变项目。
4. 登记组合、构建新包，运行最窄无密钥组合检查。
5. 使用原本隔离运行区启动并检查在线包，将人工验收入口交给用户。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| 原插件面向宿主 0.1.5，当前为 0.1.1 | 会话、工具、UI API 有差异 | 适配当前公开接口；若必须升级基座则暂停确认 | 真实组合无密钥测试 |
