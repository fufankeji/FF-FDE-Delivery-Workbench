# F019 · 权限控件中文化规格

## 目标与可观察结果

FDE 使用中文界面选择 Agent 权限时，对话输入栏和设置页都显示与本地 Studio 一致的 `只读`、`工作区写入`、`完全访问`；对话输入栏菜单同时展示各权限后果，并以红色风险文案和图标突出 `完全访问`；风险确认框不再混入英文，同时不改变任何实际权限行为。

## 来源与范围

- 来源需求：REQ-004, NFR-004, NFR-005
- 来源总规格：PSC-008, PSC-012
- 对应 PRD 验收：AC-004
- 本 Feature 包含：对话输入栏当前会话权限选择器、设置页新会话默认权限选择器、命令弹出选择器的三个内置权限名称，对话输入栏菜单的权限后果说明与完全访问红色风险提示，以及完全访问风险确认框的中文文案。
- 本 Feature 不包含：权限策略、默认权限、命令参数、权限 ID、审批流程、模型能力、其他界面文案或全站翻译。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 工作台使用中文界面且权限能力可用 | 打开对话输入栏或设置页权限选择器 | 内置权限按中文产品名称显示；对话输入栏菜单补充权限后果 | 无 | 菜单与当前值显示 `只读`、`工作区写入`、`完全访问`，完全访问在输入栏菜单中以红色风险文案和图标突出 | 选择所需权限 |
| 用户选择只读或工作区写入 | 点击对应中文选项 | 继续提交原有权限 ID | 权限按既有规则切换 | 中文当前值反映已确认权限 | 继续工作 |
| 用户选择完全访问 | 点击 `完全访问` | 打开完整中文风险确认框，确认前启用按钮不可用 | 确认前不改变权限 | 用户明确理解风险并决定确认或取消 | 确认后按既有规则切换，取消则保持原权限 |

## 功能行为

### 主流程

1. 中文 locale 下，内置 `read-only`、`workspace-write`、`danger-full-access` 分别显示为 `只读`、`工作区写入`、`完全访问`。
2. 对话输入栏、设置页和命令弹出选择器使用同一组中文产品名称。
3. 对话输入栏权限菜单显示提问标题和三种权限的后果说明；`完全访问` 的名称、说明和盾牌图标使用与 Studio 一致的红色风险样式。
4. 选择完全访问继续经过原有勾选确认；标题、说明和启用按钮使用完整中文。
5. 英文 locale 保持 `Read Only`、`Workspace Write`、`Full access`，并显示对应英文后果说明。

### 业务规则与边界

- 本地化只改变显示名称，不改变 `/permission <preset>` 命令、持久化值、默认值或 Host 权限计算。
- Host 提供的非内置自定义名称原样显示，不被翻译或改写。
- 权限能力缺失时继续按现有规则隐藏或显示不可用状态，不伪造权限选项。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 当前值不在已知内置列表 | 显示 Host 提供的名称或原有可读转换 | 不猜测对应中文含义 | Host 恢复有效投影后自动刷新 |
| 用户取消完全访问确认 | 对话框关闭，原权限中文名称保持 | 不提交命令、不改变权限 | 可再次选择并确认 |
| 切换为英文 locale | 三个内置名称恢复英文 | 权限状态不变 | 切回中文后再次显示中文名称 |

## 验收标准

### AC-F019-001 · 内置权限名称在中文界面统一

- 来源：REQ-004, NFR-005, PSC-008, PSC-012
- 对应 PRD 验收：AC-004
- Given 工作台使用中文 locale 且 Host 提供三个内置权限选项
- When 用户打开对话输入栏、设置页或命令弹出权限选择器
- Then 当前值和菜单逐字显示 `只读`、`工作区写入`、`完全访问`，不显示对应英文产品名称

### AC-F019-002 · 完全访问确认保持风险门并使用中文

- 来源：REQ-004, NFR-004, NFR-005, PSC-008
- 对应 PRD 验收：AC-004
- Given 当前权限不是完全访问且工作台使用中文 locale
- When 用户选择 `完全访问`
- Then 页面显示完整中文风险确认，勾选前启用按钮不可用，取消不提交，确认后仍提交原有 `danger-full-access` 权限值

### AC-F019-003 · 英文与自定义名称兼容

- 来源：REQ-004, NFR-005, PSC-008, PSC-012
- 对应 PRD 验收：AC-004
- Given 工作台使用英文 locale，或 Host 提供非内置自定义权限名称
- When 权限控件渲染当前值和菜单
- Then 英文内置名称保持原有文案，自定义名称保持 Host 原值，权限命令和状态流不变

### AC-F019-004 · 输入栏菜单明确展示权限后果与完全访问风险

- 来源：REQ-004, NFR-004, NFR-005, PSC-008, PSC-012
- 对应 PRD 验收：AC-004
- Given 工作台使用中文 locale 且 Host 提供三个内置权限选项
- When 用户打开对话输入栏的权限菜单
- Then 菜单显示 `应如何批准 DeepSeek Harness 操作？`，逐项展示只读、工作区写入和完全访问的中文后果说明，并将 `完全访问` 的名称、说明和盾牌图标显示为与 Studio 一致的红色风险提示

## 开放问题

- 无；其他界面是否继续中文化由后续明确请求单独确认。
