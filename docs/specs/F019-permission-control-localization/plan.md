# F019 · 权限控件中文化实施计划

## 现有上下文与复用

- 当前实现与入口：`ui-conversation` 渲染输入栏权限选择器，`ui-permission-presets` 渲染设置行和命令弹出选择器；两者都使用 locale 服务，但内置权限名称仍由英文字符串或 Title Case 转换产生。Studio 后续提交 `97b5851f3b` 还为输入栏权限菜单增加了标题、权限后果说明和完全访问风险色，本 Feature 需连同这部分用户可见合同一并对齐。
- 直接复用点：现有 locale 字典、权限选择组件、`RiskConfirmation`、`/permission <preset>` 命令和 Settings mutation。
- 必须保持的现有行为：内置权限 ID、默认值、当前会话与新会话的不同生命周期、完全访问确认门、自定义 Host 名称透传和英文 locale。
- 必须保持的 Product Spec 合同：PSC-008, PSC-012。

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |

| `packages/client/ui-permission-presets` | 设置页默认权限与命令弹出选择器 | 共享本地化展示函数，三个界面一致；自定义名称透传 | AC-F019-001～AC-F019-003 |

| Feature 调试运行目录 | 为人工验收提供独立 Web 运行状态 | 保留独立端口、Profile 与可写 DSH_HOME，只从 main 的 `.runtime/dsh-home` 同步项目注册、阶段状态、会话与附件快照；不复制凭据 | AC-F019-001～AC-F019-004 |

## 实现方案

只在 Client 展示层增加三个稳定内置值到 locale key 的映射。展示函数先识别 Host 是否仍使用内置名称；内置名称按当前 locale 翻译，自定义名称继续透传。输入栏菜单复用 Studio 已验证的复合菜单项结构与语义风险色，增加 locale 持有的菜单标题和后果说明。选择动作仍提交原始 ID，设置仍写原始值，完全访问继续复用现有风险确认组件，不修改 Host、Projection 或权限策略。

人工调试运行继续使用 Feature 专属 DSH_HOME，避免与 3080 的 main Host 并发写同一数据目录。启动前从 main DSH_HOME 复制 `sessions`、`storages` 与 `attachments` 的一次性快照到 Feature 运行目录，保留 Feature 自己的 `profiles`，并明确排除 `.credentials.yaml`、模型凭据和 main 的可写运行文件。项目 Workspace 仍指向原有真实目录，因此文件树与历史会话可以恢复，但后续调试产生的 Session 状态只写 Feature 快照。

## 实施顺序

1. 在两个 Client 包的 locale 字典增加三个内置权限名称，并补全中文风险确认文案。
2. 让输入栏、设置行和命令弹出选择器只在内置名称上调用翻译，自定义名称保持原样。
3. 对齐 Studio 输入栏权限菜单：加入标题、三项后果说明和完全访问红色风险样式。
4. 更新聚焦测试，分别证明中文统一、英文兼容、自定义名称透传、权限后果菜单和完全访问风险门。
5. 同步两个包的中英文 README，运行最窄测试与相关 Client 构建。
6. 从 main 运行数据生成不含凭据的 Feature 快照，重启 3181 并确认项目、工作区与历史会话可供人工调试。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| Host 可为内置 ID 提供自定义展示名 | 直接按 ID 翻译会覆盖部署方名称 | 仅对内置或约定默认名称使用 locale，自定义名称透传 | 组件测试 |
| 中文 locale 与英文 locale 共用组件 | 中文改动可能污染英文产品名称 | 每个 locale 独立字典并保留英文断言 | locale/组件测试 |
| 完全访问是高风险状态 | 文案调整可能绕过确认 | 不改变确认状态机和提交路径，只替换字符串 | 风险确认测试 |
| 两个权限界面各自有展示函数 | 可能出现名称不一致 | 使用相同内置值判断与 locale key，并分别覆盖聚焦测试 | 两包聚焦测试 |
| main 与 Feature Host 同时运行 | 共用 DSH_HOME 会产生并发写入和调试污染 | 只复制一次性业务数据快照，Feature 保持独立 DSH_HOME 与端口 | 启动前目录审计与 HTTP/数据投影检查 |
| main 数据目录包含本地凭据 | 为了复现历史而复制整个目录会扩大凭据暴露 | 仅复制项目、阶段、会话和附件；明确排除凭据、匿名标识、Profile 与模型私有状态 | 快照文件清单检查 |

## 回退策略

保留权限 ID、命令和 Host 行为不变；若本地化展示失败，只需反向移除新增 locale key 与展示映射即可恢复英文标签，不触碰已保存权限或会话数据。
