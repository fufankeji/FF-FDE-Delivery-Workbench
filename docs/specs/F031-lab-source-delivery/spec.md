# F031 · 实验室完整源码交付

## 目标与可观察结果

用户从 GitHub 或学员源码包安装 FF-FDE 后，能直接进入五案例业务挖掘实验室，不需要另找讲师本机素材包。本功能只补齐既有实验室，不改变训练、资料权限或项目交付。

## 来源与范围

- 来源需求：REQ-030, REQ-031, REQ-032, REQ-010, NFR-003, NFR-004, NFR-006。
- 来源总规格：PSC-026, PSC-009。
- 包含：已授权运行必需静态素材、完整性检查、安装/故障说明、GitHub 正常推送和桌面源码包。
- 不包含：教师资料、未来事件材料、个人运行记录、模型凭据、模型计费验证、素材市场、宣传视频或新的业务功能。
- 2026-11-13 用户明确批准素材随项目发放；第三方声明与字体许可原样保留，不重新授予整体 MIT 许可。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| GitHub 或新版 ZIP | 获取源码、安装、构建 | 校验所需内容完整 | 静态素材就绪；没有训练历史 | 五案例可读取 | 选择案例与岗位 |
| 未配置模型 | 打开实验室或挑战 | 只读列表和案例；主动选择才建立本机轮次 | 不改变项目或阶段 | 可浏览业务入口，挑战可独立使用 | 自行配置模型后访谈 |
| 文件漏包或被改坏 | 校验/构建/启动 | 明确指出缺失或损坏 | 不冒充就绪，不覆盖历史 | 可重新取得完整源码并重启 | 重试同一入口 |

## 功能行为

### 主流程

1. GitHub 源码和学员包提供同一五案例静态内容与必要许可，不依赖个人目录或另行下载素材。
2. 安装、构建和启动均使用该交付内容；完整性校验包含案例定义、原件、计算脚本与报告字体。
3. 新源码不包含训练数据库、会话、模型密钥或用户上传；既有运行区升级不覆盖这些数据。
4. 正常推送后提供一个有明确版本的桌面源码 ZIP，并从最终 ZIP 独立解压安装、构建、验证五案例读取。

### 业务规则与边界

- 案例可读不代表真实访谈或模型效果已经验证；计费行为仍需用户主动提交。
- 岗位与资料权限、完整训练及项目隔离规则不变。源码拥有者可读静态配置不等同于匿名 HTTP 可访问资料。
- 缺失或损坏仍真实报错，不能仅删除错误提示。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 必需文件漏包、路径不一致或摘要不符 | 素材不完整 | 校验与构建失败；实验室接口明确不可用，其他模块不伪装失败 | 重新获取同版本完整源码，不删除训练数据 |
| 远端分叉或推送失败 | 明确未推送状态 | 不强推、不覆盖远端 | 用户决定合并方式或网络恢复后重试 |
| 验包失败或磁盘不足 | 不交付假成功包 | 保留旧包与旧数据，仅处理本轮临时目录 | 修正确定问题后重试 |

## 验收标准

### AC-F031-001 · 新安装有完整案例

- 来源：REQ-030, REQ-031, PSC-026。
- 对应 PRD 验收：AC-026, AC-027。
- Given 未配置模型、没有开发者缓存的完整源码。
- When 安装、构建并进入实验室。
- Then 五案例及其 234 份引用资料、固定脚本与报告字体齐备，无额外交付 ZIP 前提。

### AC-F031-002 · 漏包和损坏不被放过

- 来源：REQ-010, NFR-004, PSC-009。
- 对应 PRD 验收：AC-008。
- Given 必需文件缺失或内容与固定清单不同。
- When 校验、构建或初始化实验室。
- Then 显示明确的完整性失败与恢复方式，不生成可发放假成功包。

### AC-F031-003 · 运行状态与授权保留

- 来源：REQ-032, NFR-003, PSC-026, PSC-009。
- 对应 PRD 验收：AC-004, AC-028。
- Given 已有训练记录、岗位资料边界及项目。
- When 发布或安装静态内容。
- Then 不读取或发放个人记录、教师材料和凭据，不覆盖训练数据、不改变项目阶段，HTTP 仍遵循原授权。

### AC-F031-004 · 可复现的源码交付

- 来源：REQ-030, REQ-010, NFR-006, PSC-026, PSC-009。
- 对应 PRD 验收：AC-026, AC-008。
- Given 当前版本已通过定向验证。
- When 正常推送 GitHub 并生成桌面源码包。
- Then 远端提交可核对，包内版本、素材与中文部署说明一致；最终 ZIP 独立解压安装、构建及案例读取通过，未验证的模型能力单独说明。
