# F025 · 统一工作台导航与总览实施计划

## 现有上下文与复用

- 复用 ProjectPageController、ProjectProgressOverlay 的 Workspace/Session 投影和项目动作；不复制项目状态。
- 实验室目前使用独立全屏 iframe 与导航 store，迁为 Slot 页面，原 iframe 应在切换时保持挂载。
- 保持 PSC-027；不改变 Agent、阶段状态、训练后端或模型权限。

## 影响范围

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |
|---|---|---|---|
| upstream/deepseek-harness/packages/client/ui-fde-project/src/client | 页面导航及项目投影 | 扩展页面选择，新增侧栏、总览、技能占位和 Slot 声明 | AC-F025-001, AC-F025-002, AC-F025-003 |
| upstream/deepseek-harness/packages/client/ui-fde-discovery-lab/src/client | 实验室入口与 iframe | 接入导航 Slot，维持 iframe 生命周期，提供只读概况 | AC-F025-001, AC-F025-002 |
| 两包 tests 与 README | 行为验证与包说明 | 窄范围组件测试及导航说明 | AC-F025-001, AC-F025-002, AC-F025-003 |

## 实现方案

复用当前页面控制器发布导航快照，注入显式回调供所有入口调用。项目插件新增 root overlay 导航与实验室页面 child Slot；实验室只接收可序列化状态和回调。总览复用项目行数据，通过独立摘要 Slot 获取实验室案例数；技能占位页不连接 Skills API。页面共享 CSS 导航宽度，窄屏改用紧凑侧栏；不更改既有主题选择。

## 实施顺序

1. 更新确认范围和导航状态。
2. 接入统一侧栏及项目原有入口。
3. 实现总览、实验室保活和技能占位。
4. 窄范围测试、构建、隔离服务启动后交用户验收。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| 全屏覆盖层 | 遮住导航 | 同一导航宽度和层级 | 组件/样式合同测试及人工验收 |
| 实验室 iframe 卸载 | 中断当前页面 | 首次打开后保留挂载，切换只隐藏 | 组件重渲染测试 |
| 外观皮肤透明度 | 透出后层 | 全屏页面使用不透明主题基色 | 本地人工确认 |

## 回退策略

实现保留在独立 worktree，不修改主线运行区；如未通过验收，用户仍可访问主线 3080。功能回退只撤销本轮导航改动，不删除任何项目或训练数据。

## 验收映射

| AC | 实现结果 | 最窄验证方法 | 预期证据 |

| AC-F025-003 | 技能仅占位 | 总览/占位组件定向 Vitest | 无 Skill 网络请求 |
