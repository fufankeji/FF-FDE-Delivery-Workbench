# F025 · 统一工作台导航与总览实施计划

## 现有上下文与复用

- 复用 ProjectPageController、ProjectProgressOverlay 的 Workspace/Session 投影和项目动作；不复制项目状态。
- 实验室目前使用独立全屏 iframe 与导航 store，迁为 Slot 页面，原 iframe 应在切换时保持挂载。
- 保持 PSC-027；不改变 Agent、阶段状态、训练后端或模型权限。

## 影响范围

| 路径/模块 | 当前职责 | 计划变化 | 对应 AC |
|---|---|---|---|
| upstream/deepseek-harness/packages/client/ui-fde-project/src/client | 页面导航及项目投影 | 扩展页面选择，新增侧栏、总览、技能入口和 Slot 声明；技能页内容由 F026 承接 | AC-F025-001, AC-F025-002, AC-F025-003 |
| upstream/deepseek-harness/packages/client/ui-fde-discovery-lab/src/client | 实验室入口与 iframe | 接入导航 Slot，维持 iframe 生命周期，提供只读概况 | AC-F025-001, AC-F025-002 |
| 两包 tests 与 README | 行为验证与包说明 | 窄范围组件测试及导航说明 | AC-F025-001, AC-F025-002, AC-F025-003 |

## 实现方案

复用当前页面控制器发布导航快照，注入显式回调供所有入口调用。项目插件新增 root overlay 导航与实验室页面 child Slot；实验室只接收可序列化状态和回调。总览复用项目行数据，通过独立摘要 Slot 获取实验室案例数；技能入口打开 F026 技能页，总览不读取目录。页面共享 CSS 导航宽度，窄屏改用紧凑侧栏；不更改既有主题选择。

## 实施顺序

1. 更新确认范围和导航状态。
2. 接入统一侧栏及项目原有入口。
3. 实现总览、实验室保活和技能入口；F026 承接技能页内容。
4. 窄范围测试、构建、隔离服务启动后交用户验收。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| 全屏覆盖层 | 遮住导航 | 同一导航宽度和层级 | 组件/样式合同测试及人工验收 |
| 实验室 iframe 卸载 | 中断当前页面 | 首次打开后保留挂载，切换只隐藏 | 组件重渲染测试 |
| 外观皮肤透明度 | 透出后层 | 公共导航持有全屏不透明底板，底板绘制现有皮肤；页面内容使用透明背景与语义表面 | 组件与样式检查，随后人工确认 |

## 回退策略

本轮直接使用唯一 main 工作树，不创建 worktree。沿用 F027 的隔离 DSH_HOME 和 3082，禁止新版写入原运行区。回退只撤销本轮视觉改动，不删除项目、会话、皮肤或训练数据。

## 2026-10-23 视觉适配方案

以官方插件页的 20/28 页标题、13/20 说明、32px 分组间距、轻量行背景与共享 Button 为参照。总览保留真实指标、最近三个项目和两项模块入口，但去掉重复的大面板边框与首行装饰；项目中心保留优先事项、指标、卡片/列表、搜索筛选、排序、分页、时间轴和详情入口，弱化深色宣传横幅与大图，使用语义表面及原生主操作。一级导航保持既定顺序、Logo 和返回/设置入口，采用官方侧栏填充和中性选中态。

修改仅限 ui-fde-project 的公共入口组件/样式与 ui-fde-discovery-lab 的总览摘要样式；不修改控制器、API、模型调用、业务状态或实验室 iframe。共用背景由 WorkbenchNavigation 按现有 visible 生命周期挂载，使用当前 --fde-background-image/position 和官方主题色，以不透明底板隔开旧工作面。项目详情与时间轴等直接相邻路径不得因新背景丢失遮挡、滚动或入口。

不增加设计库、新皮肤、动效框架或用户配置。只运行相关组件测试、必要构建和在线制品核对；不做全量浏览器自动化，完成后交用户第一时间手动体验。
