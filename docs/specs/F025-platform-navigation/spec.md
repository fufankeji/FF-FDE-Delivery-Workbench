# F025 · 统一工作台导航与总览规格

## 目标与可观察结果

用户进入工作台后先看到总览，再通过同一侧栏选择项目中心、实验室或技能中心；能够继续真实项目和训练。技能内容与下载由 F026 承担。

## 来源与范围

- 来源需求：REQ-033
- 来源总规格：PSC-027
- 本 Feature 包含：一级导航、真实概况、最近项目入口、实验室导航适配和技能中心入口。
- 本 Feature 不包含：Skills 内容、计数、执行、安装、阶段筛选；新增实验室；训练成果回流；修改项目生命周期。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 产品介绍页 | 进入平台 | 显示总览和侧栏 | 仅页面选择 | 三模块摘要 | 选功能或继续项目 |
| 任一一级模块 | 切换模块 | 高亮目标入口 | 仅页面选择 | 对应功能页 | 保留原业务状态 |
| 实验室已打开 | 切换并返回 | 原训练页继续保留 | 不重置轮次或页面实例 | 恢复访谈现场 | 继续训练 |
| 技能中心 | 打开内容 | 交给 F026 读取第一阶段方法 | 仅页面选择 | 真实技能库入口 | 返回其他模块 |

## 功能行为

### 主流程

1. 介绍页所有进入按钮统一为“进入平台”，动作指向总览；移除首页实验室快捷入口，保留介绍页其他内容及平台内实验室入口。
2. 侧栏固定顺序为总览、项目中心、实验室、技能中心，提供返回介绍页动作。
3. 总览展示项目数、实验室与案例概况、第一阶段技能入口、最近项目；支持直接进入最近项目或创建项目。
4. 项目中心复用现有创建、搜索、筛选、排序、列表、时间轴、详情和进入项目动作。
5. 进入具体项目保留原项目导航；原项目中心及实验室入口可回到一级模块。

### 业务规则与边界

- 保留：介绍页、全部项目业务动作、实验室训练与原有快捷入口、项目内部阶段方法。
- 新增：总览、统一侧栏、技能中心入口（具体资产由 F026 提供）。
- 替换：项目中心右上实验室入口迁至侧栏；介绍页主按钮的落点由项目中心调整为总览。
- 移除：不删除业务数据或能力，不增加其他模块。
- 模块切换不调用模型，不创建会话，不推进阶段。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 无项目 | 尚无项目 | 保留其他模块入口 | 创建项目 |
| 概况读取失败 | 明确失败，不展示为零 | 失败局限于对应摘要 | 重试或进入模块 |
| Skills 内容读取失败 | 技能页内明确失败 | 总览与其他导航仍可用 | F026 提供目录重试 |

## 验收标准

### AC-F025-001 · 导航与恢复

- 来源：REQ-033, PSC-027
- 对应 PRD 验收：AC-029
- Given 用户位于介绍页、项目中心、项目内或实验室。
- When 进入工作台、切换模块并返回。
- Then 默认总览，侧栏入口及高亮准确；原项目路径可用，实验室实例不被切换卸载，项目状态不变。

### AC-F025-002 · 真实总览

- 来源：REQ-033, PSC-027
- 对应 PRD 验收：AC-030
- Given 项目或实验室概况处于加载、失败、空或成功。
- When 查看总览与继续项目。
- Then 数量与状态真实，最近项目按更新时间展示并打开相同项目；空项目保留创建入口。

### AC-F025-003 · 技能入口交接

- 来源：REQ-033, PSC-027
- 对应 PRD 验收：AC-029
- Given 技能内容由 F026 提供。
- When 从总览或一级侧栏打开技能中心。
- Then 导航进入同一技能页，保持平台侧栏及返回路径；不安装执行或改变现有阶段方法。

### AC-F025-004 · 官方风格的公共工作入口

- 来源：REQ-033, PSC-027
- 对应 PRD 验收：AC-029, AC-030
- Given 用户使用原版、内置或自定义皮肤，处于总览、项目中心或交付时间轴。
- When 浏览、搜索、筛选、创建、进入项目或切换一级模块。
- Then 页面使用统一的轻量页头、间距、列表、控件与主题表面；保留所有原入口、数量、状态及业务动作。背景可以展示当前皮肤，但不透出下层会话和可操作内容；窄屏仍可进入项目。视觉确认由用户完成。

2026-10-23 用户授权先以总览、项目中心和一级导航作为视觉样板。保留介绍首页、项目内部八阶段工作面、实验室内部场景及技能正文；仅同步总览中由实验室提供的摘要样式。此项不新增产品行为，不改变 PRD 与 PSC-027。

## 开放问题

- 技能内容于 2026-09-17 交由 F026 只读接入；页面观感由用户在本地服务手动确认。
