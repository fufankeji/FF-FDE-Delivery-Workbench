# F002 · 透明的当前阶段工作台实施计划

## 现有上下文与复用

- 当前实现与入口：`ui-fde-stage` 已有阶段条与项目进度，`ui-fde-project` 已有项目管理，`ui-conversation`、`ui-trajectory`、`ui-tool` 已能呈现会话和工具轨迹。
- 直接复用点：现有 FDE 快照、导航、会话状态、轨迹详情和主题能力。
- 必须保持的现有行为：对话、文件树、会话切换与 V1 阶段页面继续可达。
- 必须保持的 Product Spec 合同：PSC-002, PSC-005, PSC-007, PSC-009, PSC-021。

## 实现方案

- 本次修复：`fde-project` 在已登记 Workspace 下持久化 `.fde/project-metadata.json`，提供可信同源读取与缺失时保存接口；`ui-workspace` 通过共享 `projectMetadata` 服务承接创建保存、旧数据导入与读取投影，`ui-fde-project` 通过既有服务/Hook 通道消费，不改 Workspace 内核或 Agent Loop。
- 项目中心由已加载的 Session、阶段和 Workspace 快照生成带目标的近期记录；会话跳转校验所属 Workspace 和可见性。周期预览、计数与时间轴共享筛选，失败可重试，长列表独立滚动。
- 本轮唯一行为验证：Host 持久化/路由、共享读取/创建恢复、项目中心交互的定向测试；另执行受影响包类型检查、构建及 3080 实际资源核验，不自动推进阶段。

由 Host 从同一项目事实生成版本化快照，确定性投影为全部项目、单项目首页、当前阶段工作台和真实交付环境四层。全部项目负责行动优先级，单项目首页负责恢复现场认知，阶段工作台采用统一骨架与阶段专属中心视图，真实交付环境负责具体执行并回写稳定对象。执行轨迹建立业务步骤摘要与技术详情两层，不复制日志数据。

项目中心使用一个共享的集合视图状态：业务范围仍分为“待我处理”和“全部项目”，展示方式统一为卡片、列表与交付时间线。卡片为默认值，并把待处理项目压缩为桌面双列的行动摘要；列表复用现有项目比较表，时间线复用已登记周期。切换范围不重置展示方式，切换展示方式也不改变范围或项目事实。

阶段浏览采用 Apply 生命周期内、按 Workspace 隔离的轻量前端观察状态。项目持久化阶段仍是唯一权威事实；左侧阶段导航可查看全部阶段，右侧项目记录轴只列出当前阶段和已完成阶段。记录轴默认折叠并按节点数量自适应高度，展开后读取所选阶段的真实输入、产物和人工结论，或汇总全部已有记录；选择记录不调用阶段迁移接口。阶段迁移后清除浏览覆盖，默认回到新的当前阶段。未开始阶段仍由左侧导航进入明确空状态；只有当前阶段保留执行、评审和阶段门动作。

## 实施顺序

本轮收紧项目中心待处理判定：在 `ProjectProgressOverlay.tsx` 内增加纯函数，从当前阶段快照、显式问题、Host 评审状态及已登记计划日期派生可选的待处理原因；不新增接口、事件或存储。所有相关展示与排序消费该原因。V2 只读取当前阶段，不使用自动补齐的 `reviewBlockers`；旧生命周期继续读取对应验证、试运行和移交合同的显式问题与评审状态。保留普通项目的阶段建议、默认最近操作排序及原进入项目动作。组件测试覆盖无待办、加载、异常、过期日期、历史/已解决问题、多个真实待办、筛选、排序和刷新后消失；构建并核对 3080 实际 Bundle，视觉待用户确认。

项目中心的集合排序默认使用 `activity`，在既有 `ProjectRow` 投影内聚合 Workspace、Session 和阶段更新时间；不新增访问日志或持久化排序状态。优先事项排序入口保留。卡片背景采用静态 WebP 与右侧对齐的非交互装饰层，不修改集合卡片的小型插画。定向组件测试验证默认时间顺序、无会话回退、数据更新重排、列表切换和人工优先排序仍可用。

1. 定义四层产品形态共享的项目事实快照与错误语义。
2. 建立全部项目与单项目首页的同源投影，并统一待处理与全部项目的卡片、列表和时间线入口。
3. 构建统一阶段骨架、阶段专属中心视图承载区、工作、产物、缺口和决定区。
4. 接入工作项到真实交付环境及执行结果回写。
5. 接入业务进度与可展开技术轨迹。
6. 验证能力显隐、加载失败和窄屏布局。

## 依赖与风险

| 依赖/风险 | 影响 | 应对 | 验证时机 |
|---|---|---|---|
| F001 项目身份未稳定 | 可能投影错误项目 | 所有查询强制携带项目身份 | 合同测试 |
| V1 页面信息结构不同 | 回归风险 | V2 使用版本化 slot，不移除 V1 入口 | UI 回归测试 |
| 技术轨迹淹没业务状态 | 用户仍不理解 | 默认折叠原始日志，固定业务摘要 | 组件测试 |

## 回退策略

新工作台通过 V2 生命周期启用；若呈现层失败，保留现有对话和 V1 页面入口，并显示明确加载错误，不回退到模拟或全局数据。
