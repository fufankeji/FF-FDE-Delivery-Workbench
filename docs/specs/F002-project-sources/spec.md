# F002 · 项目原始来源规格

## 目标与可观察结果

FDE 从项目入口添加客户原始资料后，系统在项目 `fde-resources/` 中保留唯一原件并建立稳定 `SourceId`。同一资料既能在“项目进度 → 项目详情”中审阅，也能在项目交付的右侧开发工作区中打开；受支持格式在本地生成可追踪的派生文本。保存、预览、本地识别和 Agent 使用是四个独立状态，前三者都不修改输入框、不创建消息、不启动 Agent。

## 来源与范围

- 来源需求：REQ-008, REQ-010, REQ-016, NFR-001, NFR-002, NFR-005, NFR-007, NFR-008
- 来源总规格：PSC-003, PSC-005, PSC-011, PSC-012, PSC-016, PSC-018, PSC-024
- 对应 PRD 验收：AC-008, AC-015
- 当前切片包含：项目级批次导入；`fde-resources/` 原件；稳定来源记录；资料清单；Office/PDF/文本/表格/常见图片的只读预览能力判断；本地文本识别；派生 Markdown 与处理状态；项目详情和开发工作区共用同一来源；失败与重试。
- 当前切片不包含：Office/PDF 编辑、OCR、外部模型识别、自动加入上下文、`@` 引用、权限审批、有效性确认、版本关系、删除和客户资产库。

## 资料状态

| 维度 | 状态 | 含义 |
|---|---|---|
| 原件 | 上传中／已保存／保存失败 | 只说明项目原件是否持久化 |
| 预览 | 可预览／不支持预览／预览失败 | 只说明浏览器能否只读渲染原件 |
| 识别 | 待识别／识别中／已识别／需要 OCR／不支持／识别失败 | 只说明本地派生文本状态 |
| 对话 | 未加入对话 | 当前切片不会因保存、预览或识别改变 |

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 已有真实项目 | 从项目行选择一个或多个文件 | Host 校验项目、批次和文件限制 | 原件与 Source 记录原子建立 | 显示已保存数量；可识别文件开始本地识别 | 继续添加或查看资料 |
| 项目进度中的项目详情 | 选择一份资料 | 按 WorkspaceId/SourceId 读取 | 不修改原件和会话 | 右侧显示只读预览、格式、大小和识别状态 | 重试识别或进入项目交付 |
| 项目交付右侧文件树 | 打开原件 | Better Sidebar 按文件能力选择同一预览器 | 不创建第二份文件身份 | Office/PDF/文本等在编辑区只读打开，不支持格式提供下载 | 继续研发或回到对话 |
| 本地识别成功 | 查看状态 | 系统校验原件版本后读取派生 Markdown | Source 指向当前派生结果 | 显示“已识别”，两个入口状态一致 | 后续显式引用给 Agent |
| 识别失败或扫描 PDF | 查看诊断并重试 | 原件继续保留，旧有效派生不被覆盖 | 状态为“识别失败”或“需要 OCR” | 页面不显示“已处理”假状态 | 修复文件、以后接入 OCR 或重试 |

## 功能行为

### 保存与来源身份

1. 每个真实项目行提供“添加项目资料”；未分组会话不显示该动作。
2. Client 以明确 WorkspaceId 提交批次，不按当前 Session、cwd 或最近项目回退。
3. Host 在项目根目录安全创建 `fde-resources/`，拒绝符号链接、非目录、路径穿越、超限批次和越界文件。
4. 文件名保留可移植的中文/Unicode 主体，重名使用可读后缀，不覆盖既有字节。
5. 每个成功原件拥有稳定 SourceId 和持久记录，至少包含项目、相对路径、显示名、MIME/扩展名、字节、修改时间、预览能力、识别状态和派生引用。
6. 已存在但早于来源索引的 `fde-resources/` 文件在首次列出时补建稳定记录，不复制或移动原件。

### 预览与识别

1. 项目详情和开发工作区都按 WorkspaceId/SourceId 或该 Source 对应的受控文件 URL 读取同一原件；不得按同名文件猜测。
2. DOCX、XLSX、PPTX、PDF、Markdown、纯文本、CSV 和常见图片优先提供浏览器只读预览；实际不支持或损坏时显示真实失败并保留下载/进入项目交付路径。Office 文档画布固定使用浅色预览，不跟随系统深色模式，以保留原件中的深色文字、单元格填充和页面排版；该选择不改变工作台主题或原文件。File Viewer 按 `docx`、`xlsx`、`pptx`、`csv` 等文件扩展名选择 Renderer；项目详情必须传入保留扩展名的存储文件名，MIME 只作为响应与页面元数据，不得覆盖扩展名分发。PPTX 命中 Renderer 后必须显示实际幻灯片内容或明确失败信息；只有工具栏而正文空白不算预览成功。
3. 本地识别优先覆盖 DOCX、XLSX、PPTX、PDF、Markdown、纯文本、CSV 等文档；扫描件或只有图片且无可用文本时标记“需要 OCR”。
4. 派生内容写入项目 `.fde/derived/`，记录 SourceId、原件版本和解析器版本；不得覆盖 `fde-resources/` 原件。
5. 原件字节或修改时间改变后，旧派生被标记过期，页面不能把它继续显示为当前结果。
6. 识别失败不撤销已保存原件；重试只更新该 Source 的识别状态和派生结果。
7. 保存、预览和本地识别均不得调用模型、修改 Composer 草稿、创建会话消息或启动 Agent。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 用户取消文件选择 | 无错误 | 不发送请求、不创建目录 | 再次添加 |
| 项目目录失效 | 项目不可用 | 不回退其他 Workspace | 恢复/重新导入项目后重试 |
| 单文件、数量或批次超限 | 显示对应限制 | 整批不发布 | 拆分或减少文件 |
| 同名文件 | 正常保存 | 新文件分配后缀并建立独立 SourceId | 无需恢复 |
| 来源记录暂时损坏 | 显示索引读取失败 | 不删除原件、不猜测其他项目 | 修复索引或重新扫描当前项目 |
| 预览器不支持/损坏 | 显示不支持或失败 | 不影响原件和识别状态 | 下载原件或进入项目交付 |
| 识别失败 | 显示诊断 | 保留原件和旧有效派生 | 原位重试 |
| 原件已改变 | 显示需要重新识别 | 不展示旧派生为当前结果 | 重新识别 |

## 验收标准

### AC-F002-001 · 文件与来源身份持久化到明确项目

- 来源：REQ-008, NFR-001, NFR-007, PSC-003, PSC-011, PSC-012, PSC-024
- 对应 PRD 验收：AC-008
- Given 工作台已有一个目录可用的真实项目
- When 用户从该项目行选择一个或多个符合限制的文件
- Then 原件只出现在该项目 `fde-resources/`，每份原件拥有稳定 SourceId 和记录，刷新或 Host 重启后仍可列出

### AC-F002-002 · 保存与识别不触发 Agent

- 来源：REQ-008, REQ-010, NFR-002, PSC-005, PSC-016, PSC-024
- 对应 PRD 验收：AC-008
- Given 当前项目会话的输入框已有或没有草稿
- When 用户上传、预览或本地识别项目资料
- Then 输入框、消息数和 Agent 运行状态均不改变，系统不调用外部模型

### AC-F002-003 · 原件不被同名覆盖

- 来源：REQ-008, NFR-001, PSC-003, PSC-024
- 对应 PRD 验收：AC-008
- Given `fde-resources/` 已有同名文件
- When 用户再次导入该名称的文件
- Then 新旧文件保持各自字节、拥有不同 SourceId，新文件获得可读的不冲突名称

### AC-F002-004 · 批次失败不伪装成功

- 来源：REQ-008, NFR-001, NFR-007, PSC-003, PSC-011, PSC-012, PSC-016
- 对应 PRD 验收：AC-008
- Given 批次超限或项目目录无法安全写入
- When Host 校验或保存该批次
- Then 页面显示真实失败原因，批次不留下部分原件/记录，原有文件与会话不变

### AC-F002-005 · 两个入口审阅同一资料

- 来源：REQ-008, REQ-016, NFR-005, NFR-007, NFR-008, PSC-003, PSC-012, PSC-018, PSC-024
- 对应 PRD 验收：AC-008, AC-015
- Given 项目中已有受支持和不支持预览的资料
- When 用户分别从项目详情和开发工作区打开它们
- Then 两个入口关联同一 WorkspaceId/SourceId；DOCX、XLSX、PPTX、CSV 和 TSV 均按存储文件名扩展名命中对应 Renderer，带 `charset` 参数的 MIME 不改变格式分发；Office 文档以可读的浅色画布呈现且不因系统深色模式隐藏文字；PPTX 显示实际幻灯片或明确失败，不得停留在只有工具栏的空白正文；不支持或失败状态真实且不影响下载/工程入口

### AC-F002-006 · 本地派生可追踪且可恢复

- 来源：REQ-008, REQ-010, NFR-001, NFR-002, NFR-007, NFR-008, PSC-003, PSC-005, PSC-011, PSC-012, PSC-016, PSC-024
- 对应 PRD 验收：AC-008
- Given 项目含 DOCX、XLSX、PPTX、PDF 和文本样本
- When 本地识别运行
- Then 可提取文本的文件生成带原件/解析器版本的派生 Markdown；扫描件标记需要 OCR；失败保留原件且可重试；原件变化后旧派生不再算当前

## 开放问题

- OCR、版本关系、权限/有效性、删除和对话显式引用按后续 F002/F003 切片确认；当前不得用模型读取代替本地识别。
