# F030 · 官方 0.2.2 下继续既有交付

## 目标与可观察结果

升级到已确认的官方版本后，用户继续使用当前 FF-FDE 项目、八阶段、历史会话、资料、Skills、业务挖掘与中文场景挑战，桌面品牌、界面风格和访问授权不退回官方默认状态。升级失败时能保留既有数据并回到原版本。

## 来源与范围

- 来源需求：REQ-001, REQ-009, REQ-010, REQ-030, REQ-031, REQ-032, REQ-033, REQ-034, REQ-035, REQ-036, REQ-037, REQ-038, REQ-039, REQ-040, NFR-001, NFR-003, NFR-005, NFR-006, NFR-007。
- 来源总规格：PSC-001, PSC-008, PSC-009, PSC-010, PSC-026, PSC-027, PSC-028, PSC-029, PSC-030, PSC-031, PSC-032。
- 本 Feature 包含：固定官方基线、现有扩展兼容、依赖与构建、历史数据隔离验证、本机桌面启动、升级与回退说明。
- 不包含：重写 Agent Loop、重新设计八阶段、自动批准、多人账号、默认启用团队/工作树清理/外发遥测、模型计费验证、GitHub 推送或批量浏览器回放。
- 用户 2026-11-12 的升级指令作为本范围确认；仅实现兼容，不改变已确认的 PRD/总 Spec 业务语义。

## 功能行为

### 主流程

1. 保留中文挑战、请求接收者修复与 macOS 品牌安全间距等当前修改，确定唯一源码基线；不复制整个工程或创建额外 worktree。
2. 基座使用精确发布标签，不跟随滚动开发分支；官方通用改进与 FDE 产品扩展按责任归属合并，不能把一侧全部覆盖到另一侧。
3. 当前项目身份、阶段、文件、会话、训练与答题历史分别核对；首次启动在非秘密数据副本上运行，原运行区不写入。
4. 保持原生完整 Skill 读取/下载、账号配置的主动入口、本机授权与指定 IP 的局域网语义；不自动弹出旧引导或移除安全控制。
5. 完成无密钥定向检查、安装构建与最小在线核对后，启动桌面端交用户手动验收；对未执行的模型效果、生产集成与完整视觉验收如实标记。

### 业务规则与边界

- 上游新增功能不构成自动清理用户工作树、切换模型、开启遥测或扩大工具权限的授权。
- 中文挑战不调用模型；业务访谈继续按用户明确提交运行，保留角色/资料授权，成绩或训练完成不推进项目。
- 保持运行输出只读与独立手动终端的既有分工。必须迁移接口时只改变承载方式，不把权限或责任语义当作技术默认值改变。
- 技术升级不自动完成 V1→V2 生命周期迁移；历史日志可读与项目验收是两件事。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 安装、编译或插件失败 | 具体未通过项 | 停止宣称完成，保留原代码检查点与数据 | 修复后重试相应检查 |
| 新默认值扩大写入/外发 | 对应能力不自动开启 | 使用原已确认策略 | 另行确认产品行为 |
| 历史无法恢复 | 明确失败，不以空项目替代 | 不覆盖或迁移旧原件 | 修复迁移或回退原代码/原数据 |
| 磁盘不足 | 暂停大体积安装 | 不擅自删除其他项目、包或运行记录 | 清理本轮可重建产物或请求用户处理 |

## 验收标准

### AC-F030-001 · 固定版本与完整构建

- 来源：NFR-005, NFR-006, PSC-010。
- 对应 PRD 验收：AC-007。
- Given 当前成果已建立本地代码检查点。
- When 合并目标官方版本并安装、构建。
- Then 版本可追溯、文档中文、依赖可解析；失败不伪装通过，不以禁用 FDE 核心能力换取启动。

### AC-F030-002 · 原导航、身份与桌面视觉保留

- 来源：REQ-001, REQ-009, REQ-033, REQ-037, NFR-001, NFR-005, PSC-001, PSC-008, PSC-027, PSC-031。
- 对应 PRD 验收：AC-001, AC-007, AC-029, AC-030, AC-034。
- Given 既有项目、会话与桌面运行区。
- When 用户进入总览、项目、实验室、技能和阶段工作面并返回。
- Then 原身份、页面、当前阶段和品牌保持一致，macOS 控件避让保留，不自动新建或迁移项目。

### AC-F030-003 · 历史保护与失败真实性

- 来源：REQ-010, NFR-003, PSC-009。
- 对应 PRD 验收：AC-004, AC-008。
- Given 原会话、阶段、业务调查和挑战记录。
- When 在隔离副本读取或转换历史。
- Then 原件摘要不变，已登记身份及既有内容可核对；缺失/失败明确显示，不用空白数据覆盖。

### AC-F030-004 · 授权与终端语义保持

- 来源：REQ-035, REQ-036, NFR-007, PSC-029, PSC-030。
- 对应 PRD 验收：AC-032, AC-033。
- Given 本机服务与现有项目运行记录。
- When 访问 FDE 接口、查看输出或打开手动终端。
- Then 未授权与跨站请求拒绝，输出归属和只读规则不变，不自动扩大监听、读取用户终端或启用清理。

### AC-F030-005 · 中文训练与 Skills 兼容

- 来源：REQ-030, REQ-031, REQ-032, REQ-034, REQ-038, REQ-039, REQ-040, PSC-026, PSC-028, PSC-032。
- 对应 PRD 验收：AC-026, AC-027, AC-028, AC-031, AC-035, AC-036, AC-037, AC-038。
- Given 原平台 Skills、业务挖掘与中文挑战功能。
- When 浏览、读取、恢复与按原规则保存。
- Then 同源完整内容、角色和资料隔离、答题截止/评分/历史及中文解释保持；不开启新模型请求，不污染项目状态。

### AC-F030-006 · 可恢复交付

- 来源：REQ-009, REQ-010, NFR-003, NFR-005, PSC-008, PSC-009。
- 对应 PRD 验收：AC-007, AC-008。
- Given 本次兼容与无密钥检查完成。
- When 启动桌面并交付用户。
- Then 提供实际运行版本、代码检查点、隔离数据路径、未验证项和安全清理条件；用户可以体验，原数据与回退来源仍保留。
