# F027 · 新基座下继续既有交付规格

## 目标与可观察结果

用户升级工作台技术基座后，仍能从原入口继续项目、查看已有会话和八阶段产物、使用独立实验室及中文 Skills；原项目身份、人工决定、来源与权限保持原义。异常应明确报告，并能保留原数据回退。

## 来源与范围

- 来源需求：REQ-001, REQ-009, REQ-010, REQ-030, REQ-031, REQ-032, REQ-033, REQ-034, REQ-035, REQ-036, NFR-001, NFR-003, NFR-005, NFR-006, NFR-007。
- 来源总规格：PSC-001, PSC-008, PSC-009, PSC-010, PSC-026, PSC-027, PSC-028, PSC-029, PSC-030。
- 包含：基座升级所需适配、当前本地源码保留、历史会话读取与恢复、现有入口回归、正确运行区与回退说明。
- 不包含：重设计页面、改写八阶段规则、把 V1 项目自动改为 V2、增加模型调用或遥测外发、部署公网、推送 GitHub、导入新实验室素材或更改第三方许可。
- 用户已于 2026-10-23 明确授权本 Feature，并确认 REQ-035/PSC-029 的局域网授权和 REQ-036/PSC-030 的终端分工变更；其他产品合同保持。

## 用户旅程与状态

| 入口/前置 | 用户动作 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步 |
|---|---|---|---|---|---|
| 当前源码和运行数据 | 开始升级 | 保留精确源码基线，隔离验证数据 | 原项目不变 | 可回退来源明确 | 启动新版验证 |
| 新版工作台 | 进入平台、选择项目 | 总览与项目中心读取真实登记 | 只改变浏览位置 | 原项目和阶段可见 | 打开会话或阶段 |
| 历史项目 | 查看会话、资料与阶段 | 必需格式迁移与文件读取保留身份 | 不推进阶段或改写原件 | 历史结果与当前状态一致 | 继续原工作 |
| 实验室与技能中心 | 阅读、切换、下载 | 保留原训练现场和统一内容源 | 不自动执行模型 | 原流程可用 | 人工验收 |
| 不兼容、迁移或启动失败 | 查看错误并停止验证 | 保留诊断与旧数据 | 不把部分成功当完成 | 可恢复旧运行区 | 修正后再验证 |

## 功能行为

1. 新基座承载现有工作台，不替换产品身份、平台模块、阶段语义和人工决定。
2. 浏览、导入或重启不自动生成消息、推进阶段、调用模型或外发会话。
3. 历史会话格式转换不等于项目生命周期迁移；原代文件、项目原件及决定可追溯。
4. 权限校验失败时拒绝请求；不能以升级为由移除项目作用域或浏览器授权。按用户于 2026-10-23 明确确认，局域网改为指定 IP＋浏览器授权；原全网卡免登录退役，本机默认访问保留。
5. 当前七个中文 Skill 的实际文件、原生加载、阅读、配套引用及完整下载继续同源；课程原版不被覆盖。
6. 实验室保留五案例和原训练能力；缺少授权素材时仍显示实际缺口，不伪造可用。
7. 同一项目工作区提供只读“运行输出”和独立“手动终端”。前者仅查看真实运行会话，缺失不创建替代终端；后者进入当前项目目录，提示与项目共享文件和端口、服务变更需重新核验。启动/停止和项目预览保留，不提供 Agent 终端输入权接管。
8. 按用户人工反馈，工作台首次进入、刷新及无模型凭证时均不自动显示“预览版说明”与“开始使用”。手动账号登录、模型配置及显式 API Key 编辑保持可用；不伪造声明确认、不降低浏览器访问授权。

## 异常与恢复

| 情况 | 用户可见状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 新版无法启动 | 具体依赖或配置错误 | 不加载原运行区 | 修复本轮适配后重试 |
| 会话不能迁移 | 明确迁移失败 | 保留旧文件，不拼接伪历史 | 使用保留原件诊断 |
| 数据或素材缺失 | 未登记、缺失或错误 | 不使用其他项目兜底 | 用户补齐原条件 |
| 需要回退 | 原源码及原运行区位置明确 | 不让旧代码读取新版写入结果 | 停止新版，恢复原组合 |

## 验收标准

### AC-F027-001 · 可重复部署与中文记录

- 来源：NFR-005, NFR-006, PSC-010。
- 对应 PRD 验收：AC-007。
- Given 已固定新版与当前下游源码。
- When 按锁文件安装、构建并启动。
- Then 真实构建成功，运行版本和中文升级记录一致，不误用另一份 checkout。

### AC-F027-002 · 入口与项目事实保留

- 来源：REQ-001, REQ-009, REQ-033, NFR-001, NFR-005, PSC-001, PSC-008, PSC-027。
- 对应 PRD 验收：AC-001, AC-007, AC-029, AC-030。
- Given 原项目、导航和多会话已经存在。
- When 进入总览、项目中心和具体项目，并切换查看阶段。
- Then 原入口、项目归属、既有阶段和真实概况保持，不自动迁移 V1 或推进项目。
- 首次进入与刷新补充：没有模型凭证时也不自动显示预览声明、登录或 API Key 引导；主动配置入口仍可用，未产生声明确认或凭证写入。

### AC-F027-003 · 历史、错误与回退

- 来源：REQ-010, NFR-003, NFR-005, PSC-008, PSC-009。
- 对应 PRD 验收：AC-004, AC-007, AC-008。
- Given 有实际历史会话、项目材料及阶段记录。
- When 在隔离数据中读取历史或发生失败。
- Then 历史内容、身份和用量保持可解释，旧代原件保留；失败明确可恢复，不修改原运行区及阶段证据。

### AC-F027-004 · 授权与项目隔离

- 来源：REQ-001, REQ-035, NFR-001, NFR-007, PSC-001, PSC-009, PSC-029。
- 对应 PRD 验收：AC-001, AC-008, AC-032。
- Given 未授权浏览器、跨来源请求或错误项目标识。
- When 访问 FDE 读取与写入接口。
- Then 本机与指定局域网 IP 均要求浏览器授权，拒绝不可信请求，不泄露数据或以兼容开关绕过权限；受信任当前项目请求继续工作，旧全网卡免登录方式不再生效。

### AC-F027-005 · 平台与课程 Skills 保留

- 来源：REQ-034, PSC-028。
- 对应 PRD 验收：AC-031。
- Given 七个中文平台 Skill 及已收录课程原版。
- When Agent 按需加载、用户阅读引用或下载。
- Then 内容与现有维护文件一致，完整下载和原阅读交互保留，课程不新增执行能力。

### AC-F027-006 · 独立训练与返回

- 来源：REQ-030, REQ-031, REQ-032, PSC-026。
- 对应 PRD 验收：AC-026, AC-027, AC-028。
- Given 现有实验室与项目运行环境。
- When 打开、切换、返回或恢复训练。
- Then 原训练入口、权限、报告和恢复机制继续成立，不登记为项目会话或改变项目阶段；模型质量仍需单独授权验证。

### AC-F027-007 · 真实运行输出与独立人工操作

- 来源：REQ-036, NFR-001, PSC-030。
- 对应 PRD 验收：AC-033。
- Given 当前项目记录了运行会话，且用户已授权访问。
- When 查看运行输出、打开手动终端、启动或停止项目。
- Then 只读输出准确关联运行 Session 与同名终端，跨项目读取被拒绝；手动终端独立位于当前项目，不能向 Agent 终端写入；输出缺失可见且不伪造恢复，启动停止仍使用 operationId 与真实核验。

## 开放问题

无阻塞产品问题。用户已确认终端职责分离；第三方兼容、编译和数据迁移按真实结果验收。
