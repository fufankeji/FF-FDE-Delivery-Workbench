# 阶段 7 手动测试：进入生产、推动采用并验收交接

测试项目：本地知识库。客户验收与责任移交必须由真实人员确认。

## 1. 复审生产与采用准备

```text
进入第七阶段。请基于 Pilot 证据复审生产范围、业务结果、SLO、支持方式、采用计划和接收责任人。写入 fde-deliverables/07-production-handover/production-review.md，并更新 .fde/stages/production.json 的第一步状态；没有真实生产批准时保持待批准。
```

## 2. 准备客户验收

```text
请把结果合同中的验收条件映射到可查看的证据，记录客户验收责任人、条件和待关闭事项。写入 fde-deliverables/07-production-handover/customer-acceptance.md，并更新 production.json 的第二步状态。不要代替客户填写接受结论。
```

## 3. 组织交接和实操

```text
请整理可取得的交付物、运维指南、已知问题、权限责任、培训和接收团队实操结果。写入 fde-deliverables/07-production-handover/handover-record.md，并更新 production.json 的第三步状态。仅有文档或参加培训不能证明接收团队能独立运行。
```

## 4. 整理给 FDE 评审

```text
请核对 production-review.md、customer-acceptance.md 和 handover-record.md，分别列出生产、采用、客户接受、实操和责任转移的真实状态。材料齐备时把 .fde/stages/production.json 更新为待 FDE 评审，不要自动关闭项目或伪造签署。
```
