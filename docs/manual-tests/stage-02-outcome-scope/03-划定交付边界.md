# 第三步：划定交付边界

只复制下面提示词到同一个 Agent 会话：

```text
请继续划清本次本地知识库试点的交付边界。

本次包含：X200 产品系列、客户确认有效的产品手册和维修 SOP、本地部署、基于资料的查询与回答、答案来源展示、无法判断时人工接手、试点过程记录。

本次不包含：其他产品系列、自动向客户发送回复、CRM 改造、资料上传公网、自动替客户批准资料、无人审核的全自动处理。

如果出现客户资料外泄、无法展示答案来源、引用已失效资料，或者无法转人工处理，应暂停试点并重新评审。

请更新 outcome-contract.md 和 value-case.md，明确范围、非目标、风险上限和停止条件。同步更新 .fde/stages/definition.json，保持根对象 stage 为 definition：scope 标为 complete，ownership 标为 current。不要创建技术方案或承诺尚未核实的实现能力。
```

## 本步观察点

- 页面当前工作应切换到“确认责任与计划”；
- 范围、非目标和停止条件应分别记录；
- “本地部署”是客户约束，不等于平台已经完成部署；
- 停止条件不能被平均分或模糊表述覆盖；
- Agent 不应提前进入第三阶段调查。
