# 第四步：形成阶段记录

只复制下面提示词到同一个 Agent 会话：

```text
请基于本轮对话中已经提供的信息，按照平台第一阶段的内置规范，整理并保存三项必备记录：客户现状记录、待确认事项、业务流程说明。

记录中请保留信息来源、代表案例、正常与异常流程、责任人和决策人、人工接手方式，并区分已经确认、根据现有信息推断和仍待确认的内容。未知信息保持未知，不要补写不存在的客户结论。

完成后请告诉我生成了哪些记录、目前还有哪些关键缺口，以及为什么可以或不可以提交 FDE 评审。不要自动进入第二阶段，阶段是否推进由我手动决定。
```

## 本步观察点

- 右侧三项必备记录应从“待形成”变为已有候选记录；
- 每项记录应可点击并正常预览；
- 候选工作流与记录中的事实应保持一致；
- 系统应如实展示剩余缺口；
- 即使三项记录齐全，也只能出现提交或人工确认动作，不能自动进入第二阶段。
