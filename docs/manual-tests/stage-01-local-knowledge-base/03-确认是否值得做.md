# 第三步：确认是否值得做

只复制下面提示词到同一个 Agent 会话：

```text
再补充一组用于判断价值的信息：

- 售后团队每天大约收到 60 个问题，这是售后主管的估算，还没有从系统中核对；
- 最近人工抽查了 20 个问题，平均处理时间约 14 分钟，其中 7 个需要询问资深工程师，2 个因为参考了旧资料而重新回复；
- 售后主管最关心新人能否更快找到可追溯的答案，以及答案是否引用了正确版本的资料；
- 客户愿意先选择一个产品系列、5 名售后人员做小范围尝试；
- 如果答案无法说明来源、引用错误版本，或者无法由人工接手，就不能继续扩大使用。

请判断“售后问题查询与回复”是否值得进入下一阶段。请分别说明：目前有依据的结论、仍然只是推断的结论、必须向客户继续确认的事项，以及建议继续、补充调查、缩小范围还是停止。不要把估算写成已经核实的数据，也不要开始做技术方案。
```

## 本步观察点

- Agent 应给出有证据边界的价值判断；
- “每天约 60 个问题”必须保持为未核实估算；
- 应识别资料版本、答案来源和人工接手为关键边界；
- 结论应是候选建议，不能代替 FDE 的阶段决定。
