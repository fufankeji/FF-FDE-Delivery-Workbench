# 第一步：听客户怎么说

只复制下面提示词到 Agent 输入框：

```text
我们准备为一家约 20 人的售后团队做一个本地知识库项目。客户目前只说：“资料太散，新人找答案很慢，希望做一个能问答的知识库。”

现在不要设计方案，也不要开始开发。请先按第一阶段帮我梳理：为了弄清客户现在到底怎么工作、问题发生在哪里，最少还需要确认哪些关键事实？请优先问最关键的问题，并把客户目前的说法保留为待确认信息。
```

## 本步观察点

- Agent 应先调查事实，而不是直接推荐 RAG、向量数据库或模型；
- 应询问真实参与人、近期案例、正常流程、异常流程、结果验证者或责任人；
- 页面仍处于第一阶段。
